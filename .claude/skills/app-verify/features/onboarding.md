# 온보딩

첫 실행 때 앱 소개 2장을 보여 주고 관심 ETF 를 고르게 한 뒤, 고른 ETF 의 AI 분석 화면으로 보낸다.

## 하위 기능
- 소개 1 "뉴스 3만 건을 대신 읽어드려요" → `다음`
- 소개 2 "전망은 스티커 하나로 말해요" → `관심 ETF 고르기`
- 관심 ETF 고르기: 검색칸 "ETF·테마 검색", ETF 원형 아이콘 격자, `전망 보기`(하나 이상 골라야 켜진다)
- 하단 "이미 계정이 있나요? 로그인" → 로그인 화면(쓰기 영역, 자동 검증 안 함)

## 가는 길 (사용자 시점)
앱을 처음 설치해 켠다. 이미 온보딩을 마친 기기는 다시 볼 수 없다(앱 데이터를 지워야 한다).

## Maestro 로 조작
`ONBOARDING=1 scripts/run.sh flows/onboarding.yaml`. 글자로 누른다: `다음`, `관심 ETF 고르기`, `KODEX 반도체`, `전망 보기`.
끝 상태: ETF 상세의 `AI 분석` 탭이 보인다.

## 주의할 점
- 이 흐름은 앱 데이터를 지우고 온보딩을 끝낸다. 운영 서버에 게스트 1명 + 관심 ETF 1개가 새로 생긴다(`POST /onboarding/complete`, 기기 ID 헤더). 그래서 기본 실행에서 뺐다. 온보딩 화면을 고쳤을 때와 새 검증 기기를 준비할 때만 돌린다.
- ETF 목록을 불러오는 1~2초 동안 "찾는 ETF가 없어요"가 보인다. 로딩 중인데 빈 결과처럼 보이는 제품 문제다(2026-11-25 발견, 미수정). 흐름은 `KODEX 반도체`가 보일 때까지 기다린다.
- 소개 화면 제목은 줄바꿈이 들어 있어 글자 일치가 불안정하다. `다음`과 "이미 계정이 있나요?"로 확인한다.
