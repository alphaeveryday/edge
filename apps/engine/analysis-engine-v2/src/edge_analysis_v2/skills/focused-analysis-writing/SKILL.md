# 분석 결과 작성

작업 지시의 출력 계약에 맞춰 확인한 내용만 써. 분량이나 논점 수를 채우기 위해 조사하지 마.

- 가격변동 설명은 구체적인 사건과 이 ETF에 중요한 이유를 짧게 써. 이전 분석이 있으면 바뀐 설명만 작성하고 유효한 기존 항목과 ID를 유지해.
- 전망 수정은 달라진 문장·근거·판단만 고쳐. 유지할 본문은 다시 작성하지 말고 기존 본문 편집 도구로 필요한 변경만 적용해. 요약과 결론도 의미가 달라질 때만 고쳐.
- notes/answer.md에는 새로 쓸 설명이나 변경점과 이유만 짧게 적어. 바뀐 것이 없으면 유지 이유만 적어. 긴 보고서 초안을 새로 쓰지 마.
- 읽는 사람은 이 ETF를 가진 일반 투자자야. 누가 무엇을 했고 어떤 의미인지를 쉬운 해요체로 써. 사건의 시점, 예정·확정 여부와 수치의 기준을 보존해.
- 기존 원자료의 유효한 근거 ID는 재사용해. 이전 글이나 메모 자체를 근거로 삼지는 마. 새 기사를 최종 근거로 쓸 때는 get_issue_evidence(include_body=false)의 성공 결과를 사용하고, 웹 문서는 final_eligible이 true인 것만 사용해.
- 최종 응답의 필수 필드와 길이 제한은 그대로 지켜. 변경이 없다는 이유로 필수 필드를 생략하지 마.
