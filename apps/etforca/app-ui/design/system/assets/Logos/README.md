# Logos

ETF Orca의 마크다. 범고래 안에 오르는 막대 세 개가 있다.

- `icon.png` (1024×1024): 앱 아이콘. 검정 바탕에 흰 마크. 스토어, 프로필 이미지, 어두운 표지에 그대로 쓴다.
- `logo-mark.png` (96×96, 투명 바탕): 흰색 마크만 있다. 잉크는 흰색 한 가지다. `text`, `primary`, 검정처럼 어두운 바탕 위에만 올린다. 밝은 바탕에는 보이지 않으므로 쓰지 않는다.

마크의 색을 바꾸거나, 늘이거나, 막대만 따로 떼어 쓰지 않는다. 밝은 바탕용 어두운 마크와 벡터 원본은 저장소에 없어서 이 묶음에도 없다.
