목록을 걸러 보는 선택 칩이다.

## 언제 쓰나

- 보기 방식이나 범위를 고를 때 가로로 나열한다. ETF 종목정보의 투자 온도와 오늘 등락, 종목과 테마, 커뮤니티의 전체가 그 예다.
- `add` 변형은 줄의 맨 끝에 두는 추가 칩이다. 점선 테두리와 더하기 아이콘으로 구분한다.
- 행동을 실행하는 버튼으로 쓰지 않는다. 그때는 CtaButton을 쓴다.

## 수치

- 안쪽 여백 8px 13px, 모서리 `radius-control`, 글자는 `tab` 스타일.
- 선택: `surface` 바탕에 `text` 글자, 굵기 800. 선택 안 됨: 바탕 없음, `textMuted` 글자, 굵기 600.
- add: `lineStrong` 점선 테두리, `textSub` 글자, 15px 더하기 아이콘.
- 누르는 동안 불투명도 0.7.

## 쓰는 쪽이 정하는 것

`label`, 선택 여부 `on`, `variant`(filter 또는 add).

정적 재현이다. `src/components/ui/Chip.tsx`의 수치를 옮겼다.
