한 화면 안에서 보기를 바꾸는 밑줄 탭 하나다.

## 언제 쓰나

- ETF 상세의 AI 분석, 오늘 움직임, 커뮤니티, 종목정보처럼 같은 대상의 다른 면을 볼 때 쓴다. 알림함의 분류에도 쓴다.
- 탭이 화면 폭을 나눠 가질 때는 `grow`, 개수가 많아 가로로 넘길 때는 `fit`(좌우 여백 12px)으로 둔다.
- 새 내용이 있으면 오른쪽 위에 점을 찍는다.

## 수치

- 위 10px, 아래 11px 여백. 글자는 `tab` 스타일.
- 선택: `text` 글자, 굵기 800, 2px `text` 밑줄. 선택 안 됨: `textMuted`, 굵기 600, 밑줄 없음.
- 점: 5px 원, `up` 색. 선택은 색이 아니라 굵기와 밑줄로 구분된다.

## 쓰는 쪽이 정하는 것

`label`, 선택 여부 `on`, 점 `dot`, 폭 방식 `grow`. 탭 줄 아래의 선은 쓰는 쪽이 긋는다.

정적 재현이다. `src/components/ui/TabItem.tsx`의 수치를 옮겼다.
