# 제품별 차이

같은 저장소 안에 디자인 토큰이 세 벌 있다. 이 시스템은 앱의 것을 담았다. 아래는 2026-11-23, `dev@7f43ab1` 기준으로 세 벌을 비교한 것이다.

| | ETF Orca 앱 | 포트폴리오 진단 웹 (Orca UI 1.1) | EDGE 콘솔 (ui-kit) |
| --- | --- | --- | --- |
| 위치 | `apps/etforca/app-ui/src/theme` | `apps/etforca/portfolio-ui/src/design-system` | `libs/ui-kit/src/styles` |
| 대상 | 개인 투자자 | 개인 투자자 | 금융사 실무자 |
| 브랜드 색 | 보라 #3D34E0 | 파랑 #1B64DA | 청회색 #2E5AAC |
| 상승 / 하락 | 빨강 #F04452 / 파랑 #3182F6 | 빨강 #D22030 / 파랑 #1B64DA | 초록 #2F7D5B / 빨강 #B4453B |
| 화면 바탕 | 흰색 위에 회색 카드 | 회색 #F2F4F6 위에 흰 카드 | 회색 #FAFAFA 위에 흰 면 |

| 카드 모서리 | 16px | 24px | 콘솔 자체 값 |

| 본문 크기 | 14px | 17px | 콘솔 자체 값 |
| 글꼴 | Pretendard 정적 5종, JetBrains Mono | Pretendard Variable | Pretendard (CDN) |
| 다크 모드 | 있음 | 없음 | 없음 |

## 같은 것

- 글꼴은 셋 다 Pretendard다.
- 앱과 웹은 본문 글자색(#191F28), 보조 글자색(#4E5968), 선(#E5E8EB), 회색 면(#F2F4F6)이 같다. 둘 다 토스 공개 디자인 시스템의 회색 단계를 참고했다.
- 앱과 웹은 버튼 모서리(14px)와 상승=빨강, 하락=파랑 관례가 같다.

## 다른 것 중 사용자가 알아채는 것

1. **브랜드 색.** 앱은 보라, 웹은 파랑이다. 웹의 파랑(#1B64DA)은 앱에서 "하락"을 뜻하는 색 계열과 같아서, 웹의 주요 버튼이 앱 사용자에게는 하락 색으로 읽힐 수 있다.
2. **면의 순서.** 앱은 흰 바탕에 회색 카드, 웹은 회색 바탕에 흰 카드로 반대다.
3. **카드 모서리와 본문 크기.** 웹이 더 둥글고(24px) 글자가 더 크다(17px).
4. **콘솔의 등락 색은 반대다.** 콘솔은 상승이 초록, 하락이 빨강이다. 대상이 금융사 실무자라 의도된 차이지만, 콘솔 화면을 개인 투자자용 자료에 그대로 쓰면 안 된다.

## 통합 제안

결정은 소유자의 몫이고, 아래는 제안이다.

- **개인 투자자에게 보이는 것은 앱 토큰으로 맞춘다.** 인스타 계정, 스토어, 앱 아이콘이 모두 ETF Orca 이름으로 나가므로, 새로 만드는 랜딩 페이지와 인스타 카드는 이 시스템의 `primary`와 방향 색을 쓴다.
- **웹은 브랜드 색 한 줄만 먼저 바꾼다.** `--color-primary`를 앱의 `primary`로 맞추면 "파란 버튼 = 하락 색" 문제가 사라진다. 면의 순서와 모서리는 웹의 정보 밀도에 맞춘 결정이므로 그대로 둔다.
- **콘솔은 합치지 않는다.** 대상과 관례가 다르다.
- **원천은 하나로 둔다.** 색 이름과 값을 한 파일에서 만들어 앱과 웹이 함께 읽게 하면 세 벌이 두 벌로 준다. 지금은 앱의 `tokens.ts`와 웹의 `tokens.css`를 사람이 따로 고친다.
