# Portfolio UI

- UI 변경 전 `docs/design/portfolio-design-system.md`와 `src/design-system`을 읽는다.
- 모든 화면은 Orca UI 토큰과 공통 조작부를 사용한다. 색상 생값·별도 테마 덧씌우기·동일 역할 컴포넌트 복제를 추가하지 않는다.
- 버튼/입력/셀렉트/텍스트 영역은 `design-system/components`를 사용한다. 금융 계산·저장·인증은 디자인 코드에 넣지 않는다.
- 새 상태·변형은 실제 사용처와 전시 화면을 같은 PR에 추가한다. 새 고객 문구는 짧고 명확한 해요체로, 필수·선택과 행동 결과를 정확히 표시한다.
- `check:design`, 빌드, 관련 Playwright 검사와 모바일/PC 화면 확인을 실행한다. 전역 토큰 변경은 전체 UI 검사를 실행한다.
- 팝업 초점·키보드·축소된 모션·확대·결측·큰 금액을 보존한다. 전시/미리보기에서 고객 API 쓰기와 분석/메일 발송을 만들지 않는다.
