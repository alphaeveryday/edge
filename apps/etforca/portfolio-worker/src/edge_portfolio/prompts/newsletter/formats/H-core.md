# H. 보유 가설 브리핑 — 운영 기본

**원칙:** 독자는 매일 모든 소식을 읽고 싶지 않다. 내 보유 이유가 흔들렸는지, 흔들렸다면 왜인지만 알면 된다.
**지면 순서:** 표지(가장 중요한 변화) → 변화가 있는 종목: 보유 가설 → 오늘 판정 → 무엇이 바뀌었나(원인 후보) → 가설에 주는 의미 → 다음 확인 → 변화 없는 종목: 한 줄.

독자가 투자 조건을 입력하지 않았으면 이 ETF를 사는 사람들의 가장 일반적인 보유 이유를 가설로 세운다.

- `thesis`: 검증할 보유 가설 한 문장. 반증 가능하게 쓴다. 예) "AI 서버 수요로 메모리 업황이 2027년까지 좋아진다".
- `verdict`: 오늘 정보가 가설을 `강화`·`유지`·`약화`했는지. 하루 등락만으로 판정하지 않는다.
- `important`: 가설에 실질적으로 닿는 새 사실(실적·공시·정책·수요 지표·구조적 수급 변화)이 있으면 `true`. 단순 등락, 반복 보도, 일반 시황은 `false`. 대부분의 날은 `false`가 정상이다.
- `changes`: `important`가 `true`일 때만 1~2개, 영향이 큰 순서. `label`은 12자 안팎 명사구, `detail`은 근거 사실과 가설로 이어지는 경로, `certainty`는 자료로 직접 확인되면 `확인`, 시점·방향만 맞으면 `추정`. `false`면 빈 배열.
- `meaning`: `true`면 이 변화가 가설에 주는 의미. `false`면 오늘 변화가 가설과 무관한 이유를 한 문장으로.
- `next_check`: 가설이 맞는지 다음에 확인할 일정이나 지표 하나.
- `headline`·`dek`: 판정과 가장 중요한 변화를 앞세운다. 변화가 없으면 담담하게 쓴다.
