# 스킬: 새 사건 찾기 (discover-cases)

이번 세션은 기존 사건에 배정되지 않은 최근 기사에서 **조사 후보 조건을 모두 만족하는 사건이 있으면 하나만** 등록하는 일이다. 대부분의 날에는 등록할 사건이 없다. 없으면 아무것도 만들지 말고 `finish` 한다.

## 조사 후보 조건 (넷 다 만족해야 한다)

| 조건 | 확인할 질문 |
|---|---|
| 상장종목 연결성 | 어느 상장종목(6자리 코드)의 가치·위험·매매 판단에 연결되는가 |
| 투자 중요성 | 정확히 알았다면 매수·매도·보유 판단이 달라질 수 있는가 |
| 행동 검증 가능성 | 여섯 유형 중 무엇을 어떤 기록으로 검증하는가 (지어낸 사실, 감춘 위험, 질문 회피, 과거 발언 부인, 근거 없는 원인 설명, 투자자 탓) |
| 근거 추적성 | 공시·공식 판단·원기사로 돌아갈 수 있는가 |

사회적 파급력은 우선순위를 높일 뿐 증거를 대신하지 않는다. 원문 없이 짧은 편집 영상·캡처·전언만 있는 사건은 등록하지 않는다. 단순 실적 부진·전망 하향·주가 급락만으로는 후보가 아니다.

## 절차

1. 후보 기사 제목을 훑고 위 조건에 가까운 것 2~3건을 고른다. `list_cases` 로 이미 다루는 사건인지 확인한다.
2. `view_news`·`search_news` 로 같은 사건의 다른 보도와 당사자 해명을 찾는다. 필요하면 `web_fetch` 로 공식 원문을 읽는다.
3. 조건을 모두 만족하는 사건이 없으면 그대로 `finish("등록할 후보 없음: <이유 한 문장>")`.
4. 있으면 `create_case` 로 뼈대를 만들고 채운다.
   - 출처 먼저: 서로 다른 매체·기관 2곳 이상을 `add_source` 로 등록한다(같은 브리핑을 옮긴 기사는 하나로 친다).
   - `title` 짧은 제목(6~28자, 주체 이름 + 무슨 일), `headline` 두 문장(확인 수준 형식), `contrast` 처음 한 말 ↔ 충돌하는 기록, `behaviors` 유형별 판정(근거 출처 포함), `levels`, `legalStatus`, `ach`, `body`(무엇이 쟁점인지 · 확인한 순서 목록), `rebuttal`(있으면), `set_impact`.
   - 새 사건은 판정이 나지 않은 '판단 중'으로만 등록한다. 대부분의 유형 판정은 `suspected`·`insufficient` 다.
   - `aliases`(인명·영문명)와 `topics`(이 사건 보도에만 나오는 주제어 3~10개, 예: 유상증자·공개매수·실사)를 채운다. 관련 보도는 제목에 이름과 주제어가 함께 있을 때만 붙으므로, 회사 이름만 나오는 실적·신상품 기사가 붙지 않게 사건 고유의 낱말을 고른다.
5. `check` → '통과' 후 `finish` 에 무엇을 왜 등록했는지 적는다.
