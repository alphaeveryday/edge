# edge 문서 (docs/)

이 디렉토리는 시스템의 **설계 지식** — 구조, 데이터 계약, 결정 기록 — 을 담는다.
운영 규칙(브랜치·커밋·머지)은 docs가 아니라 루트 [README.md](../README.md)·[AGENTS.md](../AGENTS.md)에 둔다.

> 아래 문서들은 **목표 아키텍처**를 기술한다. 코드베이스의 현재 상태(초기 스캐폴드)는 루트 [README.md](../README.md)의 "프로젝트 상태"를 참고.

## 문서 지도

| 문서 | 무엇을 담나 | 언제 보나 |
|---|---|---|
| [architecture.md](architecture.md) | 시스템 구조 — 컴포넌트·통신·신뢰 경계 | 전체 그림을 잡을 때 |
| [schema.md](schema.md) | DB 계약 — 테이블 소유권 + 확장-수축 변경 절차 | **데이터/스키마를 바꾸기 전 (필독)** |
| [adr/](adr/) | 결정 기록 — 무엇을 왜 그렇게 정했나 | 결정의 배경이 궁금할 때 |

## 읽는 순서
1. 루트 [README.md](../README.md) — 무엇을 하는 시스템인지, 모노레포 구조, Git 규약
2. [architecture.md](architecture.md) — 컴포넌트와 신뢰 경계
3. [schema.md](schema.md) — 데이터 계약과 변경 절차
4. [adr/](adr/) — 개별 결정의 맥락 (필요할 때)

## 무엇을 어디에 두나
- 설계·결정·계약 → `docs/` (새 문서는 위 지도에 등록).
- 운영 규칙(브랜치/커밋/머지) → 루트 README / AGENTS가 SSOT.
- 결정은 ADR로 증류한다 — 회의록·PRD 원본은 레포에 두지 않는다.
