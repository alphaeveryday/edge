# ADR-0013: Exposure Log 기록 — 조회 시점 자동 기록, 고객 해시는 증권사 생성

- 상태: 승인됨
- 날짜: 2026-07-12
- 결정 로그: 확정 결정 #2 (2026-07-12)

## 맥락
고객 노출 이력은 민원/감사 재현의 근거 데이터다. "실제 노출"을 어느 시점으로 기록할지, 고객 식별을 어떻게 비반출 원칙 아래에서 처리할지 정해야 했다.

## 결정
MVP는 Serving API 조회 시점 자동 기록(조회=노출 간주, 감사 문서 명시). 노출 콜백은 로드맵. 고객 해시는 증권사 백엔드 생성.

상세는 [../domain/exposure-log.md](../domain/exposure-log.md).

## 대안
MTS 백엔드가 실제 렌더링 후 호출하는 노출 콜백 API — 조회≠노출 오차를 제거하지만 MVP가 아닌 확장 로드맵으로 미룬다 ([../roadmap.md](../roadmap.md)).

## 결과
- 감사/민원 대응 문서에 "노출 이력은 조회 로그 기준"임을 명시할 의무가 생긴다.
- Serving API는 원본 고객 ID/계좌번호를 절대 받지 않는다. 해시 생성 규칙·salt는 증권사 관리 영역 (벤더는 관여하지 않음 — 비반출 원칙).
- Exposure Log는 근거 데이터·컴플라이언스 검사 결과·검수 결과와 조인하여 민원 시점 상태를 완전 재현할 수 있어야 한다.
