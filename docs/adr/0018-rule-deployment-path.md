# ADR-0018: Compliance Rule 배포 경로 — Rule Type은 릴리스, Sync 채널은 데이터 전용

- 상태: 승인됨
- 날짜: 2026-07-12
- 결정 로그: 확정 결정 #7 (2026-07-12)

## 맥락
증권사별 컴플라이언스 룰(금칙어/금지 표현/처리 기준)의 로직과 설정값이 각각 어떤 경로로 온프렘에 도달하는지 정해야 했다. 벤더가 증권사 내부 시스템의 동작을 원격으로 바꿀 수 있는 경로는 준법감시 관점에서 민감하다.

## 결정
Rule Type은 소프트웨어 릴리스로만, Sync 채널은 데이터 전용. Rule Instance는 콘솔 설정.

- **Rule Type = 코드**, 소프트웨어 릴리스(온프렘 버전 업그레이드)로만 배포.
- **Rule Instance = 증권사가 Tenant Console에서 설정** (금칙어 목록, 임계값, 처리 기준).

상세는 [../implementation.md](../implementation.md).

## 대안
룰 정의를 Sync 채널로 내려보내기 — 원격 코드 배포로 간주될 소지가 있어 차단한다. Sync 채널은 데이터(이벤트/설명 후보) 전용으로 유지.

## 결과
- 정책 버전은 불변(immutable), 정책 변경 이력은 Audit Log에 기록.
- 룰 로직 변경은 온프렘 버전 업그레이드 릴리스를 요구한다.
