# ADR-0022: 검증·보강 2차 — 규제 사실관계 외부 검증 및 배치·온보딩 옵션 보강

- 상태: 승인됨
- 날짜: 2026-07-13
- 결정 로그: 확정 결정 #11 (2026-07-13)

## 맥락
규제 서사의 사실관계를 외부 소스로 검증하고, 증권사 보안 정책 다양성(망연계 솔루션 요구)과 보수적 온보딩 경로를 설계에 반영할 필요가 확인됐다.

## 결정
- 규제 서사 사실관계 외부 검증 완료 — 4/20 SaaS 망분리 예외 시행세칙 시행, 6월 보안 목적 생성형 AI 비조치의견서(1차 10개사), 전면 해제는 "검토 중·시한 미공표" 모두 금융위 보도자료·법률 리뷰로 확인 (유의: 6월 비조치의견서는 보안 목적 한정, 고객 대면 AI 콘텐츠 허용 아님)
- Sync Agent→내부망 DB 경로에 망연계 솔루션 경유 옵션 추가 ([../context.md](../context.md))
- AUTO_PUBLISHED 0% 시작 가능·점진 완화 온보딩 경로 명시 ([../console-ia/tenant-console.md](../console-ia/tenant-console.md))
- 클라우드 테넌트 격리 단일 계층 트레이드오프 근거 + tenant_id 스코핑 로드맵 옵션 문서화 ([../contracts/sync-auth.md](../contracts/sync-auth.md))

## 대안
DMZ→내부망 직접 DB 커넥션 단일 배치만 지원 — 망연계 솔루션(망간자료전송 시스템) 경유를 요구하는 증권사를 수용할 수 없어, Pull·무결성 검증(DMZ)과 내부망 저장(별도 수신 모듈)을 분리하는 2단 구성도 지원한다.

## 결과
- 보수적 증권사는 전건 REVIEW_REQUIRED로 운영을 시작하고 검수 데이터 축적 후 자동 노출 기준을 점진 완화하는 경로가 표준 온보딩 시나리오가 된다.
- 대외 발표에서 6월 비조치의견서를 고객 대면 AI 콘텐츠 허용 근거로 쓰지 않는다.
