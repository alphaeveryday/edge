# ADR-0023: 고객 검증 반영 — 증권사 현업 리뷰 확보·이해상충은 노출 범위 제외로 통제

- 상태: 승인됨
- 날짜: 2026-07-14
- 결정 로그: 확정 결정 #12 (2026-07-14)

## 맥락
증권사 현업 개발자 서면 리뷰를 확보해 도입 의사결정 구조와 준법감시 관심사를 검증했다. 도입은 4단계 의사결정 관문(현업 기획 → IT본부 → 준법감시인 → 금융소비자보호팀)을 거치며, 준법감시 최우선 관심사는 금감원 조사 시 제시 근거·예외처리·이해상충·책임소재·데이터 정확도 보장 근거로 확인됐다. 이해상충(계열사 종목·자사 IPO 주관 종목 등)은 준법감시 필수 검토 항목이다.

## 결정
- 이해상충 소지 종목은 **별도 룰 타입 신설 없이 Tenant Console Settings의 노출 범위 제외(종목·섹터 단위)로 통제**한다 ([../console-ia/tenant-console.md](../console-ia/tenant-console.md)).
- 대외 기획서에 고객 검증 섹션·정확도 입장(룰 엔진 보장 경계 + 4중 방어)·RA 테스트베드 비대상 논거를 반영한다 (기획서는 레포 밖 산출물 — 충돌 시 docs/가 우선).

## 대안
이해상충 전용 룰 타입 신설 — Rule Type은 소프트웨어 릴리스로만 배포되므로([0018](0018-rule-deployment-path.md)) 증권사별로 수시 변하는 이해상충 목록을 릴리스에 결합시키게 된다. 노출 범위 제외는 콘솔 설정이라 증권사가 즉시 통제할 수 있어 이를 택했다.

## 결과
- 준법감시인 대상 설명에서 이해상충 통제는 "노출 범위 제외 설정"으로 답한다.
- 4단계 관문·준법감시 관심사 목록은 영업·기획 산출물의 검증 근거로 사용한다.
