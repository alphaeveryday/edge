# 클라우드 저장 기록 화면

분석 ID를 선택하면 개발 DB에 실제 저장된 분석 행과 툴 기록을 다시 읽어 보여준다. 실행 중인 분석도 조회할 수 있다. 이 화면은 읽기 전용이며, 에이전트 실행과 결과 발행 기능은 기존 실행 화면에 연결할 후속 작업이다.

- 실행: `python -m edge_analysis_v2.cloud_review --rds-ca <인증서 경로>`.
- 준비: `edge-v2-writer` 프로필, `EdgeV2-RdsWriterTunnel` SSM 연결(15433), 패키지 `cloud` 의존성.
- 주소: `http://127.0.0.1:8767`. 로컬 접근만 허용.
- 목록: 가격변동 설명·전망 각각 최근 50개. 관측 기준시각 순서. 새로고침으로 재조회.
- 화면이 열려 있는 동안 10초마다 재조회. 다른 탭을 보는 동안에는 자동 조회 중지.
- 상세: 분석 행, 호출 ID, 성공/실패, 인수, 저장된 출력, 수식, 관리자용 정의, 출처, 자료 기준시각.
- 로컬 JSON으로 대체하지 않음. DB 조회 실패는 오류로 표시.
- `GET /api/analyses`: 두 종류의 최근 분석 목록.
- `GET /api/analyses/{movement|outlook}/{analysis_id}`: 해당 분석의 감사 기록. 없으면 404.
- 새 DB 테이블·권한·배포 없음. 검수 화면의 표시 상태는 서버 메모리에 저장하지 않음.
- 수식은 고정 버전 KaTeX CDN으로 렌더링. 로드 실패 시 LaTeX 원문과 안내 표시.
