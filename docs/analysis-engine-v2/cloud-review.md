# 클라우드 저장 기록 화면

통합 대시보드에서 분석 ID를 선택하면 개발 DB에 실제 저장된 분석 행과 툴 기록을 다시 읽어 보여준다. 실행 중인 분석도 조회할 수 있다. 실행 설정과 출력 계약 검사, 시스템 프롬프트 관리도 같은 대시보드에서 제공한다. 실행 방법과 테스트 환경은 [패키지 안내](../../src/apps/cloud/analysis-engine-v2/README.md)를 참고한다.

- 실행: `python -m edge_analysis_v2.dashboard.server --rds-ca <인증서 경로>`.
- 준비: `edge-v2-writer` 프로필, `EdgeV2-RdsWriterTunnel` SSM 연결(15433), 패키지 `cloud` 의존성.
- 주소: `http://127.0.0.1:8765`. 로컬 접근만 허용. 별도 관측 대시보드는 제거했다.
- 목록: 가격변동 설명·전망 각각 최근 50개. 관측 기준시각 순서. 새로고침으로 재조회.
- 화면이 열려 있는 동안 10초마다 재조회. 다른 탭을 보는 동안에는 자동 조회 중지.
- 관측: 요약·툴 호출 상세·원문. 툴 입력과 출력은 구문 색상을 적용한 JSON으로 표시한다. 실제 DB 테이블 행은 DB 조회에서 확인한다.
- 로컬 JSON으로 대체하지 않음. DB 조회 실패는 오류로 표시.
- `GET /api/analyses`: 두 종류의 최근 분석 목록.
- `GET /api/analyses/{movement|outlook}/{analysis_id}`: 해당 분석의 감사 기록. 없으면 404.
- 계약 검사는 DB에서 조립한 응답의 JSON 타입·구조와 계약 규칙을 확인하고 실패 위치를 표시한다. 검사 결과는 실행 기록에 저장한다.
- 새 DB 테이블·권한·배포 없음.
