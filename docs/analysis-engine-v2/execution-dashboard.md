로컬 DB 검수 화면에서 목 시나리오를 선택해 실제 에이전트를 실행합니다. 툴과 화면 결과는 클라우드 DB에 저장하고, 초기 입력·시스템 프롬프트·모델 이벤트·최종 응답은 로컬 실행 폴더에서도 확인합니다. 목자료임을 화면에 표시하며 실제 시장 분석으로 취급하지 않습니다.

- 기본 실행은 읽기 전용. `--env-file`과 `--runs-dir`을 함께 지정해야 실행 버튼 활성화.
- `.env`의 `DEEPSEEK_API_KEY`, `DEEPSEEK_MODEL`만 사용. 키·파일 경로·명령어는 브라우저에서 받지 않음.
- 독립 시나리오: 기본 / 특이 수급 / 상충 지표 / 후속 기사 / 변화 없음. 서로의 이전 분석을 받지 않음.
- 연속 재생 1~5: 과거 자료가 변하지 않는 동일 데이터셋 사용. 같은 기능의 직전 재생 결과만 이어받으며 순서대로 실행.
- 요청: 오늘 움직임 / 전망. 한 번에 한 실행.
- 가격변동 예시는 9월 14일 10~14시, 전망 예시는 9월 14~18일 08:30. 고정 시각을 선택 화면에 표시.
- 실행 요청은 로컬 Host·Origin·CSRF 토큰을 확인. 실행 ID는 서버가 생성. 임의 파일 조회나 명령 실행 기능 없음.
- 실행 중·완료·실패 상태와 DB 기록을 따로 표시. 서버 재시작 후 실행 중이던 작업은 중단으로 표시하고 자동 재실행하지 않음.
- `/api/screens/{kind}/{id}/{feature}`는 DB에서 조립한 기능별 화면 JSON. 입력·프롬프트·이벤트는 고정 파일명만 읽음.
