## 확인하는 곳

- 로컬 대시보드: http://127.0.0.1:8767 — 시나리오 실행 → 초기 입력·툴 인수/결과 → DB 저장 근거 → 기능별 화면 JSON.
- 실행 기록: `D:/Github/v2-cloud-runs/{analysis_id}`. `quality_review.md`는 실제 문장을 읽은 검수 결과.
- 개발 RDS에는 분석·본문·업데이트·요인·수치 카드·툴 감사가 저장됨. 로컬 JSON을 DB 대신 보여주는 방식이 아님.
- 스키마 변경은 PR #970과 schema-migrate 실행 `36424348703`으로 개발 DB에 반영. 신규 서버·수집기·운영 스케줄은 배포하지 않음.
- 자동 검사는 `tests integration_tests` 전체 실행. 중복 요청, 실패 시 롤백, 감사 저장 실패, 재시작, 분석 이력 혼입, 미래 자료, 수치 카드 근거 위조를 검사.
- 실제 개발 DB에서도 부적격 근거 실행 `3c3d53a0035445fd9e1eec0834e38f03`의 발행 차단 확인. 실패 분석·툴 감사 27건은 남고 본문 행·화면은 없음. 이후 편집 툴에 사전 ID 검사를 추가해 같은 에이전트가 정정할 기회를 제공.

## 최종 재생 기록

각 ID로 대시보드에서 입력·호출·출력·문장 검수를 조회한다. 원문을 손으로 고치지 않고 규칙 보완 후 새 실행으로 확인했다.

- 최종 10건: 실제 개발 RDS의 툴 감사 184건·전망 수치 카드 100행 확인. 각 실행의 DB 재조립 결과와 저장 후 화면 JSON 일치.
- 수정 확인: 요약의 시점 역전·예정 사실 확정, 유지한 PER/PBR 근거 누락, 장중 이전 RSI 재사용이 최종 표본에서 재발하지 않음.
- 브라우저: 기능별 5종 전망 조회·LaTeX·JSON 색 구분·품질 기록 우선 표시·모바일 너비·JavaScript 오류 없음 확인.
- 표본 검수 결과이며 모든 향후 자유문장의 무오류를 보장하지 않음. 실패 샘플과 검수 이유도 대시보드에 남김.

## 완료 범위와 남기는 제한

- 실제 종목명은 사용하지만 뉴스·가격·수급·재무·매크로는 합성 자료. 실제 시장의 과거 수익이나 전망을 재현한 결과가 아님.
- 전망은 9월 14~18일 08:30, 장중 설명은 9월 14일 10~14시의 고정 재생 시점. 같은 과거 자료를 실행마다 바꾸지 않음.
- 5년 PER 밴드는 계산 정의와 원천 범위가 미확정이므로 생략. 누락을 0으로 표시하지 않음.
- 실패한 품질 샘플도 보존. 실행 완료와 문장 품질 합격을 구별하며, 수치·ID 테스트가 자유문장 의미의 정확성을 보장하지 않음.

## 실행기 계약

- Claude Agent SDK가 DeepSeek 모델과 등록한 MCP 툴만 호출. 자동 압축 활성화.
- 공통 실행기는 입력·프롬프트·툴 목록·최종 JSON 스키마를 인수로 받음. 화면 종류의 판단·계산은 하지 않음.
- 툴 콜백은 `AuditedExecution.call`을 사용. DB에 커밋된 반환만 모델에 전달.
- 초기 입력, 시스템 프롬프트, 툴 목록, SDK 이벤트, 최종 응답을 로컬 실행 폴더에 기록. API 키는 기록에서 제거.
- SDK 실패·시간 초과·최종 스키마 불일치는 실패. 응답이 없는 경우 성공으로 바꾸지 않음.
- 최종 문장의 의미 평가는 자동 코드 판정에 넣지 않음. 검수자가 메타 규칙으로 확인.
