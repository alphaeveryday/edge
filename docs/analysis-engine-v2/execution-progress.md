# 목데이터부터 최종 화면까지

목데이터로 실제 DeepSeek 에이전트와 계산 툴을 실행하고, 개발 RDS에 저장한 행으로 화면 계약을 조립한다. 자동 검사는 외부 모델 없이 수행하고, 마지막에 실제 모델 출력과 브라우저를 검수한다. 원천 수집·실제 매크로 연결은 제외한다.

| 작업 | 상태 | 완료 증거 |
|---|---|---|
| 1. 에이전트 호출·감사 저장 연결 | 진행 | |
| 2. 목 시나리오·두 요청 진입점 | 대기 | |
| 3. 뉴스·구성종목 툴 | 대기 | |
| 4. 개별·가중 수급 툴 | 대기 | |
| 5. 차트 툴 | 대기 | |
| 6. 매크로 툴 | 대기 | |
| 7. 개별·가중 밸류 툴 | 대기 | |
| 8. 오늘 움직임 저장·조립 | 대기 | |
| 9. 전망 최초 저장·조립 | 대기 | |
| 10. 전망 수정·오늘 업데이트 | 대기 | |
| 11. 요인 상세 저장·조립 | 대기 | |
| 12. 통합·실제 모델 품질 검수 | 대기 | |

## 실행기 계약

- Claude Agent SDK가 DeepSeek 모델과 등록한 MCP 툴만 호출. 자동 압축 활성화.
- 공통 실행기는 입력·프롬프트·툴 목록·최종 JSON 스키마를 인수로 받음. 화면 종류의 판단·계산은 하지 않음.
- 툴 콜백은 `AuditedExecution.call`을 사용. DB에 커밋된 반환만 모델에 전달.
- 초기 입력, 시스템 프롬프트, 툴 목록, SDK 이벤트, 최종 응답을 로컬 실행 폴더에 기록. API 키는 기록에서 제거.
- SDK 실패·시간 초과·최종 스키마 불일치는 실패. 응답이 없는 경우 성공으로 바꾸지 않음.
- 최종 문장의 의미 평가는 자동 코드 판정에 넣지 않음. 검수자가 메타 규칙으로 확인.
