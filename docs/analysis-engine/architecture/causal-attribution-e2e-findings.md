## 3. 발견 목록

### 하네스 버그 (수정 완료)

| # | 증상 | 조치 |
|---|---|---|
| **P1** | `"B": "same_event_type:COMPANY.CONTRACT.SIGNING"` 로 써서 검정 3/5 사망 | `normalize()` 관대 파싱 + 프롬프트에 맞음/틀림 예시 |
| **P2** | 카드에 `event_id` 가 없어 에이전트가 타임스탬프를 인용 → 추적 불가 | `to_prompt()` 에 `id=` 노출 |
| **P6** | 24사건 카드에서 응답 JSON 잘림 | `max_tokens` 16000 + `salvage()` 부분 복구 |
| **P7** | 채점기가 `pr_routine` 을 버킷 매핑에 안 넣어 구조적 0% | 대응 없는 라벨은 채점 제외 (일치율 17% → 30%) |

### 설계 결함

#### D1 · 검정이 가설을 치지 않는다 — **가장 심각**

018260 셀에서 `A=self B=all q=idio_pp` 가 $+3.32$ bit 를 벌었다. 그 bit 는 *"채권 발행이 원인"*
가설을 전혀 지지하지 않는다 — 단지 그날 많이 빠졌다는 사실이다. 카드가 이미 $Y$ 를 보여줬으므로
$\Pr(\text{관측}\mid h)=\Pr(\text{관측}\mid\neg h)$ 이고 0 bit 여야 한다.

**조치 1 — 대수 층 거부.**

$$B=\texttt{all}\ \wedge\ q\in\{\texttt{idio\_pp},\texttt{abs\_idio\_pp},\texttt{event\_count},\texttt{onset\_is\_open\_burst}\}\ \Rightarrow\ \textbf{거부}$$

§6.2.4 동어반복 금지의 실행 가능한 정의다. 문서의 *"카드 밖 관측을 인용하라"* 만으로는
`B=all` 이 형식적으로 카드 밖이라 통과한다.

**조치 2 — 반사실 대조군 신설.** 이것이 빠진 것이 D1 의 진짜 원인이다.

| 신설 $B$ | 크기 | 뜻 |
|---|---:|---|
| **`no_event`** | **88셀** | 사건이 하나도 없던 셀 — **진짜 반사실 대조군** |
| `has_event` | 130셀 | 사건이 있던 셀 |
| `same_onset` | 60~120셀 | 같은 장중 발현 |

*"사건이 원인"* 을 치는 유일한 방법은 **사건이 없던 셀들의 $Y$ 분포와 비교**하는 것인데,
1회전 대수에는 그 대조군이 없었다. 검정이 무력했던 이유가 이것이다.

**조치 3 — 온톨로지를 $q$ 로 승격.**

```
n_types · n_roles · frac_first_in_thread · frac_complete · hours_since_last_event
has_type(event_type=...) · measure_role(role=CONTRACT_VALUE ...)
```

이제 *"큰 계약이라 컸다"* 가 `q=measure_role role=CONTRACT_VALUE B=same_event_type` 으로,
*"신규 사건이라 컸다"* 가 `q=frac_first_in_thread B=has_event` 로 표현된다.
**뉴스 온톨로지가 처음으로 검정 층에 연결된다.**

부수 효과로 대조군 표본 부족(거부의 84%)이 거의 사라진다 — 새 대조군이 전부 $n \ge 60$ 이다.

#### D2 · 에이전트가 실행되지 않은 검정을 인용해 배제를 주장한다

**152셀 중 18셀(12%)에서 적발**됐다. `verdict.rejected_nulls` 가 명세 오류로 거부된 검정을
근거로 대안을 죽였다고 보고했다.

**조치:** `_validate_verdict()` 가 실행·통과 여부를 대조하고 아니면 `invalid_rejections` 로 격리.
$\log\Lambda$ 도 보고값이 아니라 실행 결과로 덮어쓴다.

> 자기신고를 검증 가능한 것으로 바꾸는 설계인데 **verdict 만 자기신고로 남아 있었다.**

#### D3 · 대조군 표본이 구조적으로 부족했다

골든셋은 *"크게 움직인 셀"* 219개라 **패널이 아니다.** `same_day` 3~10셀, `same_symbol` 0~2셀.
조치 2가 완화했으나 근본 해결은 전체 패널 적재다.

#### D4 · 경쟁가설을 세우기만 하고 죽이지 못한다

열거 중앙 **7개**, 유효 배제 중앙 **0개**. 생성은 잘하는데 배제가 안 된다 — D1 의 귀결이다.

## 4. 에이전트가 스스로 요구한 결손 데이터

설계 의도(`unresolved` 의무)대로 작동했다. **1,493건**이 올라왔고 이것이 데이터 로드맵이다.

| 요구 | 건수 |
|---|---:|
| **거래량** | **263** |
| **외국인순매수** | **150** |
| **기관순매수** | **142** |
| 일중분산비 | 101 |
| 지수수익률 | 67 |
| 피어잔차 | 66 |
| 업종 | 63 |
| 사건수량 · 애널리스트목표가 · 컨센서스 | 45 · 33 · 33 |

상위 3개가 전부 **수급**이다. 사건 없는 88셀에서 에이전트가 반복해서 *"수급으로 설명될 것 같은데
측정할 수가 없다"* 를 보고했다. **무엇을 먼저 수집해야 하는지가 추측이 아니라 측정으로 나왔다.**

`신규성`(25) · `사건유형`(20) 요구는 데이터가 아니라 **대수 표현력** 요구였고 조치 3이 해결한다.

`unresolved` 를 한 건도 안 낸 셀은 57/219 — 설계상 *"탐색이 카탈로그 안에만 머물렀다"* 는 신호다.
