# 2단계 — 경험 확장과 구간 소비

> 진입 조건은 `roadmap.md` §3 (PR1–PR4). **PR4 미달이면 진입 금지** — 이론이 틀렸으면 틀린 위에 짓는 것이다.
> **2단계는 확장이지 재구조화가 아니다.** 스키마·규율·루프는 1단계에서 확정된 것을 그대로 쓴다.

---

## 0. 무엇이 달라지나 — 그것뿐

| | 1단계 | 2단계 |
|---|---|---|
| 밴드 출처 | 연역 상한만 | **연역 상한 ∧ 적합된 $\Pi_\ell$** |
| 링크 status | 전부 `proposed` | **승격 게이트 가동** → `verified` |
| 범위(tier) | null | **범위 확장 가동** |
| 반박 | 연역 위주 | **+ 재표집 배터리 (DoWhy 4종)** |
| 좌표계 | 시장·피어 2-leg | **DID · Double ML 검토** |
| 지속률 $\rho$ | 기록만 | **두 점가설 우도비 채점** — 유일한 out-of-sample |

**추가되는 파이프라인은 하나다: 구간 적합 루프.** 나머지는 기존 단계의 입력이 풍부해지는 것이다.

---

## 1. 구간 적합 루프

### 1.1 무엇을 추정하나

링크별 **예측 구간**. 계수가 아니다 — 형태는 자유이고 인터페이스만 고정된다(theory §5.2).

$$\Pi_\ell:\quad p\big(\text{to}\mid\text{from},z\big)\ \longrightarrow\ [\underline y,\overline y]$$

체인 전체가 아니라 **링크 단위**다. 이것이 비정형 사건이 정형 계수를 재사용하는 경로다(theory §5.1).

### 1.2 표본 격리 — 두 규칙

| 규칙 | 내용 |
|---|---|
| **원재료에서 적합** | 영수증의 `raw.node_values` 만 사용. **LLM 예상(`share_band`)은 회귀변수가 아니다** |
| **실패도 포함** | 가설이 죽어도 관측쌍은 관측된 것. 통과 여부로 표본을 거르지 않는다 |

이 둘이면 순환이 없다. 1단계에서 걱정했던 되먹임은 **예상을 회귀변수로 놓았을 때만** 발생하는 정식화 오류였다.

### 1.3 오염 라벨에 따른 사용처

| `contamination` | $\Pi_\ell$ 적합 | 지속률 $\rho$ | 미설명 분포 |
|---|:--:|:--:|:--:|
| `single_cause` | ✅ | ✅ | ✅ |
| `multi_cause` | ❌ **배분이 우리 판단** | ✅ | ✅ |
| `confounded` | ❌ | ⚠️ | ✅ |

**다원인 날의 `share_final` 은 관측이 아니라 우리 판단이다.** 계수 추정에 섞으면 우리가 만든 편향을 우리가 측정하게 된다.

### 1.4 배포 — 동결과 버전

```
단일원인 영수증  →  β_ℓ^{vk} 추정  →  동결  →  밴드 축소에 사용
                                              ↓
                                    영수증에 beta_version 기록
```

| 규칙 | 왜 |
|---|---|
| **버전 동결** | 실행 중 갱신 금지. 같은 실행이 같은 계수를 본다 |
| **버전 기록** | 각 영수증이 어느 계수를 썼는지 남긴다. 소급 재분석의 전제 |

### 1.5 부작동 관측이 없으면 계수를 쓸 수 없다

1단계 표본 B칸(사건 있음 · 움직임 없음)이 없으면

$$\hat\Pi_\ell\ \text{는}\ \Pr(\cdot\mid\text{가격이 움직였음})\ \text{조건부로 적합된다}$$

**결과를 조건으로 잡은 것** — 콜라이더 편의이고 구간 중심이 체계적으로 **과대추정** 쪽으로 밀린다. 설명 코퍼스가 원래 갖고 있던 바로 그 편의를 재생산한다.

**roadmap PR2(각 칸 ≥ 40건)가 이 항목의 게이트다.**

## 2. 승격 — `proposed` → `verified`

| 단계 | 요구 | 판정 |
|---|---|---|
| 1 | 표본 $n_\ell \ge 30$ (단일원인) | 자동 |
| 2 | **교정** — 주장한 90% 구간이 out-of-sample 에서 90% 를 덮는가 | 자동 |
| 2b | **첨예도** — 덮는다는 전제 하에 충분히 좁은가 | 자동 |
| 3 | **정의역 밖 오용 0건** | 자동 |
| 4 | 공변량 하강 후 **잔여 이질성 없음** — 업종 더미 추가 시 잔차 유의 감소 없음 | 자동 |

**4가 세분 여부를 판정한다.** 잔차가 유의하게 줄면 하강이 실패한 것이고, **그때 비로소** 링크를 쪼갠다(theory §5.3). 선험적 세분은 하지 않는다.

**취향이 개입할 자리가 없다 — 네 단계 모두 코드가 판정한다.**

### 2.1 승격의 효과

| | `proposed` | `verified` |
|---|---|---|
| 밴드 | 연역 상한만 (넓음) | 적합된 $\Pi_\ell$ 예측 구간 (좁음) |
| 심각성 기여 | 낮음 | 높음 |
| 재사용 | 매번 제안 | 라이브러리에서 조회 |

**제안 링크 목록이 곧 연구 의제다** — 자주 제안되는데 미승격인 링크가 다음에 무엇을 봐야 하는지 알려준다. 원장이 자기 로드맵을 생성한다.

## 3. 범위 확장 — $T_1\to T_2\to T_3$

| Tier | 링크가 재현되는 범위 | 판정 |
|---|---|---|
| $T_1$ | 이 사례에서만 | 승격 직후 기본값 |
| $T_2$ | 준거집합 $R$ 내에서 | $R$ 로 좁혀도 $\Pi_\ell$ 의 교정이 유지됨 |
| $T_3$ | 환경(다른 ETF·업종) 넘어 | 환경 분할 후에도 유지 |

체인은 최약 링크만큼 강하므로

$$\text{tier}(h)=\min_{\ell\in\pi}\ \text{tier}(\ell)$$

**설명의 tier 를 별도로 판정하지 않는다.** 링크 tier 의 집계다. 검증 링크 3개 + 제안 링크 1개짜리 설명이 왜 $T_1$ 인지가 자동으로 설명된다.

## 4. 반박 배터리 — 재표집형 추가

1단계의 연역 배터리는 **배제**하고, 여기서 추가되는 것은 **강건성**을 잰다.

| 반박 | 하는 일 | 통과 조건 |
|---|---|---|
| **placebo treatment** | 원인을 무작위로 바꿔도 효과가 나오나 | 안 나와야 |
| **random common cause** | 무작위 교란을 넣어도 추정이 안 변하나 | 안 변해야 |
| **data subset** | 부분표본에서 안정적인가 | 안정 |
| **unobserved confounder** | 미관측 교란에 얼마나 취약한가 | 민감도 문턱 이내 |

**DoWhy 표준이고 인용 가능하다.** 새로 발명하지 않는다.

### 4.1 결합 귀무 — 합산의 미봉 해소

재표집형 도구가 둘 이상 등록되면 **같은 시드로 함께 표집**한다.

$$\theta^{(m)}=\big(\theta_1^{(m)},\dots,\theta_J^{(m)}\big),\qquad m=1..M$$

결합 분포가 **구성으로** 나오므로 독립 가정이 필요 없다(theory §6.5). 다중성은 Westfall–Young maxT 로 상관 구조를 반영해 통제한다.

$$\tilde p_j=\frac{1}{M}\sum_m \mathbb{1}\Big[\min_{j'}p_{j'}^{(m)}\le p_j\Big]$$

**$M$ 이 증거 상한을 정한다** — $\log\Lambda\le\log_2(M{+}1)$. 계산 예산이 곧 인식론적 한계이고, 상한에 닿으면 게시물에 명시한다.

### 4.2 교정 — 귀무를 가정에서 실측으로

무사건일(1단계 표본 D칸)에서 $\widehat{\Pr}(p\le\alpha)\overset{?}{=}\alpha$ 를 확인한다.

| 결과 | 조치 |
|---|---|
| 맞음 | 명목 귀무 사용 |
| 안 맞음 | **귀무 교체** — 경험 위약 분포로 갈아탄다. 승격이 아니라 **원래 가정이 틀렸다는 뜻**이고 lineage 에 기록한다 |

**위약일이 사건일과 교환가능해야 한다** — 사건은 변동성 큰 날에 몰린다. 조건부 매칭(변동성·거래량·체제)으로 완화하고 공변량 균형으로 검사하지만, 완전히 없앨 수 없다.

## 5. 좌표계 개선 — 그리고 Lean 재검토 지점

$\Pi_\ell$ 의 폭은 **잔차 정의의 조잡함**에서도 온다. 좌표계를 개선하면 위약 분포가 좁아지고 **같은 관측이 더 많은 bit** 를 낸다.

$$\Delta\log\Lambda=\log_2\frac{\Pr_{\text{개선 전}}(\theta\ge\theta^{\mathrm{obs}})}{\Pr_{\text{개선 후}}(\theta\ge\theta^{\mathrm{obs}})}$$

| 도구 | 걷어내는 것 |
|---|---|
| 시장·피어 2-leg (현행) | 시장 공통 성분 |
| **DID** | + 그룹 고정효과 |
| **Double ML** | + 고차원 교란 $g(X)$ (Neyman 직교 + cross-fitting) |
| 합성대조 | + 단위별 가중 반사실 |

**"이 도구를 도입할 가치가 있는가"가 취향 논쟁이 아니라 측정이 된다** — 같은 사건 집합에서 밴드를 얼마나 좁혔는지 bit 로 답한다.

### 5.1 Double ML 은 제약이 아니라 좌표계다

통제변수 집합 $X$ 를 가설이 고르게 하면 $X$ 는 **손잡이가 아니라 구멍**이다 — 느슨하게 해도 증거가 안 깎이고 잘 고르면 커진다. 그래서 $X$ 는 **관찰 단계에서 가설과 무관하게 봉인**한다.

### 5.2 여기가 Lean 재검토 지점이다

조정집합이 생기는 순간 **collider · mediator 통제 오류**가 가능해진다. 이건 그래프 이론적 기계 오류이고 LLM 이 흔히 틀리며, 코드가 답할 수 있으면 코드가 답해야 한다.

| | 상태 |
|---|---|
| d-separation 건전성 형식화 | 존재 (arXiv 2606.20351) |
| **완전한 do-calculus · 백도어 기계화** | **미발표** — 우리가 쓴다면 신규 작업 |

**1단계에서는 과잉이었다**(체인이 짧은 경로지 그래프가 아니므로). 2단계 §5 에서 조정집합이 도입될 때 **재검토**한다. 계획된 항목이 아니라 조건부 항목이다.

## 6. 지속률 $\rho$ 채점 — 유일한 out-of-sample

두 메커니즘이 서로 다른 **점 예측**을 낸다 — 영구는 $\mathrm{CAR}_{post}=0$, 일시는 $-Y_t$. 진짜 우도비가 나오고(theory §6.1.1), $T{+}n$ 에 **비용 0으로 채점**된다.

| | 값 |
|---|---|
| 라벨 비용 | **0** |
| 지연 | $T{+}n$ (n = 5–20 거래일) |
| 용도 | 프롬프트·표본설계·계수 A/B 의 **유일한 판정 지표** |

이 문제에서 진짜 out-of-sample 인 라벨은 이것뿐이다.

## 7. 2단계에서도 미해결

| # | 항목 | 2단계 계획 |
|---|---|---|
| **U1** 과잉결정 · 선점 | 악재 둘이 각각 단독 충분하면 but-for 실패, share 합 초과 | **미정.** Chockler–Halpern 책임도 검토. 당장은 `contamination=multi_cause` 로 격리하고 계수 추정에서 제외 |
| **U2** $\epsilon$ 전파 | 곱셈 누적으로 밴드가 넓어짐 | MC 합성이 $\approx2$ bit 완화. 1단계 PR4 로 걸러짐 |
| **U3** 메커니즘을 bit 로 못 잼 | Russo–Williamson 절반 구현 | 정렬 2순위 유지. 환율을 발명하지 않는다 |
| **U5** 사건 커버리지 | 부작동 해석 오염 | 뉴스 파이프라인 커버리지 개선이 선행 |

**U1 이 2단계의 최대 리스크다.** 다원인 사례를 계수 추정에서 계속 배제하면 표본이 줄고, 포함하면 오염된다. 표본이 모자라면 U1 을 먼저 풀어야 한다.
