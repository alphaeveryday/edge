# 인과 귀속 — 단계 분할

> 이론은 `causal-attribution-theory.md`, 실행 계약은 `phase1.md`·`phase2.md` 가 소유한다. **이 문서는 경계와 승격 조건만 소유한다.**

---

## 0. 분할 원칙 — 왜 이렇게 자르는가

> **1단계에서 모든 구조와 틀이 잡혀 있어야 한다. 2단계는 확장이지 재구조화가 아니다.**

이 요구가 절단선을 결정한다.

| | 1단계에 있어야 함 | 근거 |
|---|---|---|
| **스키마** | 링크·영수증 **완전한 형태** | 기록 안 한 데이터는 **소급 불가**. 모델 형태는 미룰 수 있고 스키마는 못 미룬다 (theory §5.5) |
| **규율** | 네 규율 **전부** | 나중에 붙이면 그 이전 원장이 전부 감사 불가 |
| **루프** | 제출 → 정련 ↔ 반증 **3단 전부** | 단계를 나중에 끼우면 커밋 순서가 깨진다 |
| **검증** | VC1 연역 배터리 **전부** | 0세대 밴드의 유일한 출처 |
| **노드 사전** | 관측 가능성 레지스트리 | 없으면 하강 대신 **세분으로 흐른다** (theory U6) |
| **표본** | 2×2 층화 **전부** | 한 칸만 돌리면 계수가 영구히 편의 |

반대로 **2단계로 미룰 수 있는 것**은 하나의 성질을 공유한다 — **누적된 영수증이 있어야만 의미가 생긴다.**

---

## 1. 절단선

```
1단계 ─ 구조 완비 · 0세대 원장 생산
        VC1 연역 + VC2 규율 완비,  VC3 최소
        밴드 출처: 연역 상한만
        링크 라이브러리: 구조만 있고 내용은 비어 있음

        ↓  승격 조건 (§3)

2단계 ─ 경험 확장 · 계수 소비
        VC3 확장 + 계수 추정 루프
        밴드 출처: 연역 상한 ∧ 축적된 β_ℓ
        링크 라이브러리: 승격 게이트 가동
```

**핵심: 0세대는 데이터 없이 돈다.** 연역은 항등식·상한·역산만 있으면 되고 측정을 요구하지 않는다(theory §6.3). 이것이 부트스트랩의 시드이고, 1단계가 자립 가능한 이유다.

## 2. 단계별 배치

| 항목 | 1단계 | 2단계 | 왜 |
|---|:--:|:--:|---|
| 전수 관찰 (모든 종목 × 모든 일자) | ● | | 산술이라 비용이 없다 |
| 2×2 층화 표본 | ● | | 한 칸만 돌리면 $\beta$ 가 영구 편의 |
| 링크 스키마 · 영수증 스키마 | ● | | 소급 불가 |
| 네 규율 (①②③④) | ● | | 나중이면 그 이전 원장이 무효 |
| 제출 → 정련 ↔ 반증 | ● | | 커밋 순서의 뼈대 |
| **연역 배터리** (항등식·상한·역산·차원·모순·시간) | ● | | 0세대 밴드의 유일한 출처 |
| 보존량 예산 · 미설명 기록 | ● | | 프레임 반증 지표(theory §10.2 4번) |
| 링크 라이브러리 **구조** | ● | | 스키마의 일부 |
| 심각성 산출 (`breaker` 문턱) | ● | | 장식적 기각조건 차단 |
| 게시 (production) | ● | | confidence 상한으로 통제 |
| | | | |
| **승격 게이트 가동** (proposed→verified) | | ● | 표본 $n$건 필요 |
| **구간 적합 $\Pi_\ell$** | | ● | 깨끗한 영수증 축적 필요 |
| 구간 기반 밴드 축소 | | ● | 적합이 있어야 함 |
| **범위 확장** $T_1\to T_3$ | | ● | 재현 표본 필요 |
| 반박 배터리 전체 (DoWhy 4종) | | ● | 위약 표본 필요 |
| 결합 귀무 (같은 시드 공동 표집) | | ● | 재표집형 도구가 등록된 뒤 |
| 좌표계 개선 (DID · Double ML) | | ● | 조정집합 · 형식검증 재검토 동반 |
| 지속률 $\rho$ 채점 | | ● | $T{+}n$ 라벨 축적 |
| 과잉결정 처리 (U1) | | ● | 미해결. 2단계에서도 미정 |

## 3. 단계 이행 조건 — 1단계에서 2단계로

**넷 다 충족해야 넘어간다.** 하나라도 미달이면 1단계를 계속 돌린다.

| # | 조건 | 문턱 | 왜 이 수치인가 |
|---|---|---|---|
| **PR1** | 깨끗한 영수증 (단일원인 · 접지 링크 ≥ 2) | **≥ 200건** | 링크 하나당 $n{\ge}30$ 을 상위 5–6개 링크에서 확보 |
| **PR2** | 2×2 네 칸 모두 채워짐 | 각 칸 **≥ 40건** | 부작동 칸이 비면 $\beta$ 상향편의 제거 불가 |
| **PR3** | 연역 배터리 통과율이 안정 | 최근 100건 통과율 변동 **< 10%p** | 게이트가 아직 튜닝 중이면 원장이 이질적 |
| **PR4** | **U2 반증 안 됨** — 합성 밴드가 자릿수를 넘지 않음. **MC 합성 기준**(구간 산술 아님) | 밴드폭 / 관측 **< 10×** 인 사례 **≥ 60%** | 항상 넘으면 프레임 실패 → 2단계 진입 금지 |

**PR4 가 게이트다.** 이론이 틀렸으면 2단계는 틀린 위에 짓는 것이다.

## 4. 이게 작동하는지 재는 것 셋

단계와 무관하게 계속 본다.

| 지표 | 해석 |
|---|---|
| **미설명 잔량의 분포** | 안 줄면 **사건 기반 설명 프레임 자체가 틀림** |
| **링크 구간 폭** $\epsilon_\ell$ | 안 줄면 링크 분해가 틀림 (세분이 필요하거나 링크가 잘못 잘림) |
| **지속률 $\rho$ 적중률** | 유일한 out-of-sample. 2단계부터 측정 |

---

## 5. 비범위 — 두 단계 어디에도 없는 것

| | 왜 |
|---|---|
| **횡단면 순위 · 법칙화 · 일반화** 를 설명 대상으로 | 나중 목표. 순위는 증거로만 쓴다 (theory §2.4) |
| **예측** | 목적이 설명이다. 예측 성능은 지표가 아니다 |
| 인사이트 **발견** | 별도 루프. 이 파이프라인은 제약을 생산할 뿐 소비하지 않는다 |
| 게시 문안 품질 · 가독성 | 개연성만 최적화한다 |
| Lean 형식검증 | 2단계 좌표계 개선 시 **재검토** 대상이지 계획된 항목이 아님 |

## 6. 위험과 중단 조건

| 위험 | 관측 | 조치 |
|---|---|---|
| **U2 발화** — 밴드가 항상 자릿수 초과 | PR4 미달 지속 | **중단.** theory §6.4 재설계 |
| 미설명이 대부분 | 미설명 중앙값 > 70% | 사건 기반 프레임 기각 검토 |
| 링크가 재사용 안 됨 | 제안 링크 비율이 안 떨어짐 | 링크 분해 수준 재검토 (theory §5.3) |
| 사건 커버리지 구멍 (U5) | 부작동 칸의 커버리지 플래그 불량률 높음 | 뉴스 파이프라인 선행 |
| 구간 자기수렴 | 버전 간 급변 없이 폭만 축소 | 적합 표본 격리 규칙 위반 점검 (theory §10.3) |
