## 1. 문제의 성격이 나머지를 결정한다

### 1.1 우리 문제는 셋 중 세 번째다

| | 묻는 것 | 표준 도구 |
|---|---|---|
| 인과 **발견** | 어떤 변수가 어떤 변수에 영향을 주나 | PC · GES · FCI |
| 인과 **추정** | X의 Y에 대한 평균 효과는 얼마인가 | DID · IV · Double ML |
| **인과 귀속** | **이 사례에서 이 결과가 왜 이렇게 나왔나** | ← 우리 |

세 번째는 **개별 인과**(token causation)다. 앞의 둘과 논리가 다르다. 사고조사·법정 인과·역사학이 같은 종류다.

### 1.2 세 조건이 동시에 성립한다

- **개입 불가** — 실험이 없다
- **$N{=}1$** — 사건 1건, 반복 없다
- **반사실 관찰 불가** — "없었다면"을 볼 수 없다

셋이 겹치면 표준 인과추론 도구가 대부분 무력하다. **구조를 데이터에서 도출할 알고리즘이 존재하지 않는다.** 이 한 줄이 뒤의 설계 전부를 강제한다.

### 1.3 무엇을 포기하고 무엇을 지키는가

| | |
|---|---|
| **포기** | "이 설명이 참일 확률" — 사전확률 없이 구할 수 없고, 사전을 정직하게 정할 방법이 없다 |
| **지킴** | "이 설명이 대안보다 얼마나 엄한 시험을 통과했는가" — 사전 없이 구할 수 있다 |

이 교환 하나가 §6·§7 전부를 결정한다.

## 2. 설명 대상 — 목적 통계량 셋

$$\text{explanandum}=\big(\underbrace{s}_{\text{부호}},\ \underbrace{m_1}_{\text{1차 모멘트}},\ \underbrace{m_2}_{\text{2차 모멘트}}\big)$$

### 2.1 부호 $s$ — 표적이지 증거가 아니다

이 종목이 오를지 내릴지. **사용자가 가장 원하는 것이지만 증거로는 1 bit** 다. 표적과 증거를 갈라서 쓴다.

### 2.2 1차 모멘트 — 수준과 지속

두 성분이다.

| | 정의 | 뜻 |
|---|---|---|
| **수준** | $Y_t$ | 사건 당일 잔차 |
| **지속** | $\rho=\dfrac{\mathrm{CAR}(t{+}1,\,t{+}n)}{Y_t}$ | 반응이 남는가 되돌아오는가 |

| $\rho$ | 메커니즘 |
|---|---|
| $\approx 0$ | **영구 재평가** — 정보 |
| $\approx -1$ | **완전 일시** — 순수 유동성 |
| $(-1,0)$ | 부분 되돌림 |
| $>0$ | **연속** (underreaction · PEAD) |

**이진 되돌림 플래그를 쓰지 않는다.** 플래그는 최대 1 bit 이고 문턱이 임의이며 네 번째 체제($\rho>0$)를 표현조차 못 한다 — 연속량의 조악화다.

**그리고 이것이 $\log\Lambda$ 의 가장 깨끗한 용례다**(§6.1) — 두 메커니즘이 서로 다른 **점 예측**을 내므로 진짜 우도비가 나온다.

> 실무: $\rho$ 는 비율이라 $Y_t\to0$ 에서 분포가 망가진다. **단일 사건은 두 점가설 우도비로 재고**, 표본 간 관계는 $\mathrm{CAR}$ 을 $Y_t$ 에 회귀한 기울기로 잡는다.

### 2.3 2차 모멘트 — 변동성 반응

**별개 차원이다.** 규제 리스크 제기 같은 사건은 **평균은 그대로 두고 분산만 올린다.** 1차로는 안 잡힌다.

측정: 사건 후 실현분산 / 추정창 분산의 비. 귀무는 1.

### 2.4 설명량 예산 — 1차만 등식이다

$$\underbrace{\sum_k \text{share}_k+\text{미설명}=Y}_{\textbf{1차 — 등식}}\qquad
\underbrace{\mathrm{Var}\Big(\sum_k\Big)=\sum_k\mathrm{Var}_k+2\!\!\sum_{j<k}\!\mathrm{Cov}_{jk}}_{\textbf{2차 — 등식 아님}}$$

수익률은 가법적이라 1차 예산은 **깨끗한 보존량 제약**이다. 분산은 공분산 항 때문에 **부등식이거나 독립 가정을 요구**한다. 2차 표적의 예산은 1차만큼 강한 제약이 아니고, 그렇게 써야 한다.

1차 예산의 귀결:

- 쉬운 1pp 만 설명하고 나머지 3pp 를 안 보는 것이 불가능하다
- 경쟁 가설은 배타적 라이벌이 아니라 **몫을 다투는 공동 기여자**다
- 몫을 크게 주장하면 더 엄한 크기 검사에 노출되고, 작게 주장하면 스스로 부차적이라고 인정한다

**설명량 예산이 반-Goodhart 의 본체다.** 과대주장이 자동으로 비싸다.

### 2.5 지금 목표가 아닌 것

**횡단면 순위**와 **법칙화·일반화**는 나중 목표다. 순위는 여전히 *증거*로 쓰지만 *설명 대상*이 아니다. 측정 편의성을 목적으로 승격시키지 않는다.

## 3. 인과 판정의 축 — 셋이 아니라 둘

| | 지위 | 역할 |
|---|---|---|
| **차이생성** | 축 1 — **주장의 형식** | $e$ 의 유무가 $Y$ 를 바꾸는가 |
| **반사실** | 축 1의 **측정 규약** | "없었다면"을 만들어 보이는 것 |
| **메커니즘** | 축 2 — **독립** | 어떤 실체와 활동이 $e$ 에서 $Y$ 로 가는가 |

둘 다 필요하다(Russo–Williamson). 의학에서 온 논제를 **유비로 채택**한 것이지 우리 도메인에서 증명된 것이 아니다.

| 한쪽만 | 결과 |
|---|---|
| 차이생성만 | 상관에 서사를 붙인 것. 교란 배제 불가 |
| 메커니즘만 | 그럴듯한 이야기. 크기·시점 검증 없음 |

### 3.1 두 축은 대칭이 아니다 — 그리고 그 처리가 설계의 핵심 선택

차이생성은 bit로 재는데 **메커니즘은 못 잰다.**

> **결정: 메커니즘은 화폐(bit)가 아니라 사전식 정렬의 2순위로 들어온다.**

합산하지 않는 이유: 메커니즘 정교함을 bit로 바꾸는 **환율이 없다.** 환율을 발명하면 그게 $\lambda$ 이고, 가중합의 $\lambda$ 는 정할 방법이 없다. 같은 논리를 두 축 결합에 적용한다.

증거량이 같으면 **짧고 관측된 체인이 이긴다.** 그 이상은 주장하지 않는다.

## 4. 가설의 형식 — 채점 가능성이 형식을 강제한다

$$h=\big\langle\, e,\ i,\ \pi,\ \nu,\ \mathcal{B}\,\big\rangle$$

| 성분 | 뜻 | 빠지면 죽는 것 |
|---|---|---|
| $e$ 앵커 | 어느 사건인가 | 시점 정렬 불가 |
| $i$ 대상 | 어느 종목·스코프까지 | 횡단면 축 없음 |
| $\pi$ 경로 | 메커니즘 체인 = 링크 열 | 하강 경로 없음, 밴드 못 좁힘 |
| $\nu$ 놀람 | 기대 대비 차이의 부호·크기 | 선반영 구분 불가 |
| $\mathcal{B}$ 반사실 기준 | 무엇과 비교하나 | 귀무 정의 불가 |

### 4.1 $\nu$ 가 원인이지 $e$ 가 아니다

예상된 사건은 가격을 움직이지 않는다. 원인은 사건이 아니라 **기대 대비 놀람**이다 — §2가 수익률에 한 일(기준선 차감)을 사건에 하는 것.

### 4.2 추상성 — **체인은 완비, 상수는 미결**

제출 시점의 가설이 가져야 할 수준이다.

| | 자유도 | 정련 가능? |
|---|---|---|
| "악재로 내렸다" | — | ✕ 하강 경로가 없음 |
| **"해지 → 수주잔고↓ → 매출↓ → 이익↓ → 시총↓"** | 링크마다 상수 노출 | ✅ **제출 수준** |
| "850억 → … → −2.1pp (상수 전부 확정)" | 0 | 완료 — 정련할 게 없음 |

그래서 **제출 시 몫은 점추정이 아니라 밴드**다. 상수가 미결이니까. **정련이 밴드를 좁히는 것**이 그 단계의 정의이고, 못 좁히면 설명량을 주장할 자격이 없다.

### 4.3 메커니즘 완비성 — 링크의 세 상태

각 링크는 셋 중 하나여야 한다.

| 상태 | 처리 |
|---|---|
| **observed** | evidence·measure id 로 환원 |
| **derived** | 항등식·정의에서 따라나옴 |
| **assumed** | 선언된 가정. 명시하고 confidence 상한을 내린다 |

넷째(암묵)는 금지다. **말하지 않은 링크가 있으면 그건 가설이 아니라 인상이다.**

## 5. 링크 — 스키마의 단위는 사건이 아니다

### 5.1 왜 링크인가

$$h=\ \ell_1\circ\ell_2\circ\cdots\circ\ell_L$$

사건 단위로 기록하면 사건이 반복될 때만 배운다. **비정형 사건은 정의상 반복되지 않으므로 영원히 배우지 못한다.**

링크 단위로 기록하면 다르다.

| | 정형성 |
|---|---|
| "새 규제 → 매출 감소" | **비정형** — 표본 없음 |
| "매출 감소 → 이익 감소" | **정형** — 표본 많음 |
| "이익 감소 → 시총 감소" | **정형** — 표본 많음 |

> **사건은 비정형이어도 링크는 정형일 수 있다.** 접지 안 된 건 첫 링크뿐이고, 나머지는 축적된 계수가 밴드를 좁혀준다.

이것이 비정형 사건 처리의 유일한 경로이며, **모델의 추상성 한계를 결정하는 단 하나의 설계 결정**이다(§5.5).

### 5.2 링크의 형식 — 전달함수가 아니라 **예측 구간**

$$\ell=\big\langle\ \text{from},\ \text{to},\ \Pi_\ell,\ z\ \text{공변량},\ \mathcal{D}_\ell\ \text{정의역},\ \bar u_\ell\ \text{상한}\ \big\rangle$$

$$\Pi_\ell:\quad p\big(\text{to}\ \big|\ \text{from},\ z\big)\ \longrightarrow\ [\,\underline y,\ \overline y\,]$$

**설계가 요구하는 것은 계수가 아니라 구간이다.** 밴드 축소 산술에는 반폭 $\epsilon_\ell$ 만 들어가고, 그 구간이 스칼라 회귀에서 나왔는지 GBM 에서 나왔는지 시뮬레이터에서 나왔는지 **산술이 구분하지 못한다.**

$$\log\Lambda_\ell=-\log_2\frac{2\epsilon_\ell}{\text{range}}$$

형태에 의존하는 것이 있는지 넷을 검토하고 전부 기각했다.

| 후보 | 판정 |
|---|---|
| 해석가능성 | ✕ 인과 내용은 **링크 위상**(from→to)에 있지 전달함수 형태에 없다 |
| 외삽 | ✕ **정의역** $\mathcal{D}_\ell$ 이 처리한다. 밖이면 형태 무관하게 게이트 실패 |
| 연역 상한 | ✕ $\bar u_\ell$ 은 **정의에서 나오는 별도 선언**. 경험적 적합과 직교 |
| 체인 합성 | ⚠️ 일반 함수는 MC 필요 — 그런데 **MC 가 더 낫다**(§6.4) |

**형태와 무관하게 고정되는 것은 네 줄뿐이다** — 위상 · 정의역 · 연역 상한 · 예측 구간 인터페이스. 스칼라 · 회귀 · GBM · 시뮬레이터 · 항등식+측정오차가 전부 꽂힌다. 도구 인터페이스를 $(\theta,\mathcal{N})$ 로 일반화한 것과 같은 패턴이다.

### 5.3 세분과 하강 — 얼마나 자세히 기술할 것인가

*"반도체이면서 매출 감소"* 로 링크를 쪼개는 것은 **세분**이고, 틀린 선택이다.

| | 조작 | 결과 |
|---|---|---|
| **세분** $\mathcal{P}$ | 링크를 업종별로 쪼갬 | 셀 $N$개 × 각 소표본 → **계수 추정 불가** |
| **하강** $\mathcal{D}$ | 상수를 관측 가능한 값으로 | 셀 하나, **자유모수만 사라짐** |

$$\underbrace{\text{반도체 매출감소}\to\text{이익감소}}_{\text{세분 — 표본 쪼개짐}}\quad\text{vs}\quad\underbrace{\text{매출감소}\xrightarrow{\ m_{\text{관측}}\ }\text{이익감소}}_{\text{하강 — 표본 공유}}$$

마진은 재무제표에서 **관측된다.** 추정할 필요가 없으므로 하강이 공짜다.

> **원칙: 링크는 최대한 일반적으로. 조건은 관측 가능한 공변량으로. 세분은 하강이 실패했을 때만.**

"하강 실패"는 검정 가능하다 — 업종 더미를 넣었을 때 잔차가 유의하게 주는가. 줄면 마진으로 안 잡히는 고유 효과가 있는 것이고, **그때 비로소** 쪼갠다. 세분을 선험적으로 하지 않는다.

### 5.4 링크 라이브러리 — 두 축은 직교한다

$$\ell=\big(\underbrace{\text{검증 상태}}_{\text{proposed}\,/\,\text{verified}},\ \underbrace{\text{적용 범위}}_{T_1\,/\,T_2\,/\,T_3}\big)$$

| 축 | 묻는 것 | 전이의 이름 | 검정 |
|---|---|---|---|
| 검증 상태 | **믿을 만한가** | **승격** | 교정 + 첨예도 |
| 적용 범위 | **어디까지 믿을 만한가** | **범위 확장** | 축을 넓혀도 구간이 유지되는가 |

직교한다 — `verified` 인데 $T_1$ 인 링크(이 준거집합에서만 잘 맞음)가 정상적으로 존재하고, `proposed` 인 링크는 tier 가 아예 없다.

| | `proposed` | `verified` |
|---|---|---|
| 예측 구간 | 연역 상한만 (넓음) | 관측 기반 $\Pi_\ell$ (좁음) |
| 밴드 기여 | 거의 없음 | $\epsilon$ 을 실질적으로 좁힘 |
| 재사용 | 매번 새로 제안 | **라이브러리에서 조회** |

**승격 판정은 적합 계수가 아니라 예측 성능이다** — *maximize sharpness subject to calibration*. 형태에 완전히 무관하고, 스칼라든 신경망이든 같은 시험을 본다.

자동으로 따라오는 것:

1. **설명의 강도가 구성에서 계산된다** — verified 비율이 높을수록 합성 밴드가 좁다
2. **제안 링크 목록이 곧 연구 의제다** — 자주 제안되는데 미승격인 링크 = 다음에 볼 것
3. **판정이 전부 코드다** — 취향이 개입할 자리가 없다

체인은 최약 링크만큼 강하므로

$$\text{tier}(h)=\min_{\ell\in\pi}\ \text{tier}(\ell)$$

### 5.5 추상성 수준은 선택이 아니라 스키마의 귀결

> **모델은 영수증보다 정밀할 수 없다.**

| 기록한 것 | 나중에 적합 가능한 $f$ |
|---|---|
| (사건 유형, 반응) | 유형별 평균 |
| + 경제적 크기 | $\beta_\pi$ 스칼라 |
| + 맥락 공변량 | $\beta(x;\theta)$ · ML |
| **+ 체인의 모든 중간 수량** | **링크별 전달함수 = 구조 모형** |

$f$ 를 산식으로 할지 ML로 할지는 **미뤄도 된다.** 기록 안 한 데이터는 **소급이 불가능하다.**

접지된 체인은 그 자체가 구조 모형의 표본이다. 중간 수량을 기록하면 입출력 쌍이 아니라 **SCM 실현 하나**를 기록하는 것이다.

## 6. 증거 — 심각성

### 6.1 $\log\Lambda$ 의 정체

$$\Lambda_c=\frac{\Pr(c\ \text{통과}\mid h)}{\Pr(c\ \text{통과}\mid\neg h)}$$

**가정 A1.** 참인 가설은 자기가 선언한 시험을 거의 확실히 통과한다 — $\Pr(c\mid h)=1-\delta,\ \delta\ll1$. 그러면

$$\boxed{\ \log\Lambda_c=-\log_2 p_c\ },\qquad p_c\equiv\Pr(c\ \text{통과}\mid\neg h)$$

이것은 Mayo 의 **심각성**(severity)의 로그 단조변환이다 — *$h$ 가 거짓이었다면 거의 확실히 떨어뜨렸을 시험을 통과했는가.*

**실패 분기가 대칭을 만든다.**

$$\log\Lambda_c^{\text{실패}}=\log_2\frac{\delta}{1-p_c}\ \ll\ 0$$

$\delta{=}0.05,\ p_c{=}0.077$ 이면 $-4.2$ bit. 통과하면 $+3.7$, 떨어지면 $-4.2$. **어려운 시험을 선언하는 것이 위험한 이유가 이 두 줄**이고, 이것이 정직성의 유일한 기계적 근거다.

**A1 은 공짜가 아니다.** $\delta$ 가 크면 증거를 과대평가한다. 시험은 **참인 가설이 통과하도록** 설계되어야 한다.

#### 6.1.1 가장 깨끗한 용례 — 두 점가설 우도비

지속률 $\rho$(§2.2)에서는 **두 메커니즘이 서로 다른 점 예측**을 낸다.

$$\text{영구 재평가}:\ \mathrm{CAR}_{post}=0\qquad\qquad\text{완전 일시}:\ \mathrm{CAR}_{post}=-Y_t$$

$$\log\Lambda=\log_2\frac{\Pr\big(\text{관측}\mid\text{영구}\big)}{\Pr\big(\text{관측}\mid\text{일시}\big)}$$

**귀무 대 대립이 아니라 두 경쟁 가설의 진짜 우도비**다. $\hat\sigma_{\mathrm{CAR}}$ 는 추정창에서 나오고 표준 사건연구 도구로 끝난다. 그리고 관측은 $T{+}n$ 에 **비용 0 으로** 도착한다(§10.2).

### 6.2 귀무의 출처는 셋 — 재표집은 그중 하나

| 모드 | 귀무의 출처 | 인터페이스 | 예 |
|---|---|---|---|
| **연역** | 이론 제약 + 측정 정밀도 | $\textsf{sf}(t)$ 해석적 | 항등식 · 상한 |
| **재표집** | 관측을 재배열·재추출 | $\textsf{sample}(s)$ | 순열 · 부트스트랩 · 위약일 · DID |
| **참조 모집단** | 별도 말뭉치의 빈도 | $\textsf{sf}(t)$ 경험적 | 문구가 우연히 등장할 확률 |

따라서 도구 인터페이스는 위약이 아니라 **귀무 하나**다.

$$\text{도구}=\big(\theta,\ \mathcal{N}\big),\qquad \mathcal{N}\in\{\textsf{sample}(s),\ \textsf{sf}(t)\}$$

### 6.3 연역이 주 무기다

**연역은 값을 요구하지 않고 경계를 요구한다.** 접지 0으로 작동한다.

| 무기 | 필요한 것 |
|---|---|
| **항등식** | 정의뿐 |
| **부등식 · 상한** | 정의뿐. 매출감소 ≤ 계약금액, 마진 ≤ 1 |
| **함의 모수 역산** | 외부 분포 하나 (동종 배수 등) |
| **차원** | 단위 선언뿐 |
| **내부 모순** | 체인 구조뿐 |
| **시간 순서** | 타임스탬프뿐 |

**역산이 가장 강하다.** 예측하지 말고 뒤집는다.

$$850억\times m\times k=3{,}810억\ \Rightarrow\ m\cdot k=4.48$$

마진 8%면 배수 56이 필요하다. 동종 배수 중앙값이 12면 **접지 없이 기각**된다. 그리고 역산은 관측을 **입력으로 받으므로 맹검이 필요 없다**.

> **연역은 배제하고 경험은 확립한다. 배제만으로 하나가 남으면 그게 답이다** — 사고조사가 하는 일이 정확히 이것이다.

### 6.4 밴드 폭이 진짜 양이다

체인은 곱으로 합성되고, 미접지 상수가 있으면 예측은 **구간**이다.

$$\log\Lambda_{\text{체인}}=-\log_2\frac{2\epsilon}{\text{range}}$$

$\epsilon$ 을 줄이는 방법이 **둘**이고, 둘 다 같은 화폐를 번다.

| | 방법 | 필요 |
|---|---|---|
| **접지** | `assumed` → `observed` | 데이터 |
| **연역** | 상한·항등식 추가 | **없음** |

자유모수 개수는 이 밴드 폭의 **조잡한 대리변수**였다. 실물이 있으므로 대리변수로 순위를 매기지 않는다.

**세분의 브레이크가 여기서 공짜로 나온다** — 접지 없이 쪼개면 각 조각의 밴드가 넓고, 넓은 밴드가 "맞는" 건 0 bit다. **커버리지는 bit로 사야 하고, 안 사면 커버리지가 아니다.**

#### 6.4.1 합성은 구간 산술이 아니라 MC 다

체인 합성을 **구간 산술**로 하면 최악 코너를 곱해 밴드가 폭발한다. **MC 로 통과시키면 실제 분포가 나온다.**

링크 4개, 각 90% 구간 $\pm30\%$, 독립 가정:

| 방법 | 합성 구간 | 유효 범위 |
|---|---|---|
| 구간 산술 | $[0.24,\ 2.86]$ | $-76\%\sim+186\%$ |
| **MC** | $[0.59,\ 1.68]$ | $-41\%\sim+68\%$ |

**밴드가 2.6배 좁아지고 $\approx2.1$ bit 를 더 번다.** 형태 무관 인터페이스(§5.2)로 가면 합성이 자연히 MC 가 되므로, **일반화가 비용이 아니라 이득이다** — 최대 리스크인 U2($\epsilon$ 전파)가 같이 완화된다.

### 6.5 합산은 미봉이다

$\sum\log\Lambda$ 는 베이즈 인수 해석에서 왔고 심각성 프레임에는 합산 규칙이 없다.

| 해석 | 사전 | 합산 |
|---|---|---|
| 베이즈 인수 | 필요(안 씀) | 독립 가정에서 덧셈 |
| **심각성** | **불필요** | **없음** |

해소는 **결합 귀무**다 — 전 시험을 같은 시드로 함께 표집하면 결합 통계량의 심각성을 직접 잰다. 합산은 결합 귀무가 불가능할 때의 근사로 격하된다.

## 7. 정렬 — 단일 스칼라는 끝까지 나오지 않는다

$$\underbrace{\text{자격}}_{\text{불리언}}\ \succ\ \underbrace{\text{몫별 심각성}\ \log\Lambda_k\ge\tau}_{\textbf{순위 아닌 문턱}}\ \succ\ \underbrace{\max\textstyle\sum_k\text{share}_k}_{\text{배분}}\ \succ\ \underbrace{\text{수렴}\cdot\text{집합 최소성}}_{\text{동률 판별}}$$

### 7.1 2단이 문턱이라는 것이 핵심이다

순위를 매기려 하니까 스칼라가 필요했고 $\lambda$ 가 계속 나왔다. **문턱으로 두면 사라진다.**

$\lambda$ 를 못 정한 것이 실패가 아니라, $\lambda$ 를 찾으려 한 것이 잘못된 탐색이었다. **보존량 배분 문제는 원래 스칼라 최적화가 아니다.**

### 7.2 비교 기준은 압축이 아니라 수렴

둘 다 문턱을 넘고 커버리지가 비슷하면 — **어느 쪽이 더 많은 독립 증거선에 강제되는가**(consilience). 부품이 적어서가 아니라 **우연이기 어려워서**다.

수치는 $\sum\log\Lambda$ 로 같지만 정당화가 다르고, 수렴 해석만이 **왜 독립성을 검사해야 하는지**를 설명한다.

### 7.3 MDL 의 올바른 자리

압축은 일반화 장치이고, 귀속은 **이 사례에 대한 충실도**를 요구한다. 사고조사관은 추락의 최단 기술을 찾지 않는다.

| | 적용 |
|---|---|
| **원인 집합의 최소성** (Halpern–Pearl AC3) | ✅ 군더더기 원인 금지. 3개로 덮이면 5개 주장 불가 |
| **체인 길이의 최소성** (MDL) | ❌ 유해. 상세함은 군더더기가 아니라 접지다 |

오컴은 "원인을 몇 개 대는가"에 걸리지 "메커니즘을 얼마나 상세히 쓰는가"에 걸리지 않는다.

### 7.4 충분성은 NESS 로

but-for 는 과잉결정에서 무너진다. Wright 의 NESS — *원인 = 결과를 산출하기에 충분한 조건 집합의, 필요한 원소* — 가 share 기계로 그대로 번역된다.

- **충분**: shares 합이 잔차를 덮는 부분집합
- **그 안에서 필요**: 빼면 커버리지가 문턱 아래로

**커버리지 + 집합 최소성이 곧 NESS 다.**

## 8. LLM 의 자리 — 제안 분포

### 8.1 LLM prior 는 DGP 가 아니다

$$\text{DGP}:\ p(\text{움직임}\mid\text{사건},\text{상태})\qquad\text{vs}\qquad\text{LLM prior}:\ p(\text{설명}\mid\text{사실},\ \textbf{관측된 움직임})$$

**방향이 반대다.** 학습 코퍼스(애널리스트 리포트·시황 해설)는 **사후적**이고 **비반증적**이며 **선택 편의**를 갖는다. LLM 은 가격이 어떻게 생성되는지 모르고 **사람들이 가격을 어떻게 설명하는지** 안다.

### 8.2 그래서 역할은 제안 분포다

| | 역할 | 요구 조건 |
|---|---|---|
| **LLM** | 제안 분포 $q$ | 편향돼도 됨. **support 만 있으면 됨** |
| **하네스 + 검증** | 수용 규칙 | 편향을 교정 |
| **누적 원장** | 사후 표본 | — |

> **편향은 수용 규칙이 고친다. support 상실은 못 고친다.**

이것이 *"나쁜 시멘틱 레이어 < 자유 생성"* 의 정확한 이유다. 나쁜 분류체계는 제안을 편향시키는 게 아니라 **support 를 잘라낸다.**

### 8.3 그래서 생성은 자유, 제출은 구조

| 제약 대상 | 비용 |
|---|---|
| **어휘** ("5개 채널 중 골라") | **치명적** — 프리트레인 prior 와 충돌 |
| **절차** ("서명 추출 → 도식 매칭") | **치명적** — 추론 경로를 미리 정함 |
| **제출 형식** ("체인·몫·기각조건을 채워라") | **거의 0** — 추론 *후*에 작동 |

**분류체계가 아니라 검사가능성 명세**를 요구한다.

### 8.4 격리 원칙 — `causal-learn+` 의 일반화

`causal-learn+`(arXiv 2606.23608)은 *"에이전트는 edge·orientation·prior·constraint 를 공급해서는 안 된다"* 고 요구한다. 인과 **발견**에서는 알고리즘이 구조를 도출할 수 있으므로 옳다.

$N{=}1$ 귀속에서는 도출할 알고리즘이 없다. 선택지는 "LLM edge vs 알고리즘 edge" 가 아니라 **"LLM edge vs edge 없음"** 이다. 그래서 원칙을 일반화한다.

> **알고리즘이 도출할 수 있는 것을 LLM 이 공급해서는 안 된다.**
> **도출 불가능한 것은 LLM 이 공급하되 `assumed` 로 라벨하고 접지를 요구한다.**

**정직하게:** 그들은 *"그래프는 PC 가 만들었다"* 고 가리킬 수 있고 우리는 못 한다. 우리 산출물은 그들 기준으로 causal evidence 가 아니라 **감사된 귀속**이다. 게시 문구가 이 차이를 반영해야 한다.

## 9. VCI — 세 개의 다른 보증

뭉치면 과대주장이 된다.

| | 무엇을 보증 | 도구 | 한계 |
|---|---|---|---|
| **VC1 도출** | 선언된 가정 → 결론이 형식적으로 따라 나옴 | 연역 배터리(§6.3) · 차원 · 시간 | *"correct up to its assumed premises"* — 전제는 검증 안 함 |
| **VC2 절차** | 추론이 정직한 조건에서 이루어짐 | 네 규율 (`phase1.md` §3) | 깨끗한 계보 + 나쁜 추론 = 깨끗하게 나쁜 추론 |
| **VC3 경험** | 주장이 엄한 시험을 통과 | 심각성 · 반박 배터리 | 귀무의 타당성은 도구 소관 |

$$\text{VCI}=\text{VC1}\wedge\text{VC2}\wedge\text{VC3}$$

**Lean 은 VC1 만 준다.** 그리고 우리 문제에서는 **전제(=체인)가 곧 난제**이므로 어려운 절반을 검증하지 않는다. 완전한 do-calculus 기계화는 아직 미발표이고, 조정집합이 생기는 좌표계 층에서 재검토한다(`phase2.md` §5).

**지금 가능한 VC1 은 차원 분석과 상한 대조다.** *"매출 3% × 마진 8% = 주가 −2.1%"* 는 자본화 단계가 빠져 차원이 안 닫힌다 — 그럴듯하게 읽히지만 기계적으로 틀렸고 기계적으로 잡힌다.

## 10. 목적 — DGP **구성**이 아니라 DGP **제약의 생산**

### 10.1 영수증 하나는 제약이 아니다

검증된 귀속 한 건은 **예측–관측 대조 하나**다. 반사실을 관측할 수 없으므로 그 자체로는 $f$ 를 제약하지 못한다.

제약이 되는 것은 **누적됐을 때**이고, 제약받는 대상은 $f$ 전체가 아니라 **링크별 예측 구간**이다.

$$\Pi_\ell:\quad p\big(\text{to}\mid\text{from},z\big)$$

스칼라 계수가 아니다 — 어떤 형태든 이 구간을 내놓기만 하면 같은 제약을 받는다.

### 10.2 우리가 생산하는 제약 다섯 종

| # | 제약 | 무엇을 배제하나 | 다원인 날에도 |
|---|---|---|---|
| 1 | **링크 예측–관측 대조** | 관측을 자기 구간 밖에 두는 $\Pi_\ell$ | ❌ 배분에 오염 |
| 2 | **지속률 $\rho$ ↔ 메커니즘 대응** | 영구/일시 두 점가설 우도비 (§6.1.1) | ✅ 배분과 독립 관측. **$T{+}n$ 무료 라벨** |
| 3 | **반증조건 발화 기록** | 어떤 설명이 어떤 관측에 죽는가 | ✅ |
| 4 | **미설명 잔량 분포** | **사건 기반 설명 프레임 자체의 검정** | ✅ |
| 5 | **부작동 관측** (사건 있음, 반응 0) | $\beta$ 의 상향 편의 제거 | — |

2번이 가장 값싸고 즉시 된다. 4번이 이 시스템 전체의 반증 지점이다.

### 10.3 순환은 없다 — 두 규칙으로 충분

$\Pi_\ell$ 은 **원재료에서** 적합한다 — from 노드 관측값에서 to 노드 관측값으로.

LLM 의 예상은 회귀변수가 **아니다** — 게이트 밴드와 보정 기록으로만 쓰인다. 남는 경로는 선택 효과 하나이고, 방어도 한 줄이다.

| 규칙 |
|---|
| **원재료에서 추정** — 예상은 회귀에 안 들어간다 |
| **실패도 기록** — 관측쌍은 가설이 죽어도 관측된 것이다 |

### 10.4 그리고 이것이 LLM prior 를 씻는 유일한 방법이다

LLM 의 서사 prior 는 **한 번도 반증된 적이 없다.** 감사된 귀속 하나하나가 반증 사건이다. 충분히 쌓이면 어떤 서사 패턴이 살아남는지를 **측정**할 수 있고, 오염된 prior 를 측정된 prior 로 교체할 수 있다.

> **시스템의 목적은 LLM prior 를 쓰는 것이 아니라, 감사해서 교체 가능한 것으로 만드는 것이다.**

### 10.5 그래서 커버리지 > 개별 정확도

| | 가치 |
|---|---|
| 감사된 귀속 1000건, 오류율 30% | **높음** — 오류가 측정 가능하고 교정 가능 |
| 완벽한 귀속 10건 | **낮음** — 아무것도 제약하지 못함 |

$N{=}1$ 이라 개별 밴드는 넓고, 넓은 밴드는 거의 모든 모델과 양립한다. **총합만 구속력을 갖는다.** 정직한 라벨만 붙어 있으면 오류는 자산이다.

## 11. 못 하는 것 · 미해결

| # | 항목 | 성격 |
|---|---|---|
| **U1** | **과잉결정 · 선점** — 악재 둘이 각각 단독으로 $-3\%$ 를 낼 수 있었으면 but-for 로는 둘 다 원인이 아니고 share 합은 잔차를 초과한다 | **최대 미해결.** 이벤트 스터디에서 흔함. 표준 답은 Chockler–Halpern 책임도, 채택 미정 |
| **U2** | **$\epsilon$ 전파** — 체인 곱셈으로 밴드가 실무상 쓸모없이 넓어질 수 있다 | **이 프레임의 첫 반증 지점.** MC 합성(§6.4.1)이 구간 산술 대비 $\approx2$ bit 완화하지만 제거하지는 못한다 |
| **U3** | **메커니즘을 bit 로 못 잼** | Russo–Williamson 절반 구현. 정렬 2순위가 대리. 옳은지 열려 있음 |
| **U4** | 사전확률 없음 → 순위만, 절대 신뢰도 불가 | 설계 선택 |
| **U5** | 사건 커버리지 — "사건 없음"이 진짜 없음인지 뉴스 구멍인지 | 부작동 관측을 오염시킴. 플래그 필요 |
| **U6** | **하강 가능성을 코드가 모른다** — 어떤 상수에 어떤 관측을 붙일 수 있는지가 LLM 회상에 있다 | **노드 사전**(`phase1.md` §4.2)으로 해소. 없으면 시스템이 하강 대신 **세분으로 흐른다** |

**U2 가 가장 먼저 확인해야 할 하나다.**
