## 0. 한 장 요약

| 항목 | 이전 | 이후 |
|---|---|---|
| LLM 이 내는 것 | 가설 + 수치 + 판정 | **산문 구조**(주장·메커니즘·반증조건) + **검정 코드** |
| 검증 | 에이전트가 판정 | **코드가 게이트**(G1~G7). 수치는 원장에서만 읽는다 |
| 반증 표면 | 에이전트가 작성 | **그래프에서 열거** |

> **§0·§8 은 §9.3 에서 부분 철회됐다.** "검증 에이전트 해소"(설계만 받고 추정량은 코드에
> 고정)는 되돌렸다 — 간선마다 무엇을 어떻게 재야 하는지가 달라서 고정 추정량으로는

핵심 명제 하나:

> 코드는 **"이 설명은 불가능하다"** 만 말할 수 있다.
> **"이렇게 비교하면 알 수 있다"** 는 LLM 만 말할 수 있다.

## 2. 계층 SCM - 동적분석의 범위

완전한 SCM $M=\langle U,V,F,P(U)\rangle$ 는 금융에서 만들 수 없다. 층별로 도달 rung 이 다르다.

| 층 | $F$ | 교란 | rung | 담당 |
|---|---|---|---|---|
| **A 항등식** ETF←구성종목 | **정확** (산술) | 없음(정의) | **3층 점식별** | 정적분석 |
| **B 사영** 시장·피어 제거 | 관례(선형인자) | 해당없음 | 변수 생성 | 정적분석 |
| **C 사건** 뉴스→$r_\perp$ | 미지 | 심각 | 1층+소거, 설계 있으면 2층 | **동적분석** |

**동적분석은 C 만 한다.** A·B 는 정적분석기가 이미 낸다.

산출물은 어느 층에서 말하는지 표시해야 한다. 지금 보고서는 A층 계산(기여도)과 C층 추측(뉴스 원인)을 같은 문장 높이에서 쓴다 — 의미적 공허의 발생 지점.

## 3. 좋은 DAG 의 정의

### 3.1 나쁜 DAG 는 항상 같은 모양이다

```
        S (기업/산업 상태, 미관측)
       ╱ ╲
   News   Y
```

$S\to$News, $S\to Y$. 뒷문이 열려 있고 $S$ 는 미관측. **비교군이 없으면 인과 질문이 아니다.**

### 3.2 정의

> **좋은 DAG = 처치 대비를 변이가 외생인 자리로 옮긴 그래프.**

"사건이 났다 vs 안 났다"에는 외생 변이가 없다. 창의성은 **어디에 외생 변이가 숨어 있는지 찾는 것**이고, 그건 도메인 지식이다.

### 3.3 사례 - §1.6 셀

**나쁜 버전** (실제로 돌린 것)
```
애널리스트클러스터@t-4 ──→ Biotechnology@t0
```
처치가 셀 전체 상수. 대비 없음. 식별 불가. 함의 없음. 707초 검정에서 아무것도 못 죽임.

**좋은 버전** - 처치를 *지명됨* 으로 이동
```
              S (미관측)
             ╱   │   ╲
     ①보고서   ③커버리지   ②모든 Y_i
        │        │            ↑
        └─→ ④지명_i ──⑤───────┘
```

| 화살표 | 뜻 | 역할 |
|---|---|---|
| ① `S→보고서` | 뭔가 있으니 쓴다 | 교란 원천 |
| ② `S→Y` | 그 뭔가가 가격도 움직인다 | 교란 원천 |
| ③ `S→커버리지` | 관심 산업을 더 커버 | 커버 여부로 나누면 안 되는 이유 |
| ④ `보고서+커버리지→지명` | 커버 중 일부 지명 | **여기에 변이가 있다** |
| ⑤ `지명→Y` | 재려는 것 | |

| 군 | n | 역할 | 필요 가정 |
|---|---|---|---|
| 지명 | 2 | 처치 | |
| 커버·미지명 | 6 | '애널리스트 관심' 교란 흡수 | 지명은 커버·규모 조건부 준랜덤 (**약함. 논쟁적**) |
| 미커버 | 38 | **음성대조** | 보고서는 미커버에 안 닿는다 (**강함. 거의 정의**) |

핵심 함의:
$$Y_{\text{미커버}} \perp \text{클러스터} \;\big|\; \text{산업},\text{시장}$$

38종이 같이 올랐으면 애널리스트 설명은 **검정 하나로 죽는다.** 나쁜 버전엔 이런 함의가 없었다.

### 3.4 창의성을 제한하지 않는 이유

$do$-계산은 **완전**하다 (Shpitser-Pearl 2006, Huang-Valtorta 2006). 어떤 그래프·estimand 든 식별 가능성이 알고리즘으로 결정된다.

$$\Rightarrow \text{검증이 완전하므로 생성을 제약할 이유가 없다}$$

분할 기준(커버리지·지분·공급망·지역·만기·지수편입), 대비 위치, 채널 — 전부 자유. 코드는 필요조건만 본다.

## 4. 비용 순 게이트

$$r_\perp^{\text{cell}} \;=\; \sum_i w_i\,\tau_i \;+\; \text{잔여}$$

설명은 이 항등식을 채우는 일이다. **대부분의 제안은 $w_i$ 만 봐도 죽는다.**

| # | 게이트 | 비용 | 죽이는 것 |
|---|---|---|---|
| **1** | **크기 정합** $\tau_{\text{req}}=r_\perp/\sum_{i\in T}w_i$ | **무료** | 무게 없는 원인 |
| 2 | 도달 가능성 (미도달군 존재) | 무료 | 음성대조 불가 설계 |
| 3 | 사전 측정 ($as\_of<\tau$) | 무료 | 사후변수 조건화 |
| 4 | 균형 (SMD) | 싸다 | 사과 vs 오렌지 |
| 5 | 식별 ($do$-계산) | 싸다 | 식별 불가 estimand |
| 6 | 함의 열거 -> 검정 | 중간 | 틀린 그래프 |
| 7 | LLM 왕복 | **비쌈** | |

### 4.1 크기 정합 - 실증

§1.6 셀:

| 지명 2종이 이만큼 | ETF 몫 | 관측 +13.36% 중 |
|---|---|---|
| +10% | +0.52% | 3.9% |
| +100% (두 배) | +5.20% | 39% |
| **+257%** | +13.36% | 100% |

**두 종목이 두 배가 돼도 +5.2%.** 애널리스트 설명은 산술로 죽는다. 1.37초, LLM 0회.

죽는 것의 정확한 범위:

| 주장 | 상태 |
|---|---|
| "보고서가 그 2종을 움직였다" | **살아 있음** |
| "보고서가 이 셀의 +13.36%를 설명한다" | **죽음** |

$\tau_{\text{req}}$ 는 효과 추정 없이 역산된다. 타당성 상한은 §1.1 데이터에서 타입별로 실측 가능.

우리는 이 계산을 707초 검정과 여러 LLM 세션 **뒤에** 했다. 순서가 거꾸로였다.

## 5. 설계 제약 여덟

| # | 제약 | 검사 |
|---|---|---|
| C1 | 처치 대비 양쪽 비지 않음 | $\lvert T\rvert>0 \wedge \lvert C\rvert>0$ |
| C2 | 미도달군 존재 + 정결 | $\lvert\text{미도달}\cap\text{clean}\rvert \ge k$ |
| C3 | **분할·조정 변수 전부 $as\_of<\tau$** | PIT |
| C4 | 균형 | SMD $<0.25$ 또는 매칭 |
| C5 | 간섭(SUTVA) 명시 | 파급 채널이 노드이거나 배제 근거 |
| C6 | `미상` 은 어느 군에도 미포함 | |
| C7 | **크기 정합** | $\tau_{\text{req}}$ 가 타입별 실측 상한 내 |
| C8 | 사전등록 | 예측 기록 후 검정 실행 |

**C5 가 금융에서 특히 위험하다**: ETF 설정/환매가 구성종목을 기계적으로 묶는다 -> 음성대조군 오염. 다행히 측정 가능(설정환매·괴리) -> 노드로 넣는다.

## 6. 원시 도구 다섯 - 없으면 좋은 DAG 가 표현 불가능

> **호출을 46번 해야 하는 연산은 에이전트에게 존재하지 않는 것과 같다.** (상한 40회)

| 도구 | 반환 | 없으면 |
|---|---|---|
| `population(cell)` | 단위 + 사전 속성 | 46종이 안 보임. 단위 수준 비교를 **떠올릴 수 없음** |
| `reach(cause, units, as_of)` | `{도달, 미도달, 미상}` | 음성대조군 생성 불가 (46회 필요) |
| `clean(units, window)` | 타 사건 없는 단위 | 오염된 대조군 |
| `balance(A, B, covars)` | SMD 표 | 비교가능성을 **주장**하게 됨 |
| `weight(units, target)` | $w_i$ | **크기 정합 불가** — 5.20% 를 알 방법이 없음 |

`reach` 가 온톨로지 `관계` 가 실제로 쓰이는 자리다. 여집합이 음성대조군.

### 도구가 사고의 범위를 정한다

지금 도구는 전부 **사건 모양**(`events.enumerate`·`event.card`·`thread.timeline`).

$$\text{사건 모양 도구}\;\Rightarrow\;\text{사건 모양 이야기}$$

비교군 설계는 문법상 표현이 안 된다. 프롬프트로 부탁해도 안 나온다 — 재료가 없다.

## 7. 산출 계약

```jsonc
{
  "unit":     "industry_member",                   // 셀이 아니라 단위
  "treated":  {"by": "named_in_event", "event": "0410...#0"},
  "control":  {"by": "covered_not_named", "as_of": "2026-06-22"},
  "negative": {"by": "not_reachable", "channel": "analyst_coverage"},
  "estimand": "E[Y_i|do(named=1)] - E[Y_i|do(named=0)] | covered",
  "aggregate":"sum_i w_i * tau_i",                 // 셀로 되돌리는 규칙
  "predict":  {"negative_group": "산업평균 초과 0"},  // 사전등록 (C8)
  "excluded": [{"pair":["event","Y_unreachable"], "why":"채널 없음"}],
  "conjecture":[{"need":"...","unlocks":"..."}]     // 저장소 밖. 게시 금지
}
```

`aggregate` 필수: 단위 효과를 셀 설명으로 되돌리는 규칙이 없으면 "설명했다"고 말할 자격이 없다. 이 필드가 있으면 C7 이 자동 계산된다.

**사라진 필드**: `discriminator`(계산) · `rung`(층별로) · `verdict`(계산) · `breaks_if` 대부분(계산) · estimand 5속성 산문.

## 8. 에이전트 배치 - 검증 에이전트 해소

### 8.1 코드로 가는 것

```
크기정합 · PIT · 도달/여집합 · 균형 · 식별(do-계산)
함의 열거 · 검정 실행 · 다중검정 보정 · 민감도(E-value)
```

전부 **틀리면 조용히 틀리는** 종류. 사람이 검토해도 안 보인다.
실증: `prove` 가 낸 수치는 100% 날조였다 (`p=0.37`, `placebo` 0회 호출).

### 8.2 남는 판단 다섯의 귀속

| # | 판단 | 귀속 |
|---|---|---|
| 1 | 배제제약이 참인가 | **반증** (반례 찾기) |
| 2 | 채널을 제대로 골랐나 | **반증** (대안 채널 제시) |
| 3 | 안 잰 차원에서 비교 가능한가 | **반증** (미측정 교란 지명) |
| 4 | 검정이 깨졌을 때 무엇이 틀렸나 | **생성** (진단 후 재설계) |
| 5 | 다음 설계는 무엇인가 | **생성** |

**중립적 검증자에게 남는 일이 없다.** 1-3 은 전부 "반례를 찾아라"이고, 4-5 는 "다시 만들어라"다.

### 8.3 최종 로스터

| 에이전트 | 일 | 존재 이유 |
|---|---|---|
| **생성** | 설계 발명 · 실패 진단 후 재설계 | LLM 만 가능. 2/6/38 분할은 코드가 못 떠올린다 |
| **반증** (새 세션) | 배제제약 반례 · 대안 채널 · 미측정 교란 | 적대 프레이밍이 성공기준이 명확 |
| **최종 검토** | **충돌 시에만** — 반증/생성이 안 갈리는 미검정 가정, 부분DAG 병합 충돌 | 판정 |
| ~~검증~~ | **해소** | 일이 코드이거나 반증이다 |

인증은 에이전트가 아니라 계산이다: 어떤 함의가 검정됐고 살아남았는지 + 민감도.

### 8.4 반증 에이전트에 주는 것

서사가 아니라 **원장**: 함의 목록(계산됨) · 소거 원장 · 배제제약과 근거.
받는 것: **배제제약이 깨지는 구체적 상황 하나.** 산문 비판 아님.

### 8.5 부분 DAG 병합 (합의 알고리즘) - LLM 없음

병합에서의 날조는 보이지 않는다. 전부 결정론:

- **노드 동일성**: $(\texttt{ontology\_id},\texttt{entity\_id},\texttt{time\_bucket})$ 키. 문자열 매칭 아님
- **간선**: 3상태 격자 결합

| ⊔ | present | excluded | unknown |
|---|---|---|---|
| **present** | present | **충돌→검토** | present |
| **excluded** | **충돌→검토** | excluded | excluded |
| **unknown** | present | excluded | unknown |

- **방향**: 시간 색인에서. 방향 충돌·순환이 **구조적으로 불가능**
- **병합 후 함의 재계산**: 공유 노드를 지나는 경로에서 **부분에 없던 함의**가 생긴다. 이게 전체 DAG 를 만드는 이유

간선 3상태가 필요한 이유: DAG 에서 **간선 부재는 강한 인과 주장**이다. 지금은 부재가 사고로 생긴다 — §3.3 데모에서 `MARKET ⊥ Medical_Pharma` 같은 터무니없는 함의가 그렇게 나왔다. 배제는 **의도적 선언**이어야 한다. 그것이 식별력의 원천이므로.

| # | 우리가 했던 것 | 논문 | 정정 |
|---|---|---|---|
| 1 | 미식별 → "인과 아님" | 미식별 계수도 *"does not tarnish their status as causal effects"* | **인과 지위(모델 선언)와 추정 가능성(코드 계산)을 분리한다** |

| 5 | `intervention: none` → 통계 자격 박탈 | Myth 3 기각. 본질은 **responsiveness**, 조작가능성 아님 | **`intervention` 게이트 폐기.** `timing_exogenous`(역인과)는 유지 - 별개 문제 |
| 6 | 잠재 매개 자식<4 → "접어라" | 매개는 SEM 의 핵심. CDE 는 do-계산으로 완전 특성화 | **"조건을 선언하라 or CDE 를 써라"** 로 교체 |

**보너스 - §의 1순위 취약점("생성 실패 ≠ 설명 부재")의 답이 논문에 있다.**
Myth 6 Fig 15.6: $X\to\eta_1\to\eta_2\to Y$ 에서 $X$-$Y$ 무효과의 원인은 둘이다 —
$X\to\eta_1$ 이 약함(메커니즘 부재) vs $\eta_2\to Y$ 가 약함(대리물 부적합).
Costner (1971): **구성개념당 지표 2개** -> 과대식별 -> **둘이 구별된다.**
우리 `measure:` 필드는 구성개념과 지표를 붕괴시켜 이 진단을 원리적으로 불가능하게 했다.

**논문이 확인해 준 것**: 국소 검정 > 전역 적합도 · 간선 부재가 강한 가정 ·
SEM = (질적 인과가정, 데이터) -> (양적 결론, 적합도) 추론엔진 ·
*"models that do not allow such rejection can be identified as such"* (우리 `impossible` 출력).

`implied_ci` 구현 검증: 랜덤 DAG 12/12 에서 **기저 크기 = 빠진 간선 수** 정리를 만족.
단 이건 잠재 없는 경우의 완비성이다 (오해 3).

| 항목 | §8 이후 상태 | 판정 | 사유 |
|---|---|---|---|
| 샌드박스 코드 실행 | 제거. 술어 선언으로 대체 | **철회(복원)** | 추정량이 하나(OLS 계수 + 층화 순열)로 고정되면 그 틀에 안 맞는 간선(사건연구·2단계 IV·부분식별·항등식 분해)이 **통째로 검정 불가**가 된다. 무엇을 어떻게 재야 하는지는 간선마다 다르고, 그게 검정 에이전트가 존재하는 이유다 |

**§8.2 의 판단 배분은 유효하다** — 조정집합·식별·함의 열거·판별기준은 여전히 코드가
정한다(모델에게 묻지 않는다). 철회한 것은 "**추정 실행**도 코드가 고정한다"는 부분 하나다.

같이 정정한 것:

- **데이터 부재는 기각이 아니라 산출물.** 검정 에이전트의 `impossible` 이 구조화된
  요청(`need`·`grain`·`unlocks`·`edge`)으로 `causal.data_requests` 에 쌓인다. 제안이
  잴 수 없는 간선을 남기고 `needs` 를 적는 것도 같은 큐로 간다 — 커버리지보다 **DAG
  품질(맞는 인과인가 · 검정 가능한 형태인가)** 이 먼저다.
- **G7 을 선언에서 정합 검사로.** 실험판 G7 은 `strata` 를 *선언*만 요구했다. 설계가
  날짜를 조건화했다고 적어 놓고 자유순열로 섞는 조합이 통과했다(실측 sd 0.0088 vs
  0.0077). 이제 무층화를 고르면 `strata_reason` 이 필수이고 감사에 남는다.
- **확신도 정직화.** 단일 패스에는 표본외 확증이 없으므로 `높음`을 만들지 않는다.
  감사 블록에 `status: 미확증(표본외 검정 없음)` 을 남긴다.
- **판별기준 계산을 실행 경로에 연결.** `graph.discriminator`(함의 대칭차집합·Markov
  동등 거부)가 이식돼 있었으나 호출되지 않는 죽은 코드였다. 제안이 `alt_edges` 를 내면
  계산해 `causal.discrimination` 에 남긴다. 일일 게시 경로에서 경쟁 구조는 **강제하지
  않는다**(최소제약) — 발견 루프의 프로토콜과 게시 경로를 구분한다.

**샌드박스의 위험은 다른 종류다.** 여기서 실행되는 코드는 LLM 이 쓴 것이고 그 입력에는
외부 사건 제목이 섞인다(프롬프트 주입 표면). 제한 exec 는 완전한 격리가 아니다. 그래서
`CAUSAL_SANDBOX_ENABLED` 킬스위치를 두고(OFF 면 축약 경로), 샌드박스는 다음을 강제한다:
`as_of` 코드 바인딩(모델이 PIT 를 만질 문법이 없다) · 창을 셀 당일로 절단 · `__` 금지
(바운드 메서드의 `__self__._conn` 경로 차단) · import 허용목록 · 코드 길이 상한 ·
타임아웃 + **폭주 스레드 강제 종료**(daemon 으로 남기면 남은 검정이 CPU 를 나눠 쓴다 —
실측 스위트 1.6s → 138s). 태스크는 최소권한 역할·읽기 전용 DB 사용자로 돌려야 한다.

## 11. 적합도 - 국소가 본체, 전역은 마지막 한 번 (`fit.py`)

### 11.1 무엇을 쓰고 무엇을 버렸나

| 지표 | 채택 | 사유 |
|---|---|---|
| **국소 CI 검정** (부분상관, Fisher z) | ✅ | 어디가 틀렸는지 핀포인트. 본체다 |
| **Shipley C** $=-2\sum\ln p_i \sim \chi^2_{2k}$ | ✅ | 전역. **국소 $p$ 를 합성**하므로 별도 적합이 없다 |
| **RMSEA** $=\sqrt{\max(C-df,0)/(df(N-1))}$ | ✅ | $\chi^2$ 는 $N$ 에 민감하다. 표본 보정판이 필요 |
| $C/df$ | ✅ | 한 눈에 보는 배율 |
| **수정지수(MI)** | ✅ **별도 계산 안 함** | **깨진 CI 가 곧 빠진 간선이다.** $p$ 오름차순 목록이 MI 를 대체하고 더 직접적이다 |
| CFI · TLI | ❌ | 독립모형 기준선과 $\Sigma(\theta)$ 의 ML 적합을 요구. d-분리 검정에는 $\Sigma(\theta)$ 가 없다 - **정의되지 않는다** |
| ML $\chi^2$ on $\Sigma(\theta)$ | ❌ | 선형·정규를 다 받아야 한다. 우리 데이터는 둘 다 아니다 |

`chi2_sf` 는 $df$ 가 항상 짝수($2k$)라 닫힌형으로 계산한다 - scipy 불필요.

| `LOGCAP@t-7` | `VOL@t-7` | 0 | 5000 | +0.018 | 0.191 | 통과 |
| `RATED@t-6` | `VOL@t-7` | 2 | 4972 | −0.002 | 0.860 | 통과 |

$$C=835.13,\quad df=10,\quad p<10^{-4},\quad C/df=83.5,\quad \text{RMSEA}=0.129$$

**모형 기각.** 그리고 국소 목록이 어디인지 말한다:
- `LOGCAP ⊥ RET | RATED,MOM,VOL` 위반 -> **규모 효과를 빠뜨렸다** (소형주 초과수익 $r=-0.076$)
- `RATED ⊥ VOL` 은 성립 -> 지명이 사전 변동성과 무관하다는 건 데이터가 지지

### 11.4 포화 DAG 는 함의가 0 이다

3노드·3간선(`MOM`·`RATED`·`RET`) -> **검정 가능한 함의 0건, 전역 적합 불가.**
Bollen-Pearl Fig 15.2b 그대로다: 모든 모수가 식별되지만 검정할 것이 없다.
**모수를 다 추정할 수 있다는 건 좋은 신호가 아니다.**

## 12. 양방향 간선이 들어오면 검증 에이전트는

`kind: bidirected` 는 **공짜가 아니다.** 대가가 둘, 산술로 치러진다:

**① 조정이 원리적으로 불가능해진다**
`admg_backdoor_ok` 가 `X <-> Y` 를 만나면 `X ← _L → Y` 를 관측변수로 막을 수 없다고
판정한다. 그러면 `plan()` 이 브리프에 이렇게 내려준다:

```
조정집합 : 없음
           **조정으로는 식별 불가** - X <-> Y 미지의 공통원인이 있다.
           도구변수 후보 (배제제약 성립): ['Z@t-9']
           2단계로 추정해라. 1단계 Z->X, 2단계 예측값->Y.
```

도구변수 열거는 **코드가 한다** (`iv_candidates`, Brito-Pearl 2002 단순형):
$Z$ 가 $X$ 의 조상이고, `X→Y` 를 지운 그래프에서 $Z \perp\!\!\!\perp_m Y$ 면 도구다.
두 번째 조건이 곧 배제제약이고, 그래서 **배제제약이 알고리즘으로 검사된다.**
후보가 없으면 브리프가 `impossible` 을 내라고 지시한다.

**② 검정 가능한 함의가 줄어든다**
실측: `RATED <-> RET` 추가 -> 그 쌍이 함의에서 빠지고 $df\ 10 \to 8$, $k\ 5 \to 4$.
$C$ 는 835 -> 802 로 줄지만 $C/df$ 는 83.5 -> **100.3 으로 오른다.**

$\Rightarrow$ **양방향을 뿌려서 반증을 피할 수 없다.** 피하는 만큼 모형이 약해지고
그게 $k$·$df$ 로 보고된다. 유인 구조가 맞다.

## 16. P0–P9 로의 전환 (프로덕션, 2026-07-31) — **이 문서의 §15 를 대체한다**

정정된 원칙: **어휘는 열고, 회계·교란·처분만 닫는다.**

## 15. 바텀업 귀속으로의 전환 (프로덕션, 2026-07-30)

이 문서 §2~§14 는 **타입 수준 구조 발견**을 전제로 쓰였다. 프로덕션 인과 경로는
그 전제를 버렸다 - 설명 대상이 *한 ETF 의 한 날 등락 하나*이므로 답해야 하는 것은
"이 사건 타입이 평균적으로 얼마를 움직이나"가 아니라 **"오늘 이 움직임을 어디까지
설명했나"**다. 바뀐 것과 그 근거만 남긴다.

### 15.1 층이 셋이고 통계는 한 층에만 있다

```
뿌리   이 ETF · 오늘 · 관측 등락            관측 1개
1층  = Σ wᵢ·rᵢ + 추적오차                  산술 (arithmetic_gate 가 이미 여기 있었다)
2층    rᵢ = βᵢ·시장 + 섹터 + 고유           요인 분해 (상류 파이프라인)
3층    고유분 ← 사건에 귀속 가능한가         ← 코호트·검정은 여기만
잔차   미설명                                상시 보고
```

### 15.2 간선 유형이 증명 양식을 결정한다 (`causal/chain.py`)

사건에서 가격까지는 간접이고 단계 수를 미리 알 수 없다. 그 사슬에는 성질이 다른 칸이
섞여 있고, 셋을 같은 방식으로 다루면 계산을 검정하거나 추정을 계산으로 위장한다.

| 유형 | 오차 | 검정 양식 |
|---|---|---|
| `identity` | 없음 | 값이 아니라 **입력의 출처**를 본다 (`formula`) |
| `elasticity` | 계수 불확실성 | 구간이 사슬을 따라 곱해진다 (`source` 필수) |
| `statistical` | 데이터에서 | 코호트 대비 (`exposure`·`reference`) |

셋이 한 사슬에 있으면 **점 예측**이 나온다("이 사건은 3.1% [1.8, 4.4] 여야 한다").
점 예측은 코호트 중위보다 훨씬 쉽게 죽고, 그래서 증거로 강하다. 구간 폭이 종목 일간
변동성보다 넓으면 `verdict()` 가 `무력` 로 표시한다 - 가정을 벌려 반증을 피한 통과를
정상 통과와 구별해 이름 붙이는 것이 정직성 장치다.

### 15.3 `global_fit` χ² → `chain.budget`

적합도 카이제곱은 "이 DAG 가 모집단 공분산과 정합하나"를 묻는 타입 수준 도구다. 귀속은
**같은 예산을 나눠 쓰므로** 합이 잔차를 넘으면 그 자리에서 틀렸다 - 훨씬 싸고 날카롭다.
`fit.global_fit` 은 발견 루프용으로 남았고 게시 경로는 부르지 않는다.
미설명분은 항상 산출한다(설명 비율만 내면 남은 폭이 사라진다).

### 15.4 지운 제약 (순 제약 수는 줄었다)

| 지운 것 | 왜 |
|---|---|
| 노드 종별 6종(`KINDS`) | 사슬의 매개(회계 항목·기대·수급)가 그 칸에 안 맞는다. `says`+`observed` 로 교체 |
| 규칙 3 (가격 노드에 MARKET 부모) | 2층이 상류에서 끝난다. 그래프가 시장을 다시 그릴 이유가 없다 |
| 규칙 4 (TARGET 보존) | 결론 노드는 `Proposal.target` 하나 |
| 규칙 6b (`effect: CDE\|NDE\|NIE`) | 간선 유형이 증명 양식을 정한다 |
| `claims` 사다리 · `unit`·`strata` 어휘 | 어휘 맞추기에 주의를 쓰게 했다 |
| "대조는 금융상품 기반" · "되도록 scope=type" | 참조집합을 미리 못 박는 지시 |
| 브리프의 판정 지시("방향을 못 쓴다" 등) | 결론을 미리 알려주는 것 |
| `LIMITS["edges"] 12 → 32`, `depth 4 → 12` | 상한이 사슬을 자르면 안 된다 |

**수치 금지도 풀었다.** 연역 사슬에서 수치는 본질이라 금지하면 사슬이 불가능하다. 대신
`source` 없는 값을 파싱에서 거부한다 - 날조를 금지로 막지 않고 **출처 대조로 죽인다**.

### 15.5 추가한 검사 (프롬프트에서 빼는 대가)

접지 기준을 선언에서 내용으로 옮겼고(`events` 를 적은 노드만 검사 + 접지된 노드 0개면
위반), 결론 노드 유일성(종점이 둘이면 예산이 정의되지 않는다), 유형별 필수 항목,
`invariant_to`(간선이 의존하지 않는다고 선언한 것 = 사양 곡선의 축)를 받는다.

원칙 한 줄: **기계가 검사할 수 있는 것은 프롬프트에서 뺀다. 검사할 수 없는 것만 남긴다.**
도메인 예시는 주지 않는다 - 예시를 한 번 주면 사슬의 길이·매개의 종류·코호트의 정의를
그 예시가 결정한다.

| G4 가 p 만 대조 | 원장에 `date` 로 돌린 호출이 있고 R 에 `label` 이라 적으면 통과. G6 가 읽는 값이 R 의 자기 신고였다 | **(p, null_kind) 쌍으로 매칭**하고 G6 가 매칭된 원장 항목의 종류를 읽는다 |

| `two_sided` 미기록 | 양측 p 로 방향을 주장해도 막을 수 없었다 | 원장에 `two_sided` 저장 + **G6b** 가 `DIRECTIONAL`(L3)에 단측 강제 |
| 스펙 민감도 미탐지 | 원장의 p 가 α 를 가로질러도 산출물이 침묵 | `Ledger.spec_sensitive()` → `EdgeProof`·감사블록·**확신도 강등**(게이트로 죽이지 않는다 — 막으면 한 번만 재고 끝낸다) |
| `global_fit` 기각 시 강등 없음 | 그래프가 기각돼도 findings 가 그대로 나갔다 | χ² 자체를 `chain.budget` 으로 교체. 초과면 `survived=False` + 사유가 `killed_by` 로 |

| ruff E741 (`fit.py` 의 `O`) | 선행 부채 | `L2` 로 개명. `src`·`tests` 전체 clean |
