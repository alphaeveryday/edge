# 인과귀속 설계 — 합의판

2026-08-01 대화에서 수렴한 설계의 전량 기록. 이 문서가 인과귀속의 설계 SSOT 다.
다이어그램: `causal-attribution-frame.drawio` (1p 기계 프레임 · 2p 파이프라인 · 3p 튜플 체계 as-built).
코드 대응: `src/edge_analysis/statics/` (정적 층) · `src/edge_analysis/causal/` (P0–P9, §20 매핑).

한 줄: **크기는 산술(시간 항등식)에서, 인과는 역사(타입 수준 패널)에서, 조건은 계수(조절자)에서. 셋을 섞으면 실패가 재발한다.**

## 0. 목적

한 셀(종목|ETF, 날짜)의 유의한 변동에 대해:

- **이슈 간 순위** — 이 종목의 하루를 무엇이 얼마나 움직였나
- **종목 간 순위** — 이 이슈가 어느 종목·섹터를 가장 움직였나
- **미설명 몫** — 1급 항목. 1위가 될 수 있어야 정직하다

가중치: 인사이트 0.4 · 설명력 0.25 · 인과구조 0.2 · 타당성 0.15.
인사이트의 조작적 정의: $-\log p(u_i \mid \text{서프라이즈}, \mathbf{s}_{t^-})$ — **조건부로 놀라운 정도** (§14).

## 1. 세 분리

시간 분해는 **성과기여 분석(회계 표준)이지 인과추론이 아니다.** 인과 주장이 없어서 편향이 없다 — 공짜가 아니라 아무 말도 안 하는 대가. 인과는 게이트(§12)와 구조방정식(§10)이 붙인다.

## 2. ETF 기계 프레임 (정적 층의 뼈대)

```
전일 미국장·야간선물 ─┐
금리·환율·유가 ────────┼→ 공통요인 ──────→ 구성종목 r_i → NAV 경로 Σw_i·r_i → ETF 가격
정책·규제 ─────────────┼→ 테마·섹터 충격 ─↗                                    ↑
전방수요·경쟁사·원자재 ┼→ 기대 갱신 ──────↗                                    │
기업 고유사건 ─────────┘                                                       │
ETF 설정·환매·개인수급 ──→ 괴리 경로 ──────────────────────────────────────────┤
환율 ────────────────────→ FX 경로 ────────────────────────────────────────────┘
```

심장은 마지막 분기다: **NAV 경로냐 괴리 경로냐.**
- 바스켓이 움직여서 ETF 가 움직였다 → 종목 이야기. 귀속은 종목으로 내려간다
- ETF 만 움직이고 바스켓은 조용하다 → 수급. 되돌아온다. **유일하게 ETF 고유이고 거래 가능한 발견**

실측 (2026-08-01, RDB):

| 사실 | 값 | 함의 |
|---|---|---|
| `price_movement_trigger` | 391행 (탐지기 이미 존재) | 셀 게이트 L0 은 있다 |
| `etf_contribution_observation` | 242행, top3 기여비율 ≥0.5 가 78% | ETF 문제가 **종목 3개 문제로 축소**된다 |

인사이트는 차수가 아니라 특이성에서 온다: $\text{인사이트} = \text{관측된 연결} - \text{ETF·산업·β 로 예상되는 연결}$.
기준선은 경쟁 가설이 아니라 **항상 있는 귀무 가지**다 — STORM base 팔이 "시장→β→종목"을 후보로 낸 것이 실패의 핵심.

다종목 사건의 가치는 인사이트가 아니라 **식별**이다: 사건×종목 이분그래프가 연결돼야 "충격 크기"가 정의된다(§10). 지금 89%가 1차수라 절단 — 충격 절대크기 포기의 근거(§18).

## 4. 잔차 DAG 는 4층 — 층 건너뛰기 금지

```
L1 충격 → L2 채널 → L3 추정대상 → L4 관측
```

- **L1 충격**: `event_id` 접지 필수 + τ + 53종 타입. 접지 없는 인용 = 날조 (STORM base 실측: `EVT_KR_20260601_001` 전량 허구)
- **L2 채널**: §5 의 8종. **채널은 산업을 가로지른다** (환 노출 ∋ 조선·화학·반도체·항공) — 자명하지 않은 연결의 원천이고, 노출이 연속이라 쌍이 자명해지지 않는다
- **L3 추정대상**: 회계 좌표 `(account_id, bsns_year, fs_div)` + 부호. 이것이 있어야 크기가 틀릴 수 있다 (기대변화 × 노출 → 예상 수익률 검산)
- **L4 관측**: 자기 $u_i$ + **확증**(같은 채널 고노출 $u_j$) + **위약**(같은 산업 저노출 $u_k$). 다른 종목이 자동 검정 표본이 된다

`뉴스 → 주가` 는 반증 불가라 DAG 가 아니다. 노출이 반증을 만든다: $u_i \approx \text{노출}_i^{(c)} \times \Delta^{(c)}$ — **용량-반응 정렬**이 깨지면 그 채널 가설은 죽는다.

## 6. 가설 튜플 (최종형)

```
(취약성집합, 방아쇠, 채널, 노출원, from_역할, to_역할, 결과종류, 부호)

취약성 ::= (계열족, 변환, 비교, 임계백분위)*    느린 원인 — 왜 이 회사·얼마나
방아쇠 ::= (점 | 계열, 식별)                    빠른 원인 — 왜 지금
           점 → 사건타입 53 · 계열 → 계열족 9 × 이상판정(전역 임계)
노출원 ::= 속성(계열족, 변환) | 관계(온톨로지 경로, 홉수)
```

배치 규칙 셋:
1. **시간 스케일이 슬롯을 정한다** — 느림→취약성, 빠름→방아쇠. (SVB: 금리 급등은 방아쇠가 아니라 듀레이션 갭을 실현시킨 취약성 생성기. 방아쇠는 예금유출 개시)
2. **전역 상태는 노출로 환원** — 국면 자체는 방아쇠(지수잔차 계열충격), 종목별 민감도가 취약성. 전역 계열은 횡단면 대비가 없어 그 자체로는 검정 불가
3. **동시 다중 원인은 튜플 여러 개** — 배분은 트리(§9)가 한다

수준은 단독 원인이 될 수 없다("어제도 나빴는데 어제는 안 빠졌다"). 수준 = 취약성(가능 여부·크기), 방아쇠 = 시점. INUS / Rothman causal pie 구조.
관계 노출은 교란에 약하다 (사외이사 겹침 ≈ 같은 지역·규모·업종의 대리) → **위약 = 같은 속성 ∧ 관계 없음** 을 강제.

## 7. 추상화 층위 — L2 가 경계인 이유

문제의 이름: **분기 자유도 (researcher degrees of freedom / garden of forking paths)**. 구조적으로는 $\phi$ 의 비단일성 — $|\phi(h)|>1$ 이면 검정자가 가설을 다시 쓴다.

층위는 **양화 대상**으로 이루어진다:

| 층 | 양화 대상 | 검정 |
|---|---|---|
| L0 토큰 (키미3, event_id=X) | 없음 (상수) | ❌ n=1 · id 날조 위험 |
| L1 타입 | 그 타입의 모든 사건 | △ 경로 미정 |
| **L2 채널** | 그 메커니즘의 모든 경로 | ✅ **최적 경계** |
| L3 집합 | 술어가 정의한 개체군 | ✅ (L2에서 파생) |
| L4 조건 | 조건부 사건 | ✅ (선택) |
| L5 서사 | 해석 — 열거 불가 | ❌ 분기 ∞ |

L2 가 경계인 이유: **채널 하나가 타깃 트라이얼 슬롯 다섯을 동시에 닫는다** — 노출 정의 → 대상군 → 위약군 → 결과 → 검정 형태. 판정 기준은 Hernán 타깃 트라이얼: 기본값이 유일한 슬롯만 비울 수 있다(조절상태만 해당).

## 8. 환원 (토큰 → 타입) — 새로운 사건의 처리

역사에 같은 종류가 없으면 판정불가. 유일한 출구는 추상 수준 올리기:

```
"키미3 출시"        0건    → 판정불가
"저가 대체재 등장"  340건  → 검정 가능
```

**추상 수준 = 표본↔국소성 손잡이.** 데이터가 늘어도 이 긴장은 사라지지 않는다.

- 환원은 **가설 에이전트**가 한다 — 튜플의 `사건타입`·`채널` 슬롯을 채우는 행위가 곧 환원
- **다중 환원 강제** (≥2, 경쟁): 단일 가설은 확증만 한다
- **환원 검사**: 환원이 옳았다면 오늘의 횡단면 반응 패턴(노출 순 정렬 방향)이 그 타입의 과거 패턴과 닮아야 한다. 환원도 가설이고 반증된다

추출 에이전트는 **없다**: 충격 특징 $\mathbf{z}$ 의 사용처가 전부 소멸 (충격 크기 $g$ 는 고정효과가 흡수 · 이슈 순위는 트리 · 조절자는 계열 계산). 특징 스키마 53종 작업 폐기. **에이전트는 둘이다.**

## 9. 시간 분해 트리 — 종속변수 생성기 + 상한

$$r_{\text{today}} = \underbrace{g}_{\text{갭}} + \sum_k \big(\beta_i f_k + u_{i,k}\big), \qquad \textstyle\sum = 1 \text{ (항등식)}$$

- **창은 결정론 생성**: τ 목록 + 전역 상수 $w$ → 하루의 분할. 사이 구간은 잔여로 자동. **창을 고르는 것 = 종속변수를 고르는 것 = p-hacking** — 선택 지점 0
- **미설명이 1급 노드**: 합=1 제약이 강제. "전부 설명"이 날조의 구조적 원인
- 시간 분할은 식별 장치다: 15분/390분 → **표준오차 1/5** · 같은 날 타 사건 배제 · 동일일 다중 사건 분리
- **갭은 못 자른다** → 공변량으로 좁힌다: `u_gap ~ 처치×노출 + 전일 미국장 + 환율변화`. 한국 종목은 갭이 지배적(실측 000020: 갭 |0.415%| vs 장중 |1.079%|, 갭이 더 큰 날 24.5%)이라 이 보강이 필수
- 배제가 공짜: τ 가 창 밖이면 자동 탈락 ("밤에 빠졌으면 낮의 사건은 범인이 아니다")

데이터: `raw/kr_intraday/fmp_5min/{ticker}.KS.parquet` — 종목당 ~64,020봉, 2022-11-10~2026-07-16, 09:00–15:30, 77봉/일. **3.7년치가 이미 S3 에 있다.** canonical 승격이 배관 최우선.

## 10. 구조방정식 — 창별 회귀 + 합 제약

구조방정식 구하기 = 계수 구하기 (같은 일). 구조계수 = 직접효과(화살표 하나), 인과효과 = 총효과(경로 합, 계수의 함수로 유도).

$$u_{i,k} = \sum_c \tau_c(\mathbf{v}_i)\cdot x_i^{(c)}\cdot D_{e,k} + \alpha_k + \varepsilon_{i,k} \qquad \text{s.t.} \qquad \sum_k(\beta_i f_k + u_{i,k}) + g = r_i$$

- **분해가 종속변수를 만들고 상한을 준다. 구조방정식이 그 안에서 값을 낸다.** 두 방법의 경쟁이 아니라 한 파이프라인
- **식별집합 = 교집합**: $\Theta = \text{CI}(\hat\tau x) \cap (0, \text{창의 몫}]$ — 가격 수준의 부분식별이 곧 이것
- **채널은 잠재변수 → 소거**: 노드가 아니라 노출 벡터의 인덱스. 노출들이 상관이면(HBM 비중 ↔ 반도체 산업) $\tau_c$ 개별값이 아니라 합만 식별 → **채널별 구간**. 표본 늘려도 안 풀린다 — 노출이 실제로 상관이라서
- **과대식별 검산**: 창의 몫(시간·오늘·항등식) vs 채널 예측 $\hat\gamma^{(c)} x_i$ (역사·패널). 일치 → 설명 성립 / 시각만 → 우연 의심 / 예측만 → 예고·유출
- 상관된 부모는 묶어 한 항으로 보고 (Shapley 배분의 임의성)

## 11. 식별 목표 — 층마다 다르다

| 추정대상 | 형태 | 방법 | 근거 |
|---|---|---|---|
| $\tau_c \neq 0$ (엣지) | **3값**: 성립·불성립·판정불가 | 패널 검정, 사건 고정효과, 폴드 A | 표본 부족은 "모른다"다. 불성립으로 위장 금지 |
| $\tau_c(\mathbf{v})$ (계수) | **구간** | DML 교차적합, 폴드 B | 노출 공선 → 합만 식별 |
| 오늘 기여 $\tau_c x_i D$ | 점 + 구간 | 계수 × 오늘 노출 | 창의 몫이 상한 |
| 기여 순서 | 순위 + **동순위** | 부트스트랩 | 1·2위 구간 겹치면 동순위 — 아니면 순위 날조 |
| 창의 몫 | 점 (무편향) | 항등식 | 인과 주장 아님 |

**순위는 셋째 줄의 산물이다.** 항등식에서 읽은 순위는 서술("언제 움직였나")이지 인과("없었다면")가 아니다 — 트리 몫을 인과 순위처럼 제시하는 것은 철회된 설계.

## 12. 귀속 가능성 게이트 (A–E) — 거절이 기능이다

단일 사건 점식별은 일반적으로 불가능. 깨는 것 여섯: 동시 사건 · 사전 유출 · 공시 타이밍 내생성 · 노출 내생성(헤지) · 잔차의 모형 의존성 · 나쁜 통제(요인 오염).

특히: 종목이 요인에 들면 $u_i \ni -\beta_i v_i r_i$ — **요인을 빼면 효과 일부를 같이 뺀다.** 설명 가치가 큰 종목(= 25개 대형주) = 식별이 가장 안 되는 종목. 구조적 저주.

```
A 노출 분산    같은 채널 노출 종목 ≥ k, 분산 충분
B 시각 분리    τ 전후 분리 가능, 창 안 경쟁 사건 없음
C 무예고       τ 이전 누적 잔차 무의미
D 요인 무오염  지수 내 비중 v_i 작음         ← 대형주 탈락 지점
E 노출 외생    노출이 사건 이전에 고정
```

전부 통과 → 점추정 / A∨B 실패 → 구간만 / C∨E 실패 → 배제만 / D 실패 → 요인 재구성 또는 거절.
**항상 답하는 시스템은 반드시 지어낸다** (STORM base 실측). 배제("A 때문은 아니다")는 귀속보다 강하고 단일 사건으로 성립한다 — 인사이트 0.4 와도 맞는다.
극단 결과(파산·상폐)는 기저율 때문에 직접 검정 불가 → **같은 취약성을 온건 충격에서 대리 검정** (스트레스 테스트 논리). 파산은 그 엣지의 꼬리로 해석.

## 14. 조건부 인과 — 조건화가 아니라 매개변수화

상태는 부모가 아니라 **조절자**: 가격으로 화살표를 쏘지 않고 계수를 바꾼다. $u_i = \sum_c \gamma^{(c)}(\mathbf{s}_{t^-})\cdot\text{노출}_i^{(c)}\cdot\Delta^{(c)}$.

상태로 표본을 쪼개면 N=1 로 회귀 (조건화의 극한 = 토큰). **상태를 연속 특징으로** 넣고 $\tau(\cdot)$ 를 전 표본에서 학습 = CATE. 국소적이면서 검정 가능.

에이전트의 절차는 추론이 아니라 **조회**다:
1. 서프라이즈 부호·크기 판정 (코드)
2. 상태 버킷 판정 (코드)
3. 역사의 같은 (서프라이즈 × 상태) 조건부 분포 (코드)
4. 오늘이 분포 안 → **설명 끝. 이상이 아니라 규칙** / 밖 → 초과분만 새 사건으로
5. 진짜 설명 대상 = $u_i - E[u_i \mid \text{서프라이즈}, \mathbf{s}_{t^-}]$ (두 번째 차감)

렌더 규율: 조건은 사전 고정 목록에서만 · 교호항 유의할 때만 언급 · **반사실 쌍으로 말한다** ("과열이라 −1.8%. 정상이었다면 −0.4%") · positivity (반대 사례 有) 없으면 침묵.

하이닉스 사례의 해체: "역대급 실적인데 하락" 은 $\Delta\ln P = \Delta\ln(\text{기대 펀더멘털}) + \Delta\ln(\text{배수})$ 에서 두 항의 부호가 반대였을 뿐 — 실적은 첫 항을 올렸고(+), 키미3(AI 자본지출 서사)가 둘째 항을 내렸다(−). 필요한 노드: 배수 · 기대 2층(컨센서스+포지셔닝) · 서사 채널 · 외부 주체 · 수급 포지셔닝 상태.

## 15. 충격 측 상태 (유효 충격)

같은 25bp 인상도 "예상됐으면" $g\approx 0$. 상태는 세 곳에 있다: 충격 측 $g(\mathbf{z})$ · 채널 측 $\gamma(\mathbf{m})$ · 대상 측 $h(\mathbf{v}_i)$ — 곱 구조 (하나가 0이면 효과 없음).

**단, 분해는 식별되지 않는다**: $g\gamma h = (\lambda g)(\gamma/\lambda)h$. 사건×종목 이분그래프가 연결될 때만 (양방향 고정효과) 식별 — 지금 89% 단일 종목이라 불가. "충격이 컸다"와 "종목이 민감했다"를 못 가른다 → 정직한 표현은 "이 종목에서 이만큼 작동했다"까지.

"쩌는 기술이라서 인과성이 있다"는 **범주 오류**: 충격 강도는 엣지 존재의 증거가 아니다. 없는 경로로는 아무리 센 충격도 아무것도 못 만든다.

## 16. 인스턴스 결합 — 노출 인스턴스화 원칙

추상 타입 결합(§3) 다음 층. **인스턴스 간선은 새 간선 타입이 아니라 채널 노출의 인스턴스화다.** 모든 인스턴스 간선은 5-튜플을 지닌다:

$$(\text{채널}, \; \text{노출원}, \; \text{부호}, \; \text{강도}\in\text{연속}, \; \text{available\_at})$$

"은행업 ↔ 중요한 경제지표" 같은 러프 간선 금지 — 부호도 강도도 출처도 없는 간선은 검정이 정의되지 않는다. "은행이 금리에 민감"은 이렇게 적는다: `(R금리신용, 속성(재무파생/이자마진 or 차입금, 수준), 부호 ±(차입 − / 예대 +), 강도 = 백분위, available_at = 재무 공시시각)`.

### 16.1 관계 어휘가 닫혔다 (19R as-built)

## 17. 에이전트 계약

| | 하는 일 | 금지 |
|---|---|---|
| **가설 (=환원)** | 닫힌 어휘에서 튜플 슬롯 채우기 · 환원 후보 ≥2 | id 생성 · 수치 · 자유 텍스트 · 새 어휘. 검사 실패 시 튜플 폐기 (자동 보정 금지 — 보정이 곧 대필) |
| **검정** | 튜플 → ObjectSet 결정론 전개 → 노출 계산 → 패널 검정 → 3값 + N + 구간 + 위약 | **표본에 관한 모든 선택** (창·요인모형·절단·유의수준·부분표본·튜플 수정). N 부족 → 판정불가로 종료. 다른 부분집합 찾기 금지 |

경계 한 줄: **특징 채우러 탐색은 자유, 표본 찾아 헤매기는 금지.** 이유: 표본을 고치면 "세는 횟수"가 늘어난다 (후보 20개 → 우연 유의 1개 · 버린 19개는 기록에 없다). 특징은 표본을 안 건드린다 — 단, 특징도 사전 고정 스키마여야 하고 전부 보고한다.

부분집합은 고르는 게 아니라 유도된다: 대상군 = 노출원 상위 · 위약군 = 같은 속성 ∧ 노출 없음 · 표본 = 그 타입 전 역사. 관계 기반 비교군(예: "사외이사 겹치는 은행")은 검정자가 떠올리는 게 아니라 **튜플의 노출원 슬롯에 적혀 있어야** 한다.

## 20. 개발 계획과 P0–P9 매핑

기존 `edge_analysis/causal/` P0–P9 (7,868줄) 는 **골격 유지, 정적 층이 앞에 선다**:

|---|---|---|
