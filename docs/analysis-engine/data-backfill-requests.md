# 인과귀속 백필 요청 대장

설명 품질의 병목은 코드가 아니라 데이터 좌표다. 각 요청은 **어떤 제약을 푸는지**와
함께 적는다 — 도착하면 해당 줄을 갱신하고, 새 결손이 라이브에서 발견되면 여기 추가한다.
(운영 규약: 부재 선언의 사유 문자열이 이 문서의 행과 1:1 로 대응해야 한다.)

## 요인 재구성 (데이터 아님 — 계산 작업, 참고)
게이트 D 거절 셀(하이닉스·삼성)의 점귀속을 열려면 **해당 종목 제외 요인**(leave-one-out
시장 평균)이 필요하다. 이건 백필이 아니라 `_BASE` 의 `ar` 정의 확장이며, #7 이 오면
비중 가중 제외가 가능해진다.
