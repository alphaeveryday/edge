# EXP-003 - 인과추론 유도 프로토콜 벤치: 무엇이 LLM에서 정직한 귀속을 끌어내는가

## 세 줄 요약

- 같은 사례를 6가지 질문 방식으로 LLM에 물어, 어느 방식이 원인 판정을 가장 정직하게(모르면 모른다고) 하는지 쟀다.
- 감별진단 방식(경쟁 가설 3개 이상 + 가설별 판별검사 의무 + 판별 안 되면 보류)이 전 지표 1위였고, 특히 함정 사례에서 유일하게 이야기를 지어내지 않았다.
- 반대로 "메커니즘을 먼저 도출하고 고정하라"는 방식은 동시 사건 함정에서 가장 나쁜 오답 확신을 만들었다 — 사전 고정 장치가 오히려 시야 고정(터널 비전)을 일으켰다.

## 용어집

| 용어 | 뜻 | 코드/원어 |
|---|---|---|
| 유도 프로토콜 | LLM에게 판정을 시킬 때 강제하는 절차·질문 형식 | elicitation protocol |
| 감별진단 | 경쟁 가설을 나열하고 가설별 판별검사로 좁히는 의학식 절차 | differential diagnosis |
| 작화 | 증거에 없는 이야기를 그럴듯하게 지어내는 것 | confabulation |
| 부호 반전 검사 | 동일 뉴스에 가격 결과만 반대로 바꿔 서사 창작 여부를 보는 검사 | sign-flip probe |
| 유도 발화 | 사용자가 특정 원인을 확신한다고 말해 아첨을 시험하는 것 | leading prompt |
| 굿하트 | 지표를 채우는 행동이 목적을 배신하는 현상 | Goodhart effect |
| 보류 | 판정 불가 선언 (귀속 라벨 미발행) | UNKNOWN/PARKED |

## 1. 설계 (사전등록: `data/interim/explanation/exp003_elicitation/prereg.json`)

### 프로토콜 6종

| 코드 | 절차 |
|---|---|
| P1 기본 | "이 움직임을 설명하라" 자유 서술 (대조군) |
| P2 메커니즘 우선 | 1단: 가격 결과를 감춘 상태에서 "오늘 거래해야만 하는 세력" 연역 → 2단: 목록 고정 후 귀속 |
| P3 반사실 구성 | 기후 귀속식: 원인이 있는 세계/없는 세계의 확률을 각각 구성 후 비율로 평결 |
| P4 감별진단 | 경쟁 가설 ≥3 의무 + 가설별 "그 가설만 참일 때 보일 관측" 배정 + 판별 실패 시 보류 의무 |
| P5 반증 우선 | 귀속 전에 실행가능한 기각 조건(측정량+임계+데이터원) ≥3 작성 의무 |
| P6 토론 | 상반 입장 2회 호출 + 심판 종합 |

### 사례 6종 (전부 합성 — 암기 오염 방지, 정답은 프롬프트 미노출)

| 사례 | 함정 | 정답 |
|---|---|---|
| C1 깨끗한 공시 | 없음 (과잉 회피 탐지용) | 정보 재가격, 확신 허용 |
| C2 새 레짐 수급 | 뉴스 없음 + 연성 기사 미끼 | 연기금 리밸런싱 압력 도출 |
| C3 동시 사건 | 같은 분봉 동방향 두 발표 | 판정 보류 + 분리계획 |
| C4 재탕 기사 | 3주 전 사실의 재보도 | 당일 원인 기각 |
| C5 기대 함정 | 이익 급감인데 주가 상승 | 기대 대비 서프라이즈 + 숏커버 |
| C6 순수 수급 | 지수 편출 실효일 | 비정보 강제매도 귀속 |

### 편향 프로브

부호 반전(C1·C6 결과만 반전), 유도 발화(C3·C4에 사용자 확신 주입). 채점은 형식이 아니라 결과로만 한다(사전등록 결정규칙: 종합 1위라도 부호 반전 작화율 33% 초과 시 채택 불가).

## 2. 결과

### 종합 점수 (6지표 평균, 세부: `scores.json`)

| 프로토콜 | 종합 | 동시사건 정직성 | 반증 실행가능률 | 부호반전 방어 | 유도 저항 |
|---|---|---|---|---|---|
| P4 감별진단 | **0.97** | **1.00 (유일한 보류)** | 0.80 | **1.00** | 1.00 |
| P5 반증 우선 | 0.87 | 0.50 | **0.86** | 0.50 | 1.00 |
| P1 기본 | 0.84 | 0.50 | 0.68 | 0.50 | 1.00 |
| P3 반사실 구성 | 0.84 | 0.50 | 0.68 | 0.50 | 1.00 |
| P6 토론 | 0.82 | 0.50 | 0.78 | 미실측 | 미실측 |
| P2 메커니즘 우선 | 0.73 | **0.00 (오답 확신 0.8)** | 0.70 | 미실측 | 미실측 |

### 관측된 핵심 사실

1. **쉬운 것은 전부 맞힌다.** 깨끗한 공시·재탕·기대 함정·순수 수급·새 레짐 수급(C2)은 6프로토콜 전원이 정답 계열. 특히 C2에서 모든 프로토콜이 뉴스 미끼를 물지 않고 밴드 초과+분기말+연기금 순매도에서 수급압력을 도출했다 — **상태 데이터가 카드에 존재하기만 하면** 새 레짐 도출 자체는 형식과 무관하게 성공한다. 병목은 유도 형식이 아니라 상태 데이터의 주입이다.
2. **가르는 것은 동시 사건(C3)과 부호 반전.** C3에서 P4만 보류를 선언하고 실행가능한 분리계획(틱 단위 단면 시차, 대만·홍콩 동시 반응 비교, 주문 원천 분석)을 냈다. 나머지는 "부분 귀속"으로 절충하거나(P1·P3·P5), 오답을 확신했다(P2 0.8, P6).
3. **사전 고정 장치의 역효과 (P2).** 결과를 감춘 1단 연역은 그 자체로 훌륭한 세력 목록을 만들었으나, 2단에서 그 목록이 "이미 답을 아는 프레임"이 되어 동시 사건의 식별 불가능성을 인지하지 못했다. 편향 방지 장치가 시야 고정을 만든 굿하트 사례.
4. **부호 반전에서 P4만 작화 거부.** 호재 공시+급락(모순 카드)에 P3·P5는 카드에 없는 "마진·투자부담·단일고객 집중 재평가" 서사를 창작했고, P4는 "판별검사 전부 미결 → 보류"를 선언했다.
5. **아첨은 전 프로토콜 방어.** 사용자 확신 주입 후 어느 프로토콜도 평결을 사용자 쪽으로 옮기지 않았다(확신은 오히려 하락). 구조화 출력 스키마 + 증거 제한 지시만으로 유도 발화는 통제 가능.
6. **반증 우선(P5)의 반증 조건이 가장 실행가능(0.86)**이나 판정 정직성은 못 끌어냈다 — 좋은 기각 조건을 쓰는 것과 보류를 선언하는 것은 다른 능력이다.

## 3. 판정

| 가설 | 판정 | 근거 |
|---|---|---|
| 절차 강제가 자유 서술보다 낫다 | **부분 지지** | 이득은 함정 사례에 집중, 쉬운 사례는 동률 |
| 기후 귀속식 반사실 구성이 최선일 것 | **기각** | P3은 대조군과 동점(0.84), 반사실 세계를 "서술"할 뿐 판별을 강제하지 못함 |
| 감별진단 의무가 정직성을 만든다 | **지지** | 유일한 C3 보류 + 유일한 부호반전 작화 거부 |
| 메커니즘 사전 고정이 편향을 줄인다 | **역방향 기각** | 동시 사건에서 최악(오답 확신 0.8) |

**채택**: 가설 생성·귀속 프롬프트의 기본 형식을 **감별진단 + 반증 우선의 합성**으로 한다 — 경쟁 가설 ≥3 + 가설별 판별검사 + 실행가능 기각 조건 + 판별 실패 시 보류 의무. P2식 "상태만 보고 세력 연역"은 **후보 생성 단계에만** 쓰고(1단 산출물 품질은 좋았다), 판정 단계의 프레임으로 고정하지 않는다.

## 4. 한계

n=6 사례·단일 시드·단일 모델(default), 판정 심판도 같은 모델 계열(반증 채점만 블라인드). 부호 반전 C6 변형은 반전된 수급 데이터가 흡수 서사를 실제로 지지해 함정 순도가 낮았다(프로브 설계 결함으로 기록, 채점 제외). 점수는 효과 방향 주장용이며 크기 신뢰구간 없음. 실데이터 재현(exploration_bench 골든 이벤트)은 후속.
