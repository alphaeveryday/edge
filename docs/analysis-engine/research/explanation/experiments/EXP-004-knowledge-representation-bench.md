# EXP-004 - 메커니즘 지식 표현 벤치: 카드 없음 vs 자연어 vs 형식 카드 vs 절차 강제

## 세 줄 요약

- 같은 고난도 사례 10종을 "배경지식 없음 / 자연어 서술 / 형식 카드 / 형식 카드+적용절차 강제" 4가지 지식 표현 × 2가지 질문 형식으로 풀게 해(80회 + 약한 모델 16회), 지식을 어떤 언어로 넣어야 하는지 쟀다.
- 강한 모델에서는 표현 형식이 거의 무차별(전 구성 0.94~1.0)이었다 — 결정적 관측이 사례에 있으면 모델이 스스로 추론한다. 그러나 **약한 모델에서는 형식 카드가 함정 정답률을 5/8에서 7/8로 올렸고, "반증 발화 시 카드 기각" 규율은 카드가 있을 때만 작동했다.**
- 부작용도 실측됐다: 카드를 준 구성은 세 요인이 겹친 날 확신을 0.62에서 0.70~0.75로 올리며 과신했다. 결론 — 카드는 형식(YAML)+실행가능 반증으로 넣되, **사건 겹침 판정은 카드보다 먼저, 카드가 뒤집을 수 없게** 배치해야 한다.

## 1. 설계 (사전등록 `data/interim/explanation/exp004_knowledge_repr/prereg.json`)

- 카드 라이브러리 6종(연기금 리밸런싱, 지수 편출입, 숏커버, 편입 팝, 공급사슬 전이, 옵션 만기)을 **정보 등가**의 두 표현으로 작성: 자연어 문단(K1), 형식 YAML(K2). K3은 K2+문자적 적용절차(트리거 평가→반증 실행→생존 카드만 귀속). K0은 미제공.
- 질문 형식: 자유 서술(E0) vs EXP-003 채택형(감별진단+반증 의무, E1).
- 사례 10종은 카드를 시험하도록 설계: 카드 부적합(반대매매 연쇄), **반증 발화**(리밸런싱 조건 성립인데 연기금이 순매수 — 진범은 미 금리), **감쇠**(편입 팝의 최근 6건 평균 +0.1%), 상반 카드 동시 발화(연기금 매도 vs 숏커버 급등), 간접 사슬(미 보조금→고객사→한국 장비주), 크기 불일치(패시브 함의 -1~-3%인데 실제 -9.2%), 3중 교란(금통위+분기말 리밸런싱+옵션만기), 정량 연역(1,100조×0.8%p≈8.8조, 약 7일), 깨끗한 공시(강제끼움 미끼), 교과서 사례.
- 채점: 정답 일치(기계) + 카드 규율(기계, 사용 장부 대조) + 블라인드 심판 4항목(상충 분해·사슬 구성·크기 경보·산술) + 강제끼움율. 사전 결정규칙: 강제끼움율 20% 초과 표현은 기각.

### 약한 모델 슬라이스 (smol, 판별 사례 4종 × 4구성)

| 구성 | 함정 정답 (4사례) | 특기 |
|---|---|---|
| 지식 없음 + 자유 | 3/4 | 감쇠 실패 |
| 지식 없음 + 감별 | 2/4 | 감쇠 실패 + 반증 사례를 MIXED로 혼탁 |
| **형식 카드 + 자유** | **4/4** | 감쇠·반증 기각·부적합 전부 정확 |
| 형식 카드 + 감별 | 3/4 | 감쇠 평결만 실패 |

### 관측된 핵심 사실

1. **표현 형식의 가치는 모델 역량에 반비례한다.** 강한 모델은 사례 관측에서 스스로 메커니즘을 도출(지식 없음 구성도 반대매매 연쇄를 정확히 명명). 약한 모델은 형식 카드가 있어야 같은 수준에 도달 — 카드는 **역량 평준화 장치**다.
2. **반증 규율은 카드의 고유 기여.** "리밸런싱 조건 성립 + 연기금 순매수 실측" 사례에서 카드 보유 구성 전원이 REJECTED_BY_FALSIFIER를 장부에 기록하고 진범(미 금리 급등)으로 이동했다. 이 명시적 기각 기록은 지식 없는 구성에서는 구조적으로 불가능하다 — 감사 가능성의 차이.
3. **강제끼움은 관측되지 않았다** (0/24 기회). "맞을 때만 사용 + 사용 장부 의무" 지시로 충분했다. 우려했던 부작용은 이 형태로는 나타나지 않음.
4. **실측된 진짜 부작용은 교란일 과신.** 3중 교란 사례에서 지식 없음 구성은 PARTIAL(확신 0.62)에 머문 반면, 카드 구성 6개 중 5개가 CAUSAL_LIKELY(0.70~0.75)로 상승 — 세 요인 중 둘을 카드가 "설명해주자" 해결됐다고 착각했다. **카드는 겹침 판정을 대체하지 못하며, 겹침 게이트가 카드 적용보다 선행해야 한다.**
5. 절차 강제(K3)는 강한 모델에서 추가 이득 없음. 감쇠 상태를 장부에 적고도 평결은 CAUSAL로 내는 사례(K3E0)가 남음 — 장부 기록과 평결 보정은 별개 능력.
6. 정량 연역(8.8조·약 7일)·간접 사슬·크기 경보·상충 분해는 전 구성 통과 — 산술과 사슬 구성은 표현 축의 병목이 아니다.

## 3. 판정

| 질문 | 판정 |
|---|---|
| Q1 지식 주입이 함정을 개선하는가 | 강한 모델: 무차별(천장). 약한 모델: **지지** (5/8→7/8) |
| Q2 자연어 vs 형식 | 형식 우세는 규율(장부·기각·상충 인지)에서만. 자연어는 상충 카드 동시 발화 인지에서 약함 |
| Q3 절차 강제의 추가 이득 | 기각 (강한 모델 기준) |
| Q4 감별 유도의 카드 위 추가 이득 | 지식 없음에서만 뚜렷 (0.965→1.000) |
| Q5 강제끼움 | 미관측 (사용 장부 의무가 유효한 방어로 추정) |

**채택**: 메커니즘 지식은 **형식 카드(YAML) + 실행가능 반증 + 사용 장부 의무**로 넣는다. 근거: 약한·저비용 모델에서 이득이 실측되고, 강한 모델에서 비용이 없으며, 기각·감쇠가 감사 가능한 기록으로 남는다. 단 두 가지 강제 조항을 함께 채택한다 — ① **사건 겹침 게이트는 카드 적용 이전에 실행되고 카드가 뒤집을 수 없다** (교란일 과신 방어), ② 카드의 감쇠·기각 장부 기록은 평결 상한(claim_ceiling)과 기계적으로 연동한다 (장부 따로 평결 따로 방지).

## 4. 한계

사례 10종·단일 시드, 카드 6장(전부 수급·구조 계열), 심판 동일 모델 계열. 사례 카드가 결정적 관측을 항상 포함 — 관측이 불완전한 현실 조건에서 표현 축 차이는 더 클 수 있다(미검). 약한 모델 슬라이스는 4사례 한정. 프로브(부호 반전·유도)는 EXP-003 결과를 원용하고 재실행하지 않음.
