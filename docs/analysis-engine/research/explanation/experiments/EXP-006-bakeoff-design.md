# EXP-006 설계 상세 — 판정기 6종과 사례 6유형의 정의

## 요약 (3줄)

주가가 왜 움직였는지 답하는 자동 판정기 여섯 가지를, 정답을 우리가 미리 아는 시험 문제 48개로 채점했다.
이 문서는 그 여섯 판정기가 각각 어떤 지시를 받는지, 시험 문제 여섯 유형이 각각 어떻게 만들어지고 왜 그 답이 정답인지를 코드 기준으로 적는다.
결과와 순위는 결과 문서에 있고, 여기는 "무엇을 어떻게 만들었나"만 다룬다.

## 용어집

| 용어 | 정의 |
|---|---|
| 암(arm) | 비교 대상이 되는 판정기 설계 1종. 본 실험에 6개 |
| 사례 카드(case card) | 판정기에게 주는 시험 문제 지문. 6개 필드로 된 텍스트 |
| 정답 장부(ledger) | 사례별 정답 기제와 구성 근거를 담은 파일. 판정기에게는 비공개 |
| 기제(mechanism) | 가격 변동의 원인 분류. 본 실험은 7개 어휘 고정 |
| 잔차(residual) | 종목 수익률에서 시장 수익률을 뺀 값. "시장 탓이 아닌 부분" |
| 러너 컨텍스트(runner_context) | 카드에 딸린 과거 66일 수치 배열. 검정 실행 전용 |
| 시점 안전(PIT-safe) | 판정 시점 이후의 데이터를 볼 수 없게 만든 상태 |
| 주입(injection) | 실제 시세의 특정 날에 알려진 크기의 가짜 효과를 더하는 조작 |
| 뉴스 섬(news island) | 실제 기사 제목 데이터가 존재하는 달(2021-06, 2026-06) |
| 패스1/패스2 | 1차 판정 / 검정 실행 결과를 보고 한 번 수정하는 2차 판정 |

## 1. 공통 실행 계약 (모든 암 동일)

### 1.1 입력 — 사례 카드 6필드

```text
[사례 {ID}]
[시장] 당일 시장수익률 {+x.xx%}
[대상] 종목A 당일 {+x.xx%} (시장조정 잔차 {+x.xx%}), 거래량 평시 대비 {n.n}배
[사전] 직전 5일 종목A 누적 잔차 {+x.xx%}
[수급] {문장 | "당시 수급 세부 관측 제한(가격·뉴스 중심)"}
[뉴스] {제목들 | "당일 대상 관련 사건성 기사 없음 (스크리닝 통과)"}
질문: 당일 종목A 움직임의 주요 동인을 분류하라.
```

추가로 과거 참조 요약 1줄이 붙는다: 과거 65일 잔차의 평균·표준편차와 당일 잔차의 과거분포 백분위 (`arms_runner.ctx_summary`).

### 1.2 출력 — JSON 스키마 강제

`verdict`(7어휘 중 1) · `confidence`(0~1) · `reference_class`(비교 모집단 명시) · `reasoning_digest`(200자) · `test_specs`(0~3개 검정 명세). 공통 꼬리 지시: "확신이 서지 않으면 UNKNOWN을 택하고 필요한 데이터를 적어라. 지어내지 마라."

기제 어휘 7개: `INFO_REPRICE`(신규 정보 재가격) · `FLOW_PRESSURE`(수급 압력) · `SHORT_COVERING`(공매도 상환 급등) · `MARGIN_FORCED_SELLING`(신용 청산 연쇄 급락) · `STRUCTURAL_REGIME`(제도 변화 레짐 전환) · `NOISE_NO_ATTRIBUTION`(귀속할 원인 없음) · `UNKNOWN`(판정 보류).

### 1.3 2패스 절차

- **패스1**: 카드+과거 참조 요약만으로 판정 + 검정 명세 발행.
- **검정 실행**: 발행된 명세를 공유 러너(`run_test`)가 러너 컨텍스트에서 기계적으로 실행. 러너 컨텍스트는 d0 이전 66일(과거 60 + 사전 5 + 당일)로 잘려 있어 시점 안전이 구조적으로 보장된다.
- **패스2**: 검정 결과를 돌려주고 평결 수정 기회 1회.

### 1.4 검정 템플릿 3종 (`arms_runner.run_test`)

| 템플릿 | 계산 | 용도 |
|---|---|---|
| `ANALOG_PERCENTILE` | 당일 잔차의 과거 65일 분포 백분위 | "오늘이 특이한가" |
| `PRE_DRIFT` | 사전 k일 누적 잔차와 z값 (기본 k=5) | 정보 누출·수급 드리프트·숏커버 전조 |
| `XSEC_SIGN` | 시장-종목 부호 일치 + 시장 기여비 \|m\|/\|t\| | 공통충격 vs 고유요인 (단면 대용) |

### 1.5 채점 규칙 (`arms_runner.correct`)

정답이 `UNKNOWN`이면 `UNKNOWN`/`NOISE_NO_ATTRIBUTION` 둘 다 정답 처리(작화 거부 인정), 그 외는 완전 일치. 합산 점수 금지 — 원천별 정확도의 비가중 평균(M1)과 층별 표만 보고.

## 2. 사례 6유형 정의 (48 = 12+10+6+8+8+4)

| 유형 | 수 | 배경 데이터 | 정답의 근거 | 측정 표적 |
|---|---|---|---|---|
| S1 합성 | 12 | 전부 모의 생성 | 생성기가 심은 기제 | 바닥 검사 + 보정 |
| H1a 주입(섬 안) | 10 | 실제 시세 + 실제 기사 | 주입한 효과 | 현실 잡음 속 신호 탐지 |
| H1b 주입(섬 밖) | 6 | 실제 시세, 기사 없음 | 주입한 효과 | 뉴스 부재 시 탐지 |
| H3 플라시보 | 8 | 실제 시세 무조작 | "원인 없음" | 오귀속(지어내기) |
| S2 시간여행 | 8 | 실제 역사 사건 실측치 | 사후에 확정된 실제 전개 | 미지 레짐·실전 난이도 |
| S3 쌍둥이 | 4 | S2·H1a 카드 부호 반전 | 세상에 없던 조합 → 거부 | 모순 앞 서사 창작 |

### S1 합성 (`make_cases.sim_world`)

66일 모의 세계: 시장 ~ N(0, 1.0%), 종목 = 시장×1.0 + N(0, 1.2%). 마지막 날(d0)에 기제별 시그니처를 심는다:

| 기제(4종×각3, STRUCTURAL 2) | 심는 조작 | 카드에 남는 단서 |
|---|---|---|
| FLOW_PRESSURE | d0−4~d0에 −0.4%/일 드리프트 | 수급: "연기금 5일 연속 순매도", 거래량 1.3배 |
| INFO_REPRICE | d0 +4.5% | 뉴스: "공급계약 공시(신규)", 거래량 3.2배 |
| SHORT_COVERING | 사전 8일 −0.3%/일 + d0 +6% | 수급: "잔고 상위 5% + 상환 급증", 무재료 급등 뉴스, 4.0배 |
| MARGIN_FORCED_SELLING | d0−1 −5%, d0 −5.5% | 뉴스: "반대매매 급증", 수급: "개인 오전 집중", 3.5배 |
| STRUCTURAL_REGIME | d0 +2.8% | 뉴스: "당국 공매도 제도 변경(신규 제도)", 2.5배 |

품질 관문 `signature_ok`: 심은 시그니처가 잔차 관측면에 실제로 실현됐는지 검사(예: INFO는 d0 잔차 >+3% AND \|사전\|<3%). 미달이면 시드를 바꿔 재생성 — 파일럿에서 잡음이 신호를 덮은 결함을 잡은 뒤 추가된 관문이다.

### H1 주입 (`make_cases.build_h1_h3`)

1. 실제 패널에서 대형주 4종(005930, 051910, 105560, 010130)+KOSPI 수익률 로드 (2016~2026, FMP 일봉).
2. **조용한 날 선별**: 잔차의 60일 이동 z값이 \|z\|<0.7인 날만 후보 (`quiet_days`) — 원래 아무 일 없던 날.
3. 그 날 수익률에 효과 주입: INFO +3.2% / FLOW −1.4%(직전 4일 −0.3%/일 분할) / SHORT +4.1% / MARGIN −4.8% (4기제 순환).
4. 카드 뉴스 필드 = **그날 실제 기사 제목 2건**(섬 안일 때) + 주입 기제에 맞춘 합성 기사 1줄. H1b(섬 밖)는 합성 기사만.
5. 정답 장부에 종목·날짜·효과 크기 기록 (`injection` 필드).

배경 변동성·군집·상관이 전부 실물이므로 "현실 잡음 속에서 심은 신호만 집어내되 과잉 주장하지 않는가"를 잰다.

### H3 플라시보

조용한 날을 **아무 조작 없이** 카드로 만든다. 뉴스 없음, 수급 "특이 관측 없음", 거래량 1.0배. 정답 = `NOISE_NO_ATTRIBUTION`. 여기서 기제를 답하면 지어낸 것이다 — 실전 서비스의 오귀속률에 해당하는 층.

### S2 시간여행 (실제 역사, 위장)

실제 사건 8건. 카드 수치는 그날 실측 패널 값이고, 실명·날짜만 익명화("종목A")한다:

| 실제 날짜 | 사건 | gold | 대상 종목 |
|---|---|---|---|
| 2008-10-01 | 공매도 전면금지 시행 첫날 | STRUCTURAL_REGIME | 신한지주 |
| 2011-08-10 | 공매도 금지(3개월) 발표 직후 | STRUCTURAL_REGIME | 삼성증권 |
| 2015-06-15 | 가격제한폭 ±30% 확대 시행일 | STRUCTURAL_REGIME | 신한지주 |
| 2019-08-05 | 무역분쟁·원화 급락 급락일 | INFO_REPRICE | 삼성전자 |
| 2020-03-16 | 임시 금통위 빅컷+공매도 금지 | STRUCTURAL_REGIME | 신한지주 |
| 2023-11-06 | 공매도 전면금지 첫 거래일 | SHORT_COVERING | POSCO퓨처엠 |
| 2024-08-05 | 경기침체 공포, 서킷브레이커 | MARGIN_FORCED_SELLING | 삼성전자 |
| 2025-04-07 | 관세 충격 급락일 | INFO_REPRICE | 삼성전자 |

gold는 "지금 우리가 아는 사후 전개"로 매겼다. **알려진 한계**(결과 문서 발견 3): 시장 전체가 움직인 날 종목 잔차가 ≈0인 사례(2019·2024·2025 급락일 삼성전자)는 "종목 레벨 무귀속"도 방어 가능해, gold의 귀속 레벨(사건 레벨)과 판정기의 귀속 레벨(종목 잔차 레벨)이 어긋난다. 전원 오답 4건 중 3건이 이 프레임 문제다.

### S3 쌍둥이 (`make_cases.build_s3`)

도너 4건(S2_06, S2_04, H1A_01, H1A_03)의 카드 부호를 문자열 반전하고, 러너 컨텍스트는 `t' = 2m − t`로 변환(잔차 부호만 반전, 시장 성분 보존). 결과물은 "호재 뉴스 + 반대 방향 가격" 같은 세상에 없던 조합. 정답 = `UNKNOWN`(거부) — 그럴듯한 이야기를 지어내면 틀린다.

## 3. 암 6종 정의 (`arms_runner.build_prompt`)

공통: 같은 카드 + 같은 과거 참조 요약 + 같은 출력 계약 + 같은 검정 러너. 다른 것은 **판정 절차 지시**뿐이다.

### ARM_TC — 정리카드 (검증 대상 설계)

지식 카드 라이브러리 K 전문을 프롬프트에 포함. 절차 고정: ① 후보 카드 3개 나열 ② 각 카드의 반증 필드를 카드 관측과 대조 ③ 판별 가능한 검정 명세 발행 ④ 맞는 카드가 없으면 UNKNOWN — "카드를 강제로 끼우지 마라".

**지식 K의 실제 커버리지** (6카드, EXP-004에서 동결):

| 카드 | 클래스 |
|---|---|
| PENSION_REBALANCE 연기금 리밸런스 | FLOW_PRESSURE |
| MSCI_INDEX_FLOW 지수 편출입 | FLOW_PRESSURE |
| INDEX_INCLUSION_POP 편입 발표 팝 | FLOW_PRESSURE |
| OPTION_EXPIRY_FLOW 만기 수급 | FLOW_PRESSURE |
| SHORT_COVERING_SQUEEZE 숏커버 | SHORT_COVERING |
| SUPPLY_CHAIN_EXPOSURE 공급망 노출 | INFO_REPRICE |

→ `STRUCTURAL_REGIME`·`MARGIN_FORCED_SELLING` 카드 **0개**. TC의 S2 붕괴(0.125)의 구조적 원인이며, "카드 커버리지 > 아키텍처" 발견의 근거.

### ARM_A1 — 데이터원리 (기제 언어 금지)

"메커니즘 언어 사용 금지. 오직 과거 참조 분포 대비 오늘 관측의 위치(백분위·희소성)로만 판정. 분포상 특이하지 않으면 NOISE, 특이하지만 데이터로 원인을 못 가르면 UNKNOWN." — 서사 자체를 봉쇄한 극단적 보수 설계. 가설: 작화는 0이 되지만 신호 층을 놓친다 (결과: 쌍둥이 붕괴 0.0, 신호층 최약 — 가설대로).

### ARM_A2 — 형식그래프 (고정 인과그래프)

5간선 고정 그래프와 그 함의를 지시:

```text
정보도착 → 가격점프(지속)          함의: 뉴스 선행 + 반전 없음
수급압력 → 드리프트(수일, 반전경향)  함의: 뉴스 부재 + 드리프트
고잔고+촉발 → 숏커버 급등(부분반전)  함의: 사전 음드리프트 + 과잉 크기
신용청산 → 연쇄급락(익일 부분반등)   함의: 연속 급락 + 오전 집중
제도변화 → 레짐전환                함의: 과거 유사표본 무효
```

"함의와 관측의 부합 여부만으로 판정, 불일치면 기각." 제도→레짐 간선이 있어 S2에서 상대 강세(0.5). 그래프에 없는 조합(H1b 섬 밖 변형)에서 경직 — 혼자 오답 2건.

### ARM_A3 — 스토리라인 (서사 우선)

"이 움직임을 가장 잘 설명하는 이야기를 자유롭게 구성한 뒤, 그 이야기가 참이면 데이터에 남았을 흔적을 검정 명세로 내라." — 유창성의 대가를 재는 대조군. 가설: 커버리지·보정은 최고, 모순 함정에서 창작 붕괴 (결과: 보정 0.046 최고, 쌍둥이 붕괴 0.75 최악 — 가설대로).

### ARM_A4 — 규칙엔진 (LLM 추론 금지)

고정 규칙표 위에서 아래로 첫 매칭, 매칭 규칙 id를 reference_class에 기록:

```text
R1 뉴스에 '제도|금지|규제|당국' AND 신규 레짐        → STRUCTURAL_REGIME
R2 잔차 >+4% AND 신규 공시 AND |사전드리프트|<2%     → INFO_REPRICE
R3 잔차 >+4% AND 무재료 AND 고잔고/상환 언급         → SHORT_COVERING
R4 잔차 <−4% AND 연속 급락 AND 반대매매/오전 집중     → MARGIN_FORCED_SELLING
R5 |잔차| <1% AND 뉴스 없음                        → NOISE_NO_ATTRIBUTION
R6 수급 주체 연속 매도 AND 뉴스 없음 AND 드리프트형    → FLOW_PRESSURE
R7 그 외                                          → UNKNOWN
```

임계값의 이산성이 프로필을 결정: 작화율 최저(0.083), 임계 미달 신호 전부 미탐(혼자 오답 7건).

### ARM_A5 — 상향발견 (사전지식 금지 + 불변성 검사)
