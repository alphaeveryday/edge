# EXP-006 — 설명 아키텍처 베이크오프 사전등록

## 요약 (3줄)

가격 변동의 원인을 설명하는 여섯 가지 설계(암)를 같은 사례 48개에 붙여 어느 설계가 옳은 판정을 내는지 겨룬다.
채점 기준·비교 대상·제외 규칙을 실험 시작 **전에** 이 문서로 고정한다 — 시작 후 변경은 금지된다.
정답은 세 원천(프로그램 생성, 실제 데이터에 심기, 과거 사건 자르기)에서 오고, 원천별로 점수를 따로 보고한다.

## 용어집

| 용어 | 뜻 |
|---|---|
| 암(arm) | 겨루는 설명 설계 1종. 총 6종 |
| 사례 카드 | 암이 받는 입력 — 가격·수급·뉴스 관측 묶음. 정답은 안 들어 있다 |
| 정답 장부 | 사례를 만들 때 기록한 진짜 원인 — 암에게 절대 노출 금지 |
| 평결 | 암의 출력: 원인 분류 + 확신도 + 검정 명세 |
| 2패스 | 1차 평결 → 검정 실행 → 결과 보고 2차 수정 기회 |
| 파일럿 | 본실험 전 소규모 예행 (프롬프트·스키마 결함 탐지) |

## 1. 사례 포트폴리오 (고정)

| 원천 | 수 | 정답의 출처 | 담당 약점 |
|---|---|---|---|
| S1 순수 합성 | 12 | 생성 규칙 (전지적) | 신규 레짐·다환경 조건 |
| H1a 주입(뉴스섬 안) | 10 | 주입 장부 | 현실 잡음에서의 탐지 — 본선 |
| H1b 주입(섬 밖) | 6 | 주입 장부 | 〃 (뉴스 맥락 빈약 조건) |
| H3 플라시보 | 8 | 사건 부재 | 오귀속률 |
| S2 시간여행 | 8 | 사후 실측 | 외적 타당성 |
| S3 반전 쌍둥이 | 4 | 작화 거부 행동 | 정직성 |

- S2 대상 사건(백필 가격 커버 확인): 2008-10 공매도 전면금지, 2011-08 금지, 2015-06-15 가격제한폭 ±30% 확대, 2020-03-16 임시 금통위 빅컷+금지, 2023-11-06 금지, 기타 3건은 카드 제작 시 데이터 가용성으로 확정하고 제작 후 동결.
- 위장 규칙: S2 전 사례 실명·수치·날짜 변형. S3는 S2/H1에서 부호·수급 방향 일관 반전.
- H1 창 선별: 가격 필터(|잔차 z|<1, 거래량 정상, 갭·상하한 없음) + 섬 내 스레드 조회 + 변동성 층화(조용/보통).

## 2. 암 6종 (고정)

| id | 설계 | 지식 접근 |
|---|---|---|
| ARM_TC | 정리카드 — 메커니즘 카드(트리거·방향·크기사전·지문·반증) + 감별진단 + 반증 우선 (EXP-003 승자 + EXP-004 카드) | 카드 K |
| ARM_A1 | 데이터원리주의 — 유사사례 검색·백분위 대조만, 메커니즘 언어 금지 | 없음 |
| ARM_A2 | 완전형식화 — 인과그래프(SCM) 고정 + d-분리 함의 검정 | 그래프(K에서 파생) |
| ARM_A3 | 스토리라인 — 자유 서사 생성 + 사후 검정 명세 | 자연어 K |
| ARM_A4 | 규칙엔진 — if-then 컴파일 규칙 조회, LLM 추론 금지 | 규칙(K에서 컴파일) |
| ARM_A5 | 상향발견 — 레짐 분할 불변 전제 탐색(ICP풍), 카드 금지 | 없음 |

- 공통: 동일 LLM(default), 동일 토큰 상한, 동일 사례 카드. 지식 코퍼스 K는 사례 제작 전 해시 동결.
- 2패스: 1차 평결+검정 명세(JSON) → 공유 러너 실행 → 결과 첨부 2차 수정. ARM_A1·A4는 검정 생성이 구조적으로 제한됨 — 1패스 후 러너 결과 없이 종료 허용.

## 3. 지표 M1~M8 (고정)

| id | 지표 | 계산 |
|---|---|---|
| M1 | 평결 정확도 | 정답 장부 대비 원인 분류 일치 (플라시보=무귀속, 쌍둥이=UNKNOWN/거부가 정답) |
| M2 | 커버리지 | 판정 낸 비율 (UNKNOWN 제외) — M1과 쌍으로 보고 |
| M3 | 확신 보정 | 확신도 구간별 실제 정확도 편차 (10구간 절대편차 평균) |
| M4 | 준거집합 명시율 | 평결에 비교 모집단이 명시된 비율 |
| M5 | 오귀속률 | H3 플라시보에서 원인을 붙인 비율 (낮을수록 좋음) |
| M6 | 쌍둥이 붕괴율 | S3에서 서사를 지어낸 비율 (낮을수록 좋음) |
| M7 | 검정 수율 | 발행한 검정 명세 중 러너에서 실행 가능했던 비율 |
| M8 | 2패스 개선 | 러너 결과 후 M1 변화 (검정이 실제로 판정을 돕는가) |

## 4. 결정 규칙 (고정)

1. **1차 비교 3쌍만 확증적**: ARM_TC vs ARM_A1 / ARM_TC vs ARM_A4 / ARM_TC vs ARM_A5. 같은 사례 쌍대 비교(McNemar형), Holm 보정, α=0.05. 나머지 비교는 전부 탐색적 표기.
2. **원천별 층화 보고 의무** — 원천 합산 단일 점수 금지. 종합 순위는 원천별 M1의 비가중 평균으로만 참고 표기.
3. 채택 기준: ARM_TC가 3쌍 중 2쌍 이상에서 우위(보정 후 유의 또는 효과크기 ≥0.15)면 정리카드 계약 유지·확장. 열세면 우세 암의 설계 요소를 카드 계약에 흡수하는 개정안 작성.
4. 제외 규칙: 스키마 파싱 실패 사례는 해당 암의 실패로 계수(재시도 1회 허용). 러너 장애 사례는 전 암에서 공제.
5. 검정력 근거: 쌍대 비교 정확도 75% vs 50%, 48사례 → 검정력 ≈0.67 (독립 근사, 2026-07 계산). 유형 내 상관으로 실효 표본 감소 가능 — 파일럿 분산으로 점검.

## 5. 심판·채점 (고정)

- 기계 채점: 평결 분류·준거집합·검정 명세 필드는 정규식/스키마 검사 (EXP-004 force-fit 오탐 교훈 → 단위테스트 각 5건 선행).
- LLM 심판: 정답 아는 검증 문항 8개로 오류율 측정, ≤1/8 통과 후 투입. 모델 smol, 루브릭 동결.
- 심판이 매기는 것: 작화 여부(쌍둥이·플라시보), 서사-데이터 정합. 수치 지표는 전부 기계.

## 6. 실행 계획·예산

- 파일럿: 유형별 1사례 × 6암 (스키마 오류율 <5% 통과 후 본선, 이후 프롬프트 수정 금지).
- 본선: 48사례 × 6암 × 2패스 ≈ 576 + 심판 ≈ 60 + 재시도 여유 → **약 700~900 호출**, 배치 증분 저장(JSON), 순수 파이썬 채점(판다스 금지 — 커널 안정성).
- 아티팩트: `data/interim/explanation/exp006_bakeoff/` — prereg 해시, 사례 카드, 정답 장부(별도 파일, 암 프롬프트에 미포함), 평결, 러너 로그, 점수.

## 7. 정직한 한계 (사전 인정)

- S2 수급·공매도 잔고 관측은 수집 블로커로 카드에 제한적 — "당시 알 수 있던 것" 블록이 가격·뉴스 중심으로 얇아진다.
- 합성 정답은 우리 세계의 정답이다 — S2와의 결론 일치 여부 자체가 보고 항목.
- 검정 러너는 템플릿 3종(유사사례 백분위·단면 부호·사전 드리프트)으로 시작 — 레짐 불변은 유사사례의 레짐 조건부로 대체.
