# EXP-006 결과 — 설명 아키텍처 베이크오프

> 암 6종의 프롬프트 설계와 사례 6유형의 구성 절차·파라미터 정의는 [설계 상세](EXP-006-bakeoff-design.md)가 소유한다.

## 요약 (3줄)

여섯 설명 설계를 정답을 아는 48사례에 붙여 겨뤘다 — 1차 비교 3쌍 모두 통계적으로 갈리지 않았고, 정리카드의 우위 유지 조건은 충족되지 않았다.
가장 큰 발견은 순위가 아니라 구멍 두 개다: 카드 라이브러리에 제도 변화 클래스가 없었고, "시장 전체 충격 vs 종목 고유 요인"을 구분하는 축이 평결 어휘에 없었다.
모든 설계가 아무것도 없는 날에 원인을 지어내지는 않았다(오귀속 0%) — 무너지는 곳은 모순 함정과 실제 역사 사건이었다.

## 발견 5개

1. **오귀속 0%가 전 설계 공통** — 조용한 날에 원인을 지어내는 실패 모드는 구조와 무관하게 이미 통제된다. 정직성의 병목은 플라시보가 아니라 **모순(쌍둥이)과 미지 레짐(시간여행)**.
2. **카드 커버리지 > 아키텍처**: TC의 S2 붕괴(0.125)의 절반은 지식 K에 STRUCTURAL_REGIME 카드가 없어서다. 그래프(A2)와 규칙(A4)은 제도 노드/규칙이 있어 0.5. 같은 지식이라도 **빠진 클래스가 하나 있으면 반증 우선 규율이 "정직한 오답"을 양산**한다.
3. **귀속 레벨 축 부재가 S2 라벨을 오염**: 관세일(시장 −5.6%, 종목 잔차 +0.4%)에 TC의 "시장 공통충격, 종목 고유 무귀속"은 합리적인데 gold가 사건 레벨이라 오답 처리됐다. 평결에는 **시장공통 vs 종목고유 축**이 필요하다 — 이 저장소의 2-leg 분해 계약(시장 leg vs 잔차 leg)과 정확히 같은 구분.
4. **패스2(검정 실행)가 평결을 거의 못 바꿈** (최대 +0.062, TC는 −0.021): 검정 템플릿 3종의 판별력이 부족 — 백분위·드리프트는 대부분 패스1 직감과 일치. 검정이 가치를 내려면 **가설 간 판별 검정**(단면·교차자산)이 필요하다.
5. **프로필 삼각형**: A4 규칙엔진 = 최저 작화(0.083)·최저 커버(0.708) "정직하지만 좁음" / A3 스토리라인 = 최고 커버(1.0)·최악 쌍둥이 붕괴(0.75) "유창하지만 위험" / A1 데이터원리 = 쌍둥이 완벽(0.0 붕괴)·신호 층 최약. 어느 꼭짓점도 단독으론 부족하다.

## 측정 장치 사고 2건 (투명 기록)

- 심판 1차 패스가 전 암 ~100% 작화 판정 → 원인은 심판 입력에 암이 받은 과거 참조·검정 결과를 누락한 것. 입력 수정 후 재패스(보정 세트는 통과했으나 짧은 자립형 문항이라 이 결함을 못 잡음 — 보정 세트 설계 교훈).
- S3 쌍둥이 생성 버그: 잔차 반전을 target 단독 부호 반전으로 구현해 카드·러너 수치 불일치 → `t' = 2m − t`로 수정, S3 전 사례 재생성·재실행.

## 개정안 방향 (다음 단계)

1. 지식 K에 STRUCTURAL_REGIME·MARKET_COMMON_SHOCK 카드 추가 — 커버리지 구멍 봉합.
2. 평결 스키마에 **귀속 레벨**(시장공통/종목고유/혼합) 축 추가 — 2-leg 분해 계약과 정렬.
3. TC 골격 유지 + A2의 구조 노드(제도→레짐 전환)와 A1의 무증거 거부 규율 흡수. 채택 근거: TC의 실패는 전부 "지식 구멍에서의 정직한 거부"였지 작화가 아니었다.
4. 검정 러너에 판별 검정(가설 A vs B를 가르는 관측) 템플릿 추가 후 패스2 재평가.
