# EXP-012 설계 — 시간축 축적: 루프는 정말 복리로 좋아지는가

## 요약 (3줄)

강추론 에이전트의 진짜 주장은 "한 번 잘 맞힌다"가 아니라 "회전이 돌수록 같은 질문에 더 잘 답하게 된다"이다.
이 실험은 그 축적을 네 가지 지표로 계측한다 — 같은 사건 재판정의 능력 델타, 새 조사의 자산 재사용률, 채무 상환률 궤적, 가설의 생사 회전율.
파일럿은 이미 수행됐다(10~11회전): 같은 사건(7/8)에서 트리거 실명·분봉 분해·교차일 지문·신규 가설이 확인됐고, 그 신규 가설은 다음 회전의 판별 검정에서 기각됐다 — 축적과 자기교정이 동시에 측정된 첫 사례다.

## 용어집

| 용어 | 정의 |
|---|---|
| 능력 델타(capability delta) | 동일 사건을 회전 i와 회전 j의 도구로 각각 판정했을 때 산출물의 질 차이 |
| 자산 재사용률 | 새 조사에서 신규 수집 없이 기존 루프 자산으로 충당된 증거의 비율 |
| 채무 상환률 궤적 | 발행된 예측 채무의 누적 PASS/FAIL/VOID 비율 시계열 |
| 가설 회전율 | 회전 중 부상한 가설이 판별 검정으로 채택/기각되기까지 걸린 회전 수 |

## 1. 측정 지표 4종

| # | 지표 | 조작적 정의 | 파일럿 실측 (2026-07-17) |
|---|---|---|---|
| M1 | 능력 델타 | 동일 사건 재판정에서 {트리거 실명, 시간 구조 해상도, 지문 범위, 신규 가설 수}의 전/후 비교표 | T1: 실명 0→1, 일봉 비율→3단계 분봉, 단일→교차 3일, 가설 0→1 |
| M2 | 자산 재사용률 | (기존 자산으로 충당된 증거 항목 수)/(전체 증거 항목 수) per 조사 | T5 조사: 신규 페치 1콜(환율)/증거 5축 = 재사용 ~80% |
| M3 | 채무 상환 궤적 | 원장 스냅숏의 {OUTSTANDING, PASS, FAIL, VOID, PARTIAL} 분포 시계열 | 39건 미결, 채점 이력: PASS 3·FAIL 2·VOID 1·PARTIAL 2 |
| M4 | 가설 회전율 | 가설 부상 회전 → 판별 검정 회전 → 판정까지의 회전 수 | 종가 리밸런싱 가설: 10회전 부상 → 11회전 기각 = **1회전** |
| M5 | 무결성 불변 | 전 회전 작화율 (입력 매칭 감사) — 축적이 무결성을 침식하지 않는가 | 11회전 누적 0 |

## 2. 프로토콜

1. **재판정 표본**: 분기마다 과거 사건 2건을 당시 판정 시점의 도구 스냅숏과 현재 도구로 이중 판정 — M1 산출. 사건 선정은 게이트 로그에서 기계적으로(체리피킹 방지).
2. **자산 회계**: 조사마다 증거 항목에 {신규 수집, 기존 자산} 태그 의무 — M2 자동 집계.
3. **원장 스냅숏**: 매 회전 종료 시 `debt_ledger.json` 분포를 `loop_state`에 적재 — M3.
4. **가설 등기**: 평결에서 부상한 신규 가설은 발행 회전 번호를 달고, 판별 검정 실행 회전에서 채택/기각 기록 — M4.
5. **판정 규칙**: 4분기 연속 M1 델타가 0에 수렴하고 M2가 정체하면 "축적 포화" 선언 → 아키텍처 개편 검토. M5가 0에서 이탈하면 전 회전 중단·감사.

## 3. 파일럿이 이미 보여준 것 (10~11회전)

- **축적**: T1 재판정 델타 표 (검증 보고서 §6.9) — 같은 질문에 시스템이 측정 가능하게 더 잘 답했다.
- **자기교정**: 축적이 만든 신규 가설(종가 리밸런싱 증폭)이 **1회전 만에 자기 판별 검정으로 기각** — 종가창은 증폭이 아니라 미세 반전(단면 corr −0.15~−0.26), 오후 청산 지문의 운반체는 미확인으로 재분류. 축적이 확증 편향으로 흐르지 않고 반증을 생산한다는 직접 증거.
- **이중 배당**: 하나의 데이터 투자(분봉)가 두 사건(T1·T5)의 판정을 동시에 정밀화.
