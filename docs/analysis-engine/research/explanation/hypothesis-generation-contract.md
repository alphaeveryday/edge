# 가설 생성 계약 — 충분데이터 카드와 Claim Tree 형식

## 세 줄 요약

- 주가가 왜 움직였는지 설명하는 AI에게 지금은 당일 뉴스 제목만 주고 있어서, 그 뉴스가 재탕인지·시장이 이미 알던 것인지 모른 채 추측한다.
- 이 문서는 AI에게 반드시 함께 줘야 하는 정보 묶음 10종과, AI가 내놓는 가설의 표준 형식을 정한다.
- 실험 확인: 정보를 채워 주면 바로 검증 가능한 가설 비율이 11%에서 44%로 오르고, 가설 생성과 분해는 한 번의 모델 호출로 충분하다.

## 용어집

| 용어 | 뜻 | 코드/원어 |
|---|---|---|
| 충분데이터 카드 | 가설 생성 AI에게 주입하는 입력 정보 묶음 (블록 번호 D0~D9) | D-card |
| 잔차 | 시장·동종업계 움직임을 뺀 그 종목 고유의 수익률 | residual |
| 스레드 | 같은 실제 사건을 다룬 기사·공시들의 시간순 계보 | thread (D2) |
| 신규성 | 오늘 기사가 계보에서 처음인지, 후속인지, 재탕인지의 판정 | novelty |
| 재탕 | 새 사실이 없는 기존 내용의 재보도 | REBROADCAST |
| 기대 상태 | 발표 전 시장이 이미 반영한 예상 — 컨센서스, 사전 주가 흐름 | expectation (D3) |
| 반영도 | 공개된 정보 중 이미 주가에 지불된 몫, 0~1 | paid_share |
| 클레임 트리 | 추상 가설 문장 하나 + 그것을 검증하는 구체 하위 명제들 | Claim Tree |
| 잎새 명제 | 클레임 트리의 최하위 검증 단위 — 검정 방법과 기각 조건 포함 | leaf |
| 크기 사다리 | 사건의 경제 크기를 단계별로 계산해 주가 함의치로 바꾸는 추정 | magnitude ladder |
| 즉시 검증가능 | 잎새 명제가 현재 보유 데이터로 바로 검정 가능한 상태 | VERIFIABLE_NOW |

## Summary

- 목적을 **가격 변동의 token 인과추론**으로 한정하면, 가설 생성기의 품질은 모델 크기가 아니라 **입력 데이터가 어떤 식별 지렛대를 열어주는가**로 결정된다.
- 현재 구현(`src/alphamale/events/etf/view_loop.py`)이 LLM에 주는 것은 `날짜·시장/ETF 수익률·잔차·종목별 뷰·당일 EVENT 뉴스 제목`뿐이다. 실측된 두 결함: **신규성 실명**(당일 뉴스가 재탕인지 모름), **기대 실명**(시장이 무엇을 이미 기대했는지 모름).
- 이 문서는 ① 가설 생성기 입력의 충분데이터 카드 D0~D9, ② 가설 출력 형식(Claim Tree: 추상-반증가능 루트 + 검증가능 leaf 분해), ③ 생성/분해의 아키텍처 선택(단일 강모델 vs 분리 에이전트)의 사전등록 실험을 고정한다.
- 실험 결과는 [EXP-001](experiments/EXP-001-hypothesis-bench-pilot.md)이 소유한다.

## Context

검증·언어 계약은 [정당화 표준](../../engineering/design/explanation-justification-standard.md)(S0~S8, N1~N7)이, 가설 어휘는 [메커니즘 탐색공간](mechanism-search-space.md)이 소유한다. 이 문서는 **가설 생성 단계의 입력 계약과 출력 형식**만 소유한다. 원칙: 생성은 자유, 인증은 게이트 — 단 생성기가 식별 불가능한 가설만 내놓으면 게이트가 아무리 엄격해도 산출물이 없다. 그래서 입력 계약이 병목이다.

## 1. 인과 프레임 — 생성기가 답해야 하는 질문의 형식

추정 대상(estimand)은 "자산 $A$의 창 $W$ 비정상수익률 중 원인 $E$에 귀속 가능한 몫 $\delta_E$"다. 단일 관측의 미결정성을 깨는 지렛대는 관측 차원 확장뿐이다(정당화 표준 §1). 따라서 **식별력 있는 가설 = 지렛대별 예측을 내장한 가설**:

| 지렛대 | 가설이 내장해야 하는 예측 | 필요한 입력 데이터 |
|---|---|---|
| 타이밍 | 반응이 $t_0$(available_at) 직후 집중, 이전 무드리프트 | D1 정밀 시각, D2 스레드 |
| 크기 정합 | 사건의 경제적 크기 → 함의 시총 변화가 관측 무브와 자릿수 일치 | D3 기대, D5 노출도 |
| 단면 | 노출도 순서대로 반응 크기 정렬 | D5 노출도/그래프 |
| 교차자산 | 채널이 예측하는 금리·환율·업종 동행 부호 | D6 타임라인·교차자산 |
| 경쟁 배제 | 동시 사건들이 예측 못 하는 지문 존재 | D6 타임라인 |
| 반복 표본 | 같은 유형의 과거 반응 분포 안에 위치 | D7 analogs |

## 2. 현재 계약의 실측과 두 결함

`render_day_body()` 입력: 날짜, 시장/ETF 수익률, ETF 잔차, 종목별 잔차, 아침 시점 뷰, 당일 EVENT 뉴스 **제목**(`_dedupe_titles`, 최대 30건, 시각 없음). 결과:

- **결함 1 — 신규성 실명**: 같은 내용이 3주 전 first_in_thread였어도 오늘 제목만 보면 신규로 보인다. `available_at_session=PRE_OPEN` 같은 뭉개진 신호만으로는 "장전 재탕 해설 기사"와 "장전 신규 공시"를 구분 못 한다. 온톨로지에 `novelty_status`(FIRST_OBSERVED/FOLLOW_UP/REBROADCAST/CORRECTION)가 이미 정의돼 있으나(`feature_specs_v0_1.yaml`) 프롬프트에 주입되지 않는다.
- **결함 2 — 기대 실명**: 컨센서스·사전 드리프트·포지셔닝을 모르면 "영업이익 -92%인데 왜 오르나"를 설명할 수 없다. 절대적으로 중요한 사건도 시장은 **기대 대비**로만 평가한다. 언론 합의는 편향·오보 가능성이 있으므로 단일 소스 금지 — 시장내재 기대(가격 경로·파생)와 병렬 제공해야 한다.

## 3. 충분데이터 카드 D0~D9

가설 생성기 입력의 표준 계약. 각 블록은 여는 지렛대와 막는 실패를 명시한다. **D8(부정 정보)이 없는 카드에서 생성된 가설은 인증 자격이 없다.**

| # | 블록 | 핵심 필드 | 여는 지렛대 / 막는 실패 | 소스 상태 |
|---|---|---|---|---|
| D0 | 관측 명세 | AR±CI, 시장/피어 leg, 잔차, 경로 형태(§6.2), 창 분해(전일종가→시가→사건전→사건후→종가) | 설명 대상의 오인 방지 — "잔차 0이면 설명할 것 없음" | 보유 (P0~P4) |
| D1 | 당일 이벤트 | `available_at`(초 단위)+세션, source_class, event_type, assertions(계약금액 등), 원문 발췌 | 타이밍 / PRE_OPEN 뭉개짐 | 보유 (canonical_event) |
| D2 | 스레드 역사 | thread lineage(stage 전이), first_available_at, `novelty_status`, days_since_prev, **동일 스레드 과거 가격 반응** | 신규성 — 결함 1 직격 | 계약 존재, 주입 누락 |
| D3 | 기대 상태 | 컨센서스±분산(있으면), 시장내재 기대(사전 드리프트, probability_path), 애널 목표가 궤적, 밸류에이션 분위, **소스별 분리 표기**(언론 vs 시장내재) | 크기 정합 — 결함 2 직격. surprise = actual − expectation | 부분 (expectation_state), 컨센서스 defer |
| D4 | 상태 원장 스냅샷 | 공매도·대차·신용 잔고 분위(T+2 lag 명시), 투자자별 수급, 프로그램, 시장조치 | 미시기반·L3 자격 | 무료 확보 계획 (§6.6) |
| D5 | 노출도 렌즈 | 밸류체인 그래프(고객/공급/경쟁), 매출 노출도, 관계 강도 | 단면·크기 사다리 재료 | 부분 (graph draft) |
| D6 | 동시 타임라인 | 창 내 전 사건(합성 이벤트 포함), **야간 글로벌 앵커**(미 지수·SOX·환율·야간선물), 섹터 공통 뉴스 | 경쟁 배제 / 파생 기사를 원인으로 오인 방지 | 부분 |
| D7 | 유사사례 분포 | 같은 (event_type × stage × novelty) 조건부 과거 AR 분포, n, 이번 사례의 분위 | 반복 표본 / 외삽 방지 | 설계 (response_prior) |
| D8 | 커버리지 지도 | **이 카드에 없는 데이터 목록**(옵션·틱·주문호가 등), 각 미보유가 막는 판정 | 정직한 UNKNOWN·data_request 생성 | 신규 (즉시 구현 가능) |
| D9 | 사전등록 앵커 | 허용 창 집합, 정상수익률 모형 후보, 검정 수식, 다중비교 정책, 채택/기각/UNKNOWN 규칙, 민감도 범위 — **결과를 보기 전 고정** | 선택 편향 차단 (S0·S6) | 정책 파일로 신규 |

### 3.1 D1·D2 세부 규칙 — 게이트 클래스와 재탕의 두 얼굴

**비이벤트 기사는 D1에 들어오지 않는다.** doc_class 게이트(`EVENT` / `OPINION_OR_ANALYSIS` / `NO_EVENT_MARKET_COMMENTARY` / `PROMOTIONAL_OR_SOLICITATION`)가 시황 해설("[특징주] X 강세", "소문에 사서 뉴스에")을 D1 이벤트 후보에서 구조적으로 배제한다 — 이들은 사건이 아니라 **가격 움직임에 대한 사후 서술**이므로, 원인 후보로 쓰면 순환 설명이 된다. 단 폐기하지 않는다: **D3의 언론 서사 코퍼스로 라우팅**해 "시장이 이 무브를 어떻게 소비하는가"의 측정 재료로 쓴다(편향 플래그 부착, 시장내재 기대와 병렬 — 단독 소스 금지). 게이트는 동결 모델이므로 오분류 누출(현행 정확도 ~91%)이 존재한다 — 생성기는 D1 항목에도 서술형 제목 회의를 유지해야 한다.

**INFO 자격은 태그가 아니라 측정이 정한다 — 태그는 사전확률과 요구 증거만 바꾼다.** "공개됨(available)"과 "반영됨(priced)"은 다른 축이다: 이미 공개된 정보가 늦게 반영되는 경우는 명명된 반복 현상이다(PEAD 드리프트, 재보도 재가격 — Huberman-Regev의 EntreMed, Tetlock의 stale news, 고객-공급사 링크 지연 — Cohen-Frazzini). 따라서 novelty 태그로 반영 여부를 **판정**하면 안 되고, 반영 여부는 에피소드마다 **측정**한다. 스레드의 목적은 기사 격하가 아니라 **계보 묶기**다: 오늘 기사를 스레드 누적 상태와 대조해 `{이미 확립된 부분, 새로 추가된 부분, 이미 지불된 부분}`으로 분해할 수 있게 하는 것.

0. **반영도(paid_share)는 측정량이다**: `paid_share ≈ 스레드 개시 후 누적 사전 잔차 / 크기 사다리 함의치` (CI 부착, 스레드×자산 단위, FUNCTION). L2의 PRICED_IN/PARTIAL/NEW는 기사 속성이 아니라 **이 측정의 구간 라벨**이다. 추정기 사다리(PS0 사후 정규화 / PS1 analog 분모 / PS2 크기 사다리 / PS3 확률경로 직독)와 노이즈 플로어·데이터 요구는 [EXP-002](experiments/EXP-002-paid-share-estimator.md) 소유 — 핵심 결과: **분봉 stage 창 없이는 전형 크기(5~10%p)에서 추정 불능**, CI가 구간에 걸치면 라벨 발행 대신 PARKED.
1. **assertion delta = ∅ (완전 중복 = REBROADCAST)** → INFO 재가격 가설의 **사전확률이 낮아질 뿐, 가치 0 단정 금지**. 채택 요건이 늘어난다: (a) 미반영 잔량 존재(`paid_share < 1`, 측정), (b) **"왜 지금" 채널** — 재유통 도달 확대·주목 급증(검색량·커뮤니티)·강제 수급 중 하나의 증거. 이것이 재보도 재가격(Huberman-Regev형)의 정식 경로다.
2. **assertion delta ≠ ∅ (FOLLOW_UP with 신규 필드)** → 트리거는 delta다: 단계 진전·수치 확정·신규 상대방이 후보이고, surprise 기준선은 무지(0)가 아니라 **스레드 확립 상태 + 이미 지불된 반응(D2)** 대비로 측정한다.
3. **CORRECTION** → REVERSAL 트리거 후보.
4. **사후 판별 — 지연 반영 vs 주목 과잉반응**: 둘 다 "옛 정보 + 오늘 반응"이지만 예측이 갈린다. 진짜 미반영 가치의 편입은 **지속**하고(Huberman-Regev), 개인 주목 과잉반응은 **반전 경향**이다(Tetlock 2011). resolution 슬롯의 후속 반전 측정이 ex-post 판별기다.
5. **규칙의 단순성**: 어떤 가설이 "오늘 무브 = 정보 X의 재가격"을 주장하면 **X의 나이와 무관하게 같은 게이트**를 통과한다 — ①미반영 잔량(paid_share) ②why-now 채널 ③타이밍 정합. 태그가 바꾸는 것은 사전확률과 요구 증거의 양뿐, 분기 로직이 아니다.

## 4. 가설 출력 형식 — Claim Tree

사용자 통찰의 형식화: 가설은 **추상적이되 반증가능한 루트 문장** 하나와, 그것이 함의하는 **구체적·독립검증가능한 leaf**들로 쓴다. 추상 루트가 서사적 유연성을 주고, leaf가 검증 표면을 준다 — 루트는 leaf들의 논리곱보다 강할 수 없다.

### 4.1 루트 문장 문법

```text
[사건/상태변화 E]가 [채널 C: CF|DR|RP|NF]를 통해
[자산 A]의 [창 W] 수익률을 [부호·크기밴드 Δ]만큼 움직였다.
기각 조건: [관측되면 이 가설이 죽는 사실 1~3개]
```

크기밴드는 점추정이 아니라 자릿수 구간(예: "+3%~+9%p 잔차")이다. 채널 명시가 필수인 이유: 채널이 없으면 leaf의 지문 예측(금리 동행, 단면 정렬)이 도출되지 않는다.

### 4.2 의무 분해 축 5개

| 축 | leaf가 검증하는 것 | 예시 검정 |
|---|---|---|
| ① 사실성·신규성 | E가 실제로 새 정보였나 | thread에서 first_available_at 확인, novelty_status=FIRST |
| ② 크기 사다리 | E의 경제 크기 → 함의 시총Δ가 관측과 자릿수 일치하나 | 물리량→매출→이익→NPV→시총% Fermi 체인 |
| ③ 타이밍 | 반응이 available_at 직후 집중이고 사전 드리프트 없나 | 창 분해 AR, pre-drift 검정 |
| ④ 지문 (단면·교차자산) | 채널 예측대로 노출도 정렬·동행 부호가 나왔나 | 노출도 상하위 반응차, 금리/환율 부호 |
| ⑤ 경쟁 배제 | 동시 사건·시장/피어 leg가 대신 설명하지 못하나 | confounder 목록 대조, 잔차 기준 재확인 |

### 4.3 leaf 형식

```json
{
  "claim": "마이크로쏘 국산화의 연간 이익 기여는 시총의 1% 미만이다",
  "required_data": ["장비 ASP·연간 수요 대수", "원가 구조", "경쟁사 점유율"],
  "test": "fermi_magnitude(D5.exposure, D3.valuation) → implied_cap_delta_pct",
  "refutes_if": "implied_cap_delta ≥ 관측 잔차의 50%",
  "status": "VERIFIABLE_NOW | NEEDS_DATA | JUDGMENT"
}
```

`status=NEEDS_DATA`인 leaf는 data_request로 배출된다. `JUDGMENT` leaf(예: "이 기술이 대체 불가능한가")는 존재를 허용하되 **루트 등급 상한을 낮춘다** — 판단 leaf에 기대는 가설은 mechanism_compatible을 넘을 수 없다.

### 4.4 예시 — 한미반도체 마이크로쏘 (사용자 예시의 재작성)

원문 가설 "마이크로쏘 국산화가 단기적으로 주가를 상승시켰다"의 Claim Tree:

```text
ROOT: 마이크로쏘 국산화 공시(E, 2024-XX-XX 09:12 first_available)가
      CF 채널(수입 대체 마진 + HBM 밸류체인 지위 강화)을 통해
      한미반도체의 [공시, +2일] 잔차를 +3~+9%p 움직였다.
기각: ①공시가 스레드 재탕 ②함의 시총Δ < 관측의 절반 ③반응이 공시 전 시작

leaf1 [신규성]  이 공시는 thread 최초 관측이다 — thread 조회 (VERIFIABLE_NOW)
leaf2 [크기]    국산화 연간 이익 기여 NPV ≥ 시총 2% — ASP×대수×마진 Fermi (NEEDS_DATA: ASP)
leaf3 [크기]    "얼마나 중요한 장비인가" = 대체 시 라인 정지 비용 — 공정 자료 (JUDGMENT → 상한 강등)
leaf4 [타이밍]  09:12 이후 30분에 반응의 70%+ 집중, 전일까지 무드리프트 (VERIFIABLE_NOW)
leaf5 [지문]    수혜 사슬(고객사·경쟁 국산화 실패사) 부호 정렬 (VERIFIABLE_NOW, D5 필요)
leaf6 [배제]    동일 창 SK하이닉스 CAPEX 발언이 잔차를 설명 못 함 — 피어 leg 대조 (VERIFIABLE_NOW)
```

원문과의 차이: "어떤 장비인지·얼마나 중요한지"가 JUDGMENT leaf로 격리되고, 검증 노동의 대부분이 함수 실행 가능한 leaf로 이전된다.

## 5. 아키텍처 질문 — 단일 강모델 vs 분리 에이전트

생성(루트)과 분해(leaf)를 한 호출로 할지, 역할 분리할지는 선험적으로 정할 수 없다 — 사전등록 실험으로 판정한다.

- **H-D1 (충분데이터)**: D2·D3·D6 주입은 함정 회피율(신규성·기대·파생기사 함정)을 유의하게 올린다. 판정: C_full − C_min ≥ +2/6 사례.
- **H-D2**: D 주입은 leaf의 식별 지렛대 사용 수를 올린다.
- **H-A1 (아키텍처)**: 분해 분리는 leaf 검증가능성을 올리지만, 이득이 작으면(Δ<0.15) 단일 호출이 효율 우위. 강모델 루트 + 약모델 분해의 열화 폭도 측정.

설계·수치·판정은 [EXP-001](experiments/EXP-001-hypothesis-bench-pilot.md) 소유. **판정 결과 (2026-07-14)**: H-D2 강한 지지(VERIFIABLE_NOW 0.11→0.44), H-D1 방향 지지(누출 없는 함정에서 예측된 실패), H-A1 기각 — **생성+분해는 단일 강모델 1콜 + 스키마 강제**로 확정. 약모델 분해는 품질 동급이나 장황·인식 열화로 비채택.
