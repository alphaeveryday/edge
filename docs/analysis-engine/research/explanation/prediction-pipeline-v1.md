# 예측 파이프라인 v1 - 전체 구조

> 목표 정의(`loop_state.json objective.canonical_goal`): 새 이벤트 -> "어떤 자산에 얼마만큼"의 예측 시스템. 설명은 예측+피드백 원장의 출력 포맷. 추론 규칙은 추론 계약 v3(+A1~A4)을 따른다.

## 불변식 3

1. **결과 방화벽**: 실측 idio(부호·크기)는 L5 채점에서만 보인다. L3 추론 입력에서 차단 (A1 블라인드).
2. **단일 코어, 두 입구**: 전향(진예측/실황)과 회고(그림자)가 L3 추론 코드를 공유한다. 그림자 보정의 이전 가능성이 이 공유에서 나온다.
3. **메타는 평면 밖**: L6은 개별 판정에 개입하지 않는다. 수집 투자 라우팅과 프레임·클래스 갱신만 한다.

## 층 구조

| 층 | 역할 | 구현 |
|---|---|---|
| L0 수집 | PIT 이중 박제(pub_time+fetched_at). 실시간: 1분 폴러+조건부GET/AIMD+센티널(DART 422B·KIND 1KB)+트리거체인. 회고: KIND 17만·Daum·GDELT·korea.kr 백필 | `ops/collect/*` 완성 |
| L1 사건 구조화 | 스레드 dedup -> first-in-thread, 소스 레지스트리(ORIGIN/CARRIER/ECHO), L0 정규식 에코 필터, 자산 링킹 -> 사건 객체(market_first_available_at) | 완성. 본문 수집기는 병목 실측 후 |
| L2 분모 | ex-ante 팩터 회계(v4.5) -> idio, 5분봉 온셋, 프리게이트 H_meas(거래정지·CA)·H_model(그룹 동시발화 탐지=신규 소형) | 완성 |
| L3 추론 코어 | **3상 구조 (계약 v3 §7)**: ①조사(agentic, 예산 계층, 방화벽 τ - 화이트리스트 도구로 질의·수집·계산·새 가설, 연구노트 자유 기록) ②등기(노트 -> 구조화 청구: 복합가설·판별 배터리·크기 구간·선언 테스트·검정력 주석, 검사기 통과) ③판정(코드 - 방화벽 해제, 선언 테스트만 실행, 제거/기권/풀검사/판별실험). 방화벽: τ 이후 시세 전 자산 차단 + 회수 문서 pub_time<=τ + 디코이 유지 | **이번 빌드 본체** (카드 v2 -> 3상 재작성) |
| L4 예측 원장 | 카드 발행: 등급 라벨(진예측=발행 해시 봉인 / 실황 / 그림자), 채점 만기, 채무 원장 연동 | 필드 추가 |
| L5 채점·피드백 | 만기 도래 시 실측 idio 대조 -> PASS/UNDER/OVER -> 오차 원장 -> 프라이어 갱신. 보정 곡선, 디코이 오탐률 계기판 | 채점기 있음, 계기판 신규 |
| L6 메타 회계 | 병목 히스토그램(사전등록 밴드 대조) -> 로드맵 라우팅, 상시 frame_check(기권+H_out 군집), switch_conditions 감시, next_data EIG 랭킹. loop_state+Jira | 집계 잡 신규 |

## 운영 사이클

- **장전 (07:00~09:00 KST)**: 야간·장전 이벤트 -> 진예측 카드 발행(개장 전 봉인). 역사 분포상 셀 57%(갭11+개장발화46)가 이 구간 정보 - 구조적 스위트스팟.
- **장중**: 센티널 트리거 -> 실황 카드 (반응 진행 중 발행임을 라벨로 구분).
- **장후 (18:40 KIND + EOD)**: 실측 확정 -> 만기 카드 채점 -> 원장 갱신 + 당일 셀 그림자 카드 생성.
- **주간 메타 패스**: 병목 히스토그램, frame_check, EIG 재랭킹, switch 감시.

## 빌드 순서

1. Daum 전수 수확 완료 -> **v3 그림자 전수 패스** (블라인드+디코이 ~10% 혼입): 보정 기준선 + 병목 히스토그램 첫 실측 + 기존 파일럿 지표(93%) 블라인드 재측정 교체
2. 병목 히스토그램 -> 다음 수집 투자 결정 (bottleneck_prereg 의 decision_rules 적용)
3. 노출 매핑 모듈화 (직접·그룹·테마 전이 규칙)
4. **실시간 예측 발행기**: L0 스트림에 L1->L3->L4 결선 - 장전 패스 가동 (진예측 모드 개시)
5. 8/27 BOK 사전등록 = 첫 공식 진예측 채점 (봉인 완료 상태)

## 미결 (구조에 반영된 한계)

- 리포트 시각·지표 서프라이즈 값: 유료 - L1에서 영구 UNTIMED/UNKNOWN 등급으로 정직 처리
- 다중 사건 중첩 배분: causal 병목 버킷으로 집계 후 규칙 설계 (히스토그램이 우선순위 결정)
- 상폐 종목 생존 편향: 회고 유니버스 확장 백로그
