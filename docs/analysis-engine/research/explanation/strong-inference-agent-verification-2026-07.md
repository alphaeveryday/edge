# 강추론 에이전트 검증 1차 — 벤치 4종, 2026년 7월 실전 3건, 재귀개선 1회전

## 요약 (3줄)

강추론 에이전트 프로그램의 실험 4종을 파일럿 규모로 실행해 전 계약을 통과시켰고, 이어서 에이전트에게 2026년 7월 실제 한국 시장의 급변 3건을 데이터만 주고 설명하게 했다.
에이전트는 스스로 가설을 세우고 계산을 요청해, 뉴스 없이도 실제 사건의 구조(개인 투매형 장중 하락, 거래재개 기준가 재설정, 상한가 포화의 산술)를 맞혔으며, 발행한 예측 약속을 평결 이후 도착한 실데이터(7/13 폭락 포함)로 채점해 스스로 개정했다.
부족한 점 여덟 가지를 등록부로 만들었고, 그중 하나(종목 이름 데이터 부재)를 즉시 수리해 재판정까지 마쳤다 — 재귀개선 루프의 1회전이 완료된 상태다.

## 용어집

| 용어 | 정의 |
|---|---|
| 파일럿 규모(p) | 프로그램 문서가 정한 본 설계보다 사례 수를 줄인 실행. 계약 판정은 유지 |
| 관측팩 | 에이전트에게 주는 출발 데이터 묶음 (가격·거래량·달력·단면 요약) |
| 채무 채점 | 평결이 발행한 예측 약속을 이후 실데이터로 맞음/틀림 판정하는 것 |
| VOID | 약속의 전제가 깨져 맞음/틀림 판정 자체가 무효인 상태. 전제를 명시해 재발행 |
| 구조 지문 vs 국면 약속 | "어떤 축이 시장을 지배하나"(구조)와 "다음에 어느 방향인가"(국면)의 분리 |
| 접지율(grounded share) | 평결의 사실 주장 중 제공된 데이터에 실재하는 비율 |

에이전트다운 행동의 증거: 자기 가설 11개 중 7개를 스스로 기각(반증 우선), 데이터 품질 가설(수정주가 오류)을 경쟁 가설로 자발 포함, 이름을 받은 뒤에도 "명칭 연결이 실제 테마로 작동했는지는 현 데이터로 판정 불가"로 선을 그음.

### 3.2 v2 개정 (에이전트 자가 수행)

- 구조 지문과 국면 약속을 분리해 각각 재판정 — FAIL과 VOID를 구별하고, **전제(premise) 필드를 단 채무를 재발행**.
- T2는 자기 과대해석("d0+1~2 대량거래를 지속 레짐의 증거로 봄")을 명시 철회.
- T2가 데이터만으로 기준가 재설정 퍼즐(5,110→9,030이 제한폭 초과)을 지적 — 실제 제도(재개일 기준가 재설정)와 일치.

### 3.3 개선 실행 1건

결함 D1(이름 부재)을 `data/raw/reference/krx_listed_info_20260710.json`(2,758종목) 주입으로 수리 → 재판정에서 금호 계열 명칭 연결과 건설 우선주 군집을 인지하되 과잉 서사 없이 검증 조건을 재설계함.

## 6. 루프 프로토콜 v1 (이후 회전 규칙)

1. **트리거**: 게이트 플래그(z≥2.0) → 관측팩 생성 → 다회전 자율 조사 → v1 평결 + 채무 발행 (전제 필드 의무).
2. **채점**: D+2~5 실데이터로 채무 기계 채점. 전제 깨짐 = VOID(재발행), 전제 유지 = PASS/FAIL.
3. **개정**: v2에서 구조 지문/국면 약속 분리 재판정. v1 불변(append-only), 성적 집계는 v1 기준.
4. **개선**: 회전마다 결함 등록부 상위 1건 수리 → 수리 효과를 다음 회전에서 실측.
5. **감사**: 매 회전 매칭-입력 작화 감사 + 접지율. 0 이탈 시 경보.

## 6.1 루프 2회전 결과 (2026-07-17, 같은 날 실행)

**D2 수리 → 트리거 실명 성공.** DART corp_code 매핑 + 공시 목록 + 뉴스 RSS 커넥터(`ops/collect/news_probe.py`)를 가동해 T2를 3차 판정했다. 결과: 트리거가 실명됐다 — **감자결정 공시(6/22 정정)에 따른 거래정지·기준가 재설정 후 재개일 상한가**. v2의 "장기 무거래 해소" 지문과 정합함을 스스로 검사했고, 등급을 "매우 가능성 높음"으로 정당 상향했으며, 언론 서사("전장 시장 확장")를 공시(사실)와 구분해 약한 증거로 격리했다. 트리거 실명: 0/3 → 재시도 1/1.

**D8 — 제안 수리안이 데이터에 기각됨.** EWMA σ 게이트를 실측한 결과 오히려 악화(7/2 z −1.92로 미포착: 6월 폭락이 σ를 더 빨리 부풀림). 연쇄 폭락 국면에서 z-게이트가 실명하는 진짜 원인은 σ 팽창 자체다. 채택안: **절대 플로어(|시장|≥3%) OR 폭(breadth) 트리거** — 7월 극단일 5/5 포착. 수리 가설도 반증 대상이라는 루프 원칙의 실증.

**D4 수리 → T3 방향 분기 확정.** 채점팩에 가격 경로를 추가하자 T3의 미결 질문이 닫혔다: 삼호개발은 d0 종가 대비 최대 +5.3% 후 **−20.1%(7/16)까지 반납** — 거래량 지속(PASS)과 가격 방향은 분리되며, 실체는 흡수·연장이 아니라 **대량거래 속 분배·평균회귀**였다. v2가 이 분리를 미리 선언했던 것이 정당화됐다.

**루프 상태의 기계화.** 회전 이력·결함 등록부·다음 행동을 `strong_agent_loop/loop_state.json`으로 물화 — 등록부 현황: FIXED 3(D3·D4·D8-대안), PARTIAL 2(D1·D2), BLOCKED 1(D5), MITIGATED 1(D6), OPEN 1(D7). 다음 회전 트리거: 재발행 채무 만기(≈7/24) 또는 게이트 플래그.

## 6.2 루프 3회전 결과 (2026-07-17)

**D2 완결 → T2 판정 반전 (이 검증의 백미).** DART 원문 파서(`dart_doc_parse.py`)가 감자결정 원문에서 **감자비율 50%·매매정지 6/8**을 추출하자, 에이전트가 산술을 명시하며 4차 판정을 뒤집었다(사실상 확실): 이론 기준가 5,110×2=10,220원 대비 재개 종가 9,030원 = **경제 수익률 −11.6%**. 게이트가 "+76.7% 폭등"으로 본 것은 감자 미조정 원시가격의 착시였고, 시장은 재개일에 이 종목을 감자 전보다 낮게 평가했다. v1에서 후보였던 "기계적 불연속" 가설(H3)이 최종 정답 축 — 자기 가설 목록의 가치 실증.

## 6.25 루프 26회전 결과 (2026-07-18) — 0.8 돌파와 지표 포화의 동시 실증

| 규칙 | 셀 | 원 R² | 조정 R² | 플라시보(원/조정) | 정보 초과(원/조정) |
|---|---|---|---|---|---|
| v4.5 (뉴스 없음) | — | 0.731 | 0.548 | — | — |
