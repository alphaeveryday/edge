# v2 최종 가격변동 설명의 근거 조회

일반 관리자 콘솔의 기존 ‘근거 데이터’ 표에 연결하기 위한 서버 내부 조회 계약이다. 최종 선택한 설명의 근거만 반환하며, 탐색 중 읽은 자료를 최종 근거로 섞지 않는다. 이번 변경은 DB 조회까지다. 금융사 전달 번들·API·UI 연결은 후속 PR이다.

## 실행 시점

- 가격변동 설명: 기존 가격 트리거마다 자동 실행. 해당 트리거 시점과 가격 사용.
- 전망: 매일 08:00 `Asia/Seoul`에 배치 시작. 모든 ETF의 완료 시각을 뜻하지 않음.
- 전망의 정보 기준시점: 당일 08:00. 대기·재시도로 미래 자료를 포함하지 않음.
- 이 실행 자동화는 계획이며, 이 조회 PR에서 Scheduler·소비자를 배포하지 않음.

## 조회

`read_published_movement_evidence(connection, analysis_id)`

| 반환 필드 | 내용 |
|---|---|
| `analysis` | 조회한 발행 분석 행. SQL 날짜·시각만 ISO 문자열로 변환 |
| `items` | `selected_item_ids` 순서의 항목. `item_id`, `tool_run_ids` |
| `tool_runs` | 항목이 참조한 실행만 중복 제거. 인자·저장 출력·컨텍스트와 당시 툴 정의 포함 |

- 읽기 전용 repeatable-read 트랜잭션. 호출자는 idle autocommit 연결 전달.
- 분석이 없으면 `None`. 실행 중·실패·미발행이면 오류.
- 같은 날 이전 분석에서 재사용한 항목과 툴 실행 포함.
- 선택 항목 또는 근거가 없거나, 다른 ETF·데이터 출처·미래 분석에 연결되면 오류. 부분 결과 반환 금지.
- 최종 근거 사용 자격은 발행 시 `PublicationStore`에서 검사. 조회 시 새 툴 목록으로 과거 근거를 재판정하지 않음.
- 툴 출력 재계산·반올림·뉴스 본문 추가 없음. 기존 전체 실행 감사 조회는 유지.

## 기존 관리자 표에 연결할 때

| 유형 | 내용 | 출처 | 시각 | 펼침 |
|---|---|---|---|---|
| 뉴스 | 기사 제목·원문 링크 | 저장된 공급자 | 발표시각 | 뉴스 ID |
| 수치 계산 | 계산명·결과 | 데이터명 | 관측 기준시각 | 인자·저장 출력·LaTeX 수식·관리자용 설명·실행 ID |

- ‘N개 출처’ → ‘N개 근거’. 기존 심사 정책의 출처 수 계산은 변경하지 않음.
- 뉴스는 뉴스 ID로 식별. 없는 출처·시각·URL은 생성하지 않음.
- 툴 실행시각을 관측 기준시각으로 대체하지 않음.
- 기존 번들은 뉴스·공시만 허용하므로 수신 계약·UI 배포 후 v2 전송 활성화.
- 조회 반환은 내부 자료이며 에이전트 응답·앱 응답·번들 와이어 형식을 변경하지 않음.

## 검증

- 미선택 항목·탐색용 실행 제외, 선택 순서 유지.
- 이전 분석의 근거 포함, 공유 근거 중복 제거.
- 참조 누락·잘못된 연결·미발행 분석은 오류.
- 저장한 인자·출력·수식·출처와 조회값 일치.
- 전용 로컬 PostgreSQL 사용. 운영 DB·AWS 자원 변경 없음.
