## 화면 결정

기존 Orca UI 조작부와 레이아웃을 재사용한다. 일괄 입력은 계좌별 접힌 영역이며 정확한 코드 또는 이름과 현재 입력 단위의 숫자를 한 줄씩 받는다. 오류가 한 줄이라도 있으면 일부만 추가하지 않는다. 저장된 포트폴리오 재사용은 확인 뒤 입력을 교체하며, 확인되지 않은 평가금액은 빈칸으로 남긴다.

필수 단계는 유지하고 투자 기간 이후 선택 질문을 건너뛸 수 있다. 실패 화면은 동일 입력 재시도가 주 행동, 수정이 보조 행동이다. 저장 이동에서 수량·평단이 없는 첫 종목만 열고, 이후 종목은 기존 강조 표시로 안내한다.

## 검증 기록

실패를 재현하는 회귀 테스트와 PostgreSQL 통합 검사, 모바일·PC Playwright, 디자인 검사·빌드, 로컬 Codex 리뷰를 실시한다. 실제 모델 결과와 배포 확인은 자동 검사와 구분해 PR에 기록한다. 운영 고객 입력·이메일·개별 식별자는 이 문서나 테스트 fixture에 복사하지 않는다.

백엔드 전체 964건이 통과했고, 이후 세션 장애 격리 25건과 실행 검산 70건도 통과했다. 최신 대시보드 변경과 병합한 UI 전체 558건이 통과했으며, 이후 브라우저 저장 공간 차단·금액 일괄 입력 보완을 포함한 복구 검사 38건도 통과했다. 최종 브랜치의 전체 결과는 PR의 CI 기록을 기준으로 한다. 이 수치는 서로 중복되므로 합산하지 않는다.

실제 모델은 신규 추천·현금 시작·비중 ISA·다계좌 네 유형 모두 추천 비중을 발행했다. 다계좌는 333.3초에 5개 종목·계좌 배치를 생성했고 연금저축·IRP 신규 납입과 계좌 간 인출이 모두 0원이었다. 월 납입 시점의 가격이 같다는 조건부 실행이며, 미확인 부가 자료는 일부 남았다. 과거 PostHog 필터 적용은 API 키의 프로젝트·인사이트 쓰기 권한 부족으로 별도 대기한다.

가격 슬롯을 한 개로 줄인 뒤에도 선적재가 이를 독점하지 않도록 대기·실행 중인 고객 시세 수집에 양보한다. 재사용 시 버전이 다른 평가액이나 아직 조회 중인 종목의 과거 금액을 현재 금액으로 가져오지 않는다.
