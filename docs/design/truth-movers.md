# 오늘의 급등주 해석 (truth-movers)

etforca.com/truth/today. 오늘 급등한 국내 주식마다 **왜 올랐는지**를 공시·보도와 대조해(경쟁가설 분석, ACH) 판정하고 공개한다. 목적은 투자자가 기관·회사의 과장이나 근거 없는 테마에 당하지 않게 하는 것이다.

조사 에이전트 `apps/etforca/truth-research` 가 돈다. 기만 사건 검증 에이전트 `truth-agent`([truth-service.md](truth-service.md))와 같은 구조다(pi 하네스 + DeepSeek, 종목당 세션 하나, ECS Fargate 단발 태스크). 이미지·태스크·스케줄은 따로이고, 저장소 버킷·실행 키(DeepSeek·Exa)·뉴스 말뭉치·웹 도구는 truth-agent 것을 함께 쓴다. 화면은 truth-web `today.html`.

## 1. 판정 태그

| 태그 | 값 | 기준 |
|---|---|---|
| 유망주 | `promising` | 실제 회사 사건 가설이 남고, 읽은 공시 본문·공식 원문 또는 서로 다른 매체 두 곳 이상으로 확인된다 |
| 허위매물 | `false` | 사건은 있으나 주장이 원문보다 부풀려진 가설이 남았다. 또는 회사 근거 없는 테마·풍문 가설이 다른 설명보다 뚜렷이(차이 2 이상) 덜 어긋난다 |
| 판단 보류 | `pending` | 가설이 갈리지 않았거나, 남은 설명이 업종 동반·수급(신규 상장·급락 뒤 반등)이라 주장의 참·거짓이 아니다 |

태그는 모델이 고르지 않는다. 모델이 가설(3~6개)과 증거(가설마다 일치 C·어긋남 I·무관 N, 무게 high 공시·공식 원문 / mid 구체적 보도 / low 단일·불분명 보도)를 채우면, 코드(`ach.py`)가 어긋나는 증거 무게가 가장 적은 가설을 고르고 위 표대로 태그·확신도를 정한다. 표는 비공개 상태에만 남는다.

태그마다 판정 이유(최대 3줄)와 출처를 함께 싣는다. 화면에는 "AI 판단이며 투자 권유가 아니다"를 고지한다.

## 2. 실행 (장중 매시 :35)

평일 9~15시 매시 35분(`cron(35 9-15 ? * MON-FRI *)`, Asia/Seoul). truth-agent 사건 갱신(:05)과 30분 어긋나고, 15:35 실행이 장 마감 종가를 잡는다.

1. **급등 목록 (코드):** Naver 증권 상승률 순위(`m.stock.naver.com/api/stocks/up/{KOSPI|KOSDAQ}`)로 전체 시장 상승률 상위를 받는다. ETF·ETN·스팩·우선주는 뺀다. 상승률 10% 이상, 누적 거래대금 30억원 이상만 남긴다.
   - 시세는 키 없는 공개 시세로, 포트폴리오 서비스와 같은 출처(Yahoo 차트·Naver)다.
   - 순위 응답의 체결 시각이 오늘이 아니면(휴장일) 게시하지 않는다. 5분 시세로 보지 않는다(시세 지연이 있으면 09:00 실행이 빠진다).
   - 순위의 현재가는 넥스트레이드(NXT) 체결을 포함한다. 장 전·장 뒤 수동 실행에서는 KRX 정규장 가격과 다를 수 있다.
   - 순위 응답이 비었거나 형식이 다르면 실패로 끝낸다('오늘 급등 없음'으로 게시하지 않는다).
2. **재료 모으기 (코드):** 종목마다 다음을 모은다.
   - 장중 5분 시세와 현재가: Yahoo 차트(`<code>.KS|.KQ`, `interval=5m`). 그날 봉만 쓰고 라벨은 구간 끝 시각. 게시하는 가격·상승률은 이 현재가로 낸다(순위의 Naver 가격은 넥스트레이드 체결이 섞인다). 한국 종목은 약 20분 늦다
   - 최근 14일 공시·시장조치 목록과 원문: 한국거래소 KIND(키 없음, 종목코드로 조회. 시장감시위원회의 투자주의·경고도 함께 나온다)
   - 관련 보도: 뉴스 레이크 말뭉치
   - 회사 로고: KIND 회사 개요의 홈페이지에서 아이콘을 받아 랜딩 버킷 `truth/data/logos/<code>.<확장자>` 에 저장(PNG·JPG·ICO·WebP 만, SVG 는 스크립트를 담을 수 있어 받지 않는다)
3. **조사 (모델, ACH):** 종목마다 세션 하나를 연다(동시 3개, 한 실행 5종목, 세션당 도구 40회·웹 10회·공시 원문 8회). 도구: `read_disclosure`·`view_news`·`search_news`·`web_search`·`web_fetch` 로 증거를 모으고, `set_hypotheses`·`add_evidence` 로 표를 채우고, `set_verdict`(코드가 태그 결정)·`finish`.
   - 그날 이미 판정한 종목은 판정 때 보지 못한 공시가 나오면 다시 연다(태그 무관). 급등주에 거의 매시 붙는 거래소 시장경보(투자주의·경고·위험)는 다시 열지 않는다. 매매정지·관리종목 지정은 다시 연다. 새 보도만으로는 보류였던 종목만 다시 연다 — 특징주 기사가 매시 붙어 확정 판정까지 열면 세션 예산을 다 쓴다.
   - 제목(`event.title`)은 시스템 지시의 '제목 규칙'을 따른다: 무슨 일이 있었고 시장이 왜 좋게 봤는지 한 줄, 공시 용어 대신 일상어, 숫자 하나(반올림만, 새로 계산하지 않음), 이유 하나, 32자 이내, 판정은 넣지 않는다. 길이와 공시 용어(대용납입·단일판매 등, 끝의 '공시')는 `set_verdict` 가 막는다.
   - 판정과 그때 본 근거 id 는 비공개 상태(`state/movers-seen/<날짜>.json`)에 둔다. 목록에서 빠졌다 돌아온 종목도 그날 판정을 이어 쓴다.
   - 판정은 세션 안에서 게시 형식(스키마)을 검사한다. 시세 조회가 전부 실패하면 휴장이 아니라 실패로 끝낸다.
   - 공시를 조회하지 못한 종목(KIND 오류)은 조사하지 않고 보류로 싣는다. '최근 공시 없음'으로 넘기지 않는다.
   - 증거·출처는 그 세션에서 읽은 것(news-·web-·kind-)과 공시 목록 자체(kind-list, '없음'의 근거)만 쓴다. 공개 글에는 가설 번호를 쓰지 않는다.
   - 한 문서는 증거 한 건이다(같은 기사를 다른 경로·모바일 주소로 넣어도 한 건). 사건 확인 원문은 이 회사가 낸 공시 본문, 또는 이 회사를 다룬 공식 원문만이다(공시 목록·거래소 시장조치·다른 회사 공시는 아니다). 매체 수는 www·m 같은 하위 주소를 한 매체로 센다.
4. **게시 (코드):** `truth/data/movers/latest.json` 과 `truth/data/movers/<날짜>.json`, 게시한 날짜 목록 `truth/data/movers/dates.json`(최신순, 화면의 날짜 선택).

### 가격 갱신·새 급등주 감시 (장중 매분)

평일 9~15시 매분(`cron(* 9-15 ? * MON-FRI *)`), 같은 이미지를 `prices` 명령으로 0.25 vCPU·0.5GB 로 돌린다. 모델은 부르지 않는다.
- 오늘 게시한 종목의 가격·상승률·그래프·되돌림 예상 폭만 Yahoo 로 고치고, 마지막 체결 시각을 `pricedAt` 으로 싣는다. 판정·글은 건드리지 않는다.
- 오늘 게시가 없으면(첫 조사 9:35 전, 휴장일) 아무것도 하지 않는다. Yahoo 가 약 20분 늦어 15:59 까지 돌아야 장 마감 가격이 들어온다.
- 매시 조사와 같은 파일을 고치므로 비공개 원본을 버전 조건으로 쓴다. 읽은 뒤 조사가 새로 게시했으면 이번 갱신을 버린다(옛 판정으로 덮지 않는다).
- 거래대금은 조사 실행 때 값 그대로다.
- **새 급등주 감시:** 같은 작업이 Naver 순위를 화면 기준(10%·30억원·상위 15)으로 보고, 오늘 아직 판정하지 않은 종목이 있으면 같은 태스크 정의로 '새 종목만' 조사 실행(`run --new`, 세션 3개)을 띄운다. 매시 :35 정각 조사는 이미 있는 종목을 다시 보고, 감시가 놓친 새 종목도 함께 본다.
  - 15:30 이후에는 띄우지 않는다(장 마감 뒤 순위에는 넥스트레이드 시간외 체결이 섞인다). 가격 갱신은 15:59 까지 돈다.
  - 조사 실행이 돌고 있으면(잠금) 띄우지 않는다. :20~:37 에도 띄우지 않는다(정각 조사 태스크가 떠서 잠금을 잡을 때까지) — 잠금이 겹치면 정각 재검토가 통째로 빠진다. 새 종목만 실행은 세션 직전에 시각을 다시 보고 :27~:37 이면 판정을 정각 조사에 넘긴다.
  - 띄운 뒤 6분은 다시 띄우지 않는다(태스크가 잠금을 잡기 전 중복). 같은 종목만 남아 있으면(공시 조회 실패 등) 30분 기다린다. 띄우기에 실패하면 기록을 지우고 실패로 끝내 다음 분에 다시 시도한다.
  - 태스크 역할에 이 클러스터·이 태스크 정의로 한정한 `ecs:RunTask` 와 두 역할의 `iam:PassRole` 이 있다.
- **화면 팝업:** 화면은 지난번 본 목록(기기 브라우저에 날짜별로 저장)과 비교해 새 급등주·분석 완료·판정 변경을 오른쪽 아래 팝업으로 알린다. 여러 건이면 옆으로 넘기고 '1 / N'으로 개수를 보인다. 그날 처음 열면 알리지 않는다.

## 3. 순위 (파급력 근사)

"우리 판단이 맞고 시장이 틀렸을 때 되돌려질 폭"의 근사값이다: `impact = 오늘 상승률(%) × 확신도`.
- 허위매물만 이 값을 갖는다. 근거가 확인된 급등은 되돌릴 이유가 없어 0이다.
- 같은 값이면 상승률 순이다.

증거가 아니라 정렬용 근사값이며, 화면에 그렇게 적는다.

## 4. 공개 데이터 형식

`truth/data/movers/latest.json` (스키마: `apps/etforca/truth-research/src/edge_truth_research/movers.schema.json`)

```json
{
  "date": "2026-10-22",
  "generatedAt": "2026-10-22T11:00:42+09:00",
  "pricedAt": "2026-10-22T11:38:12+09:00",
  "items": [{
    "code": "001470", "name": "삼부토건", "market": "KOSPI",
    "logo": "data/logos/001470.png",
    "price": 5500, "prevClose": 4230, "changePct": 30.02, "tradeValue": 1234.5,
    "series": [["09:00", 4300], ["09:05", 4620]],
    "tag": "false", "confidence": 0.7,
    "event": {"title": "우크라이나 재건 사업 참여 기대", "kind": "news", "at": "2026-10-22T09:12:00+09:00"},
    "claim": "회사는 재건 사업 참여가 확정됐다고 밝혔다",
    "finding": "MOU 상대 기관의 공식 발표나 공시는 확인되지 않는다",
    "reasons": ["공시 없이 보도자료로만 알렸다", "상대 기관 원문이 없다"],
    "sources": [{"title": "…", "publisher": "…", "url": "https://…", "kind": "news", "publishedAt": "2026-10-22"}],
    "impact": 21.0,
    "judgedAt": "2026-10-22T11:03:10+09:00"
  }]
}
```

- `tradeValue` 단위는 억원(누적 거래대금), `series` 는 오늘 5분 간격 `[시각, 종가]`.
- `pricedAt` 은 가격(Yahoo)의 마지막 체결 시각이다. 화면은 '가격 HH:MM 기준'으로 쓴다(이 필드가 없는 예전 파일은 `generatedAt`).
- `logo` 는 사이트 기준 상대 경로이고 없으면 null(화면이 글자 배지로 대신한다).

## 5. 비밀값

따로 두는 키가 없다. truth-agent 의 `edge-dev-truth-agent/runtime` 시크릿(`DEEPSEEK_RESIST_NEWS_API_KEY`·`EXA_API_KEY`)을 같이 읽는다. 시세(Naver·Yahoo)와 공시(KIND)는 키가 없다.
