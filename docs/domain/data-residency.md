# 데이터 저장 위치 기준

**Cloud DB 저장 가능**: 테넌트 기본 정보, 데이터 소스 상태, 종목 마스터, 뉴스/공시 원천 메타데이터, 시세/수급 관측값, 가격 변동 이벤트, 이벤트 근거, AI 설명 후보, 이벤트 번들, 무효화 이력, 테넌트 동기화 상태, Super Admin 작업 로그

**Cloud DB 저장 금지**: 고객 ID, 계좌번호, 보유 종목, 관심 종목, 개인별 노출 이력, 고객별 클릭/조회 로그, 고객별 추천/개인화 결과, 최종 컴플라이언스 검수 결과, 고객에게 실제 노출된 최종 문구

**On-Prem DB 저장 필수**: 수신 원본 이벤트, 가격 변동 설명 콘텐츠, 컴플라이언스 검사 결과, 검수 작업/결정, 최종 노출 문구, Published 상태, Publication Cache 키, 고객 노출 이력, 콘텐츠 상태 변경 이력, 정책 변경 이력, 민원/감사용 재현 데이터, 사용자/권한, Cloud Sync 연결 정보
