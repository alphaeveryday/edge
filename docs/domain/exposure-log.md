# Exposure Log / 고객 식별 (은퇴 — ADR-0053)

> **이 결정은 [ADR-0053](../adr/0053-widget-direct-serving-no-personalization.md)으로 폐지됐다.**
> 고객 단위 노출 이력(민원/감사 재현) 요건과 고객 식별(`X-Customer-Hash`)을 유지하지 않는다 —
> 개인화 부재와 함께 확정된 독립된 제품 결정이다(2026-08-17).

현행 사실:

- Publication API 는 고객 식별을 어떤 형태로도 받지 않는다(인증 없는 공개 읽기 표면).
- 서빙 경로의 기록 축은 `serving_request_metric`(요청 수·상태·에러 코드 — 고객 식별자·문구 비적재)뿐이다.
- 민원 대응의 재구성 근거는 게시·정정 이력(`publication`·`console_action_log`)과 정책 이력(`policy_version` 활성 구간)이다 — 특정 고객에게 무엇이 나갔는가는 재구성 대상이 아니다.
- `exposure_log` 테이블은 수축 마이그레이션으로 제거한다(코드 은퇴 선행 — 확장수축).

노출 시점 재현이 다시 요건이 되면 스냅샷 재도입을 ADR 로 정면 재결정한다(역산 아님 — ADR-0053 대안 절).

<details>
<summary>구 결정 (기록 보존용 — 2026-07 ~ 2026-08, ADR-0013)</summary>

- **MVP 기록 방식**: Publication API **조회 시점 자동 기록** (조회 = 노출 간주).
- **확장 로드맵(MVP 아님)**: MTS 백엔드가 실제 렌더링 후 호출하는 노출 콜백 API.
- **고객 식별 해시**: 증권사 백엔드가 생성해 전달. 원본 고객 ID/계좌번호는 절대 받지 않음.
- 저장 항목: 콘텐츠 ID, 종목, 고객 식별 해시, 노출 문구 스냅샷, 노출 시각, 채널.

</details>
