# Exposure Log / 고객 식별 (확정 결정)

- **MVP 기록 방식**: Serving API **조회 시점 자동 기록** (조회 = 노출 간주). 감사/민원 대응 문서에 "노출 이력은 조회 로그 기준"임을 명시한다.
- **확장 로드맵(MVP 아님)**: MTS 백엔드가 실제 렌더링 후 호출하는 노출 콜백 API — 조회≠노출 오차를 제거.
- **고객 식별 해시**: **증권사 백엔드가 생성**해 Serving API 호출 시 전달한다. Serving API는 원본 고객 ID/계좌번호를 절대 받지 않는다. 해시 생성 규칙·salt는 증권사 관리 영역 (벤더는 관여하지 않음 — 비반출 원칙).
- Exposure Log 저장 항목: 콘텐츠 ID, 종목, 고객 식별 해시, 노출 문구(당시 실제 문구 스냅샷), 노출 시각, 채널(MTS/HTS/Internal). 근거 데이터·컴플라이언스 검사 결과·검수 결과와 조인하여 민원 시점 상태를 완전 재현할 수 있어야 한다.
