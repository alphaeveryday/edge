# 사건 내부 파라미터의 표현공간

목표는 하나의 규모 비율을 고르는 것이 아니라 **사건의 내용·관계·변화와 사전 상태의 조합에서 효과 구조를 발견하는 것**이다. 아래는 계약을 기준으로 한 후보 공간이며 실제 생성 가능한 변수 목록이 아니다. 데이터 품질 개선은 후속 작업으로 둔다.

## 표현 축과 원천 상태

표의 상태는 현재 [계약 온톨로지 정의](../../libs/ontology/src/edge_ontology/metadata/value_types/event_types/company_deal.yaml)와의 매핑이다. **정의됨**도 DB 적재·정확성·시점 가용성을 보증하지 않는다. **조인/파생 후보**는 원천 연결과 계산 검증이, **추출 후보**는 원문 추출과 변수 정의가 추가로 필요하다.

| 블록 | 변수 후보 | 원천 상태 |
|---|---|---|
| 규모·경제적 중요도 | 총액, 연간액, 매출·시총·수주잔고 대비 규모 | 금액·basis와 연간화·매출 비율 정의됨; 시총·수주잔고 비율은 조인/파생 후보 |
| 시간 구조 | 기간, 개시까지 시간, 납품 일정, 매출 인식 분포 | `CONTRACT_DURATION`, `EFFECTIVE_DATE` 역할 정의됨; 개시까지 시간은 파생 후보; 일정·인식 분포는 추출 후보 |
| 확정성·조건 | 공개 시점 단계, 확정액/한도, 조건부 여부, 해지·갱신·옵션 | `DEAL_LIFECYCLE` 참조 정의됨; 금액 한정어·세부 조건은 별도 추출 후보 |
| 거래 대상 | 제품·서비스, 산업, 공급망 위치, 신규 제품 여부 | `CONTRACT_OBJECT` 역할 정의됨; 분류·공급망·신규성은 조인/추출 후보 |
| 상대방 특성 | 고객 산업·국가·규모·공공/민간, 공급자와의 규모 비대칭 | `CUSTOMER` 역할 정의됨; 속성 연결·비대칭은 조인/파생 후보 |
| 관계 구조 | 반복 거래, 관계 지속 기간, 과거 규모, 고객 집중도, 계열 관계 | 고객·공급자 역할에서 출발하는 이력·관계 조인/파생 후보 |
| 사건의 변화량 | 신규/갱신/확대, 금액·기간 변화, 단계 전환, 이전 발표와의 차이 | 동일 계약 계보·과거 판본 연결과 추가 추출 후보; 현재 SIGN/ENTER_INTO만으로 갱신을 판정하지 않음 |
| 기업 사전 상태 | 성장률, 수익성, 재무 여력, 생산능력, 기존 수주, 과거 주가·거래량 | 공개 시점이 확인된 재무·가격·생산 자료 조인/추출 후보 |
| 산업·시장 상태 | 업황, 산업 수요, 금리·환율, 변동성, 동종 기업 계약 흐름 | 시점별 외부 자료와 과거 사건 집계 조인/파생 후보 |

## 같은 사실의 다섯 표현

| 표현 | 예시 변수 | 정의할 기준 |
|---|---|---|
| 절대값 | 총 계약금액 | 통화·basis·한도 여부 |
| 상대값 | 연간화 금액/직전 공개 TTM 매출 | 동일 통화·기간 해석·양수 분모 |
| 변화량 | 이전 계약금액 대비 증감률 | 동일 계약·비교 가능한 금액 기준·직전 알려진 판본 |
| 관계 내 위치 | 해당 고객과의 과거 계약 대비 규모 | 사건 전 관측 이력·관측 기간; 첫 관측을 실제 신규 관계로 단정하지 않음 |
| 산업 내 위치 | 동종 산업의 과거 계약 대비 분위 | 사전 정의한 비교군·과거 기준 창·최소 이력 |

미래 계약을 포함한 전체 기간 순위나 나중에 갱신된 재무를 쓰지 않는다. 학습된 범주화·인코딩·결측 대치·변환은 탐색 자료에서 적합해 고정한다. 과거 이력 집계는 각 사건 시점 이전 정보만으로 갱신한다. 동일 사실의 여러 표현은 중복 여부를 기록하고 대안 표현 또는 블록 제거로 기여를 비교한다.

## 넓게 탐색하되 표본은 블록별로 유지

- 기본 표본은 기업·독립 사건·시점·결과변수 연결 요건으로 정한다. 모든 후보 변수의 완전 관측을 요구하지 않는다.
- 기본 표현과 블록별 확장 표현을 구분한다. 각 블록은 포함률·미관측 사유·시기/기업 편향을 기록한다. 기본 표현 자체도 결측 처리 규칙을 등록한다.
- 확장 블록의 기여는 **그 블록을 평가할 수 있는 동일 표본에서 기본 모델과 확장 모델을 모두 학습·평가**해 비교한다. 전체 기본 표본의 성능과 직접 빼지 않는다. 날짜 분할·예산은 맞춘다.
- 결측 처리는 사전 지정한다. 결측·출처·추출 버전이 분기를 지배하면 관측 과정에 따른 패턴으로 표시하고 경제적 효과와 구분한다. 블록별 결과를 전체 계약으로 일반화하지 않는다.
- 넓은 후보 공간에도 트리 복잡도·선택 절차·검정군을 제한한다. 모든 변수 조합을 독립 가설처럼 무제한 검정하지 않는다.

## 패턴에서 인과 질문으로

반응 탐색에서는 사건 공개 시점에 알려진 Z와 사전 상태 X의 조합을 사용할 수 있다. 발견된 조합은 인과 가설의 후보이며 아직 효과의 원인이 아니다.

후보마다 처치 T, 대비 a/b, 교란 X, 처치 전 조절 변수 W, 매개변수, 적용 모집단을 다시 정의한다. 공개 시점에 관측됐다는 사실만으로 다른 계약 조건이 처치 전 변수가 되지는 않는다. 예를 들어 규모와 기간이 함께 협상됐다면 기간을 규모의 효과 조절 변수로 자동 채택하지 않는다. 필요하면 공동 처치를 정의하거나 반응 연구로 남긴다.

반응 탐색과 인과 트리 선택은 모두 D 안에서 수행하고, 인과 질문과 트리를 고정한 뒤 E에서 독립 추정한다. E를 보고 질문·규칙을 수정하면 E는 탐색에 편입하고 새 독립 추정 자료를 확보한다. H는 최종 확인까지 잠근다. 구체적 절차는 [공통 프로토콜](protocol.md)을 따른다.

다른 타입에서는 같은 축을 재사용하되 역할·단위·변화의 의미를 다시 매핑한다. 의미가 맞지 않는 축은 해당 없음으로 남긴다.
