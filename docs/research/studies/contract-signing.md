# CONTRACT-001: 계약 내부 파라미터와 시장 효과

상태: **설계 초안 · 미실행**. 아래는 후보이며, 값이 비어 있는 확인 실험 항목은 실제 탐색 전 등록한다.

질문은 “같은 공급계약이라도 상대 규모·기간·단계·고객 특성에 따라 효과가 어떻게 달라지는가?”다. 분석 주체는 우선 공급자로 한정한다. 고객 주가에 대한 효과는 별도 연구로 다룬다.

원천 정의는 [company_deal.yaml](../../../libs/ontology/src/edge_ontology/metadata/value_types/event_types/company_deal.yaml)의 `COMPANY.CONTRACT.SIGNING`이다. 이 링크는 정의의 출처이며 해당 값의 실제 가용성·정확성을 보증하지 않는다.

| 후보 변수 | 현재 정의와 매핑 | 실험에서의 의미 |
|---|---|---|
| 계약금액 | `quantities.CONTRACT_VALUE`, 통화와 TOTAL/ANNUAL 기준 보존 | 절대 계약 규모 |
| 계약기간 | `quantities.CONTRACT_DURATION`, 단위를 확인해 연 단위 변환 | 지속 기간 |
| 연간화 금액 | TOTAL은 금액/기간(년), 기간 미상이면 파생 불가; ANNUAL은 기간 없이 금액 그대로 | 기간이 다른 계약 비교 |
| 매출 대비 규모 | `derived.revenue_share`: 연간화 금액/공급자 직전 공개 TTM 매출; 통화 통일 | 기업에 대한 상대 규모 |
| 계약 단계 | `lifecycle_model: DEAL_LIFECYCLE`, 공개 시점의 단계 | 확정성; 이후 확정 단계로 덮어쓰지 않음 |
| 계약 대상·고객 | `roles.CONTRACT_OBJECT`, `roles.CUSTOMER` | 대상 범주, 고객 유형, 과거 관계; 범주화 규칙은 등록 필요 |
| 기업의 사전 상태 | 직전 공개 재무, 시가총액, 과거 수익률·변동성·섹터 | 교란 통제와 효과 조절 후보 |

`op_impact_share`는 동일 정의의 이익률·매출·영업이익을 쓰면 `revenue_share`와 대수적으로 같아질 수 있으므로 독립적인 표현 기여로 세지 않는다. 다른 사건 내용도 자동으로 통제변수가 되지 않는다.

## 첫 실험의 모양

1. **반응 탐색:** 상대 규모·기간·단계 등 Z와 사전 상태 X로 CAR의 조건부 패턴을 찾는다. 임계값은 탐색 결과이지 사전 사실이 아니다.
2. **인과 질문 구체화:** 예를 들어 “비슷한 사전 상태의 공급자에서 연간화 계약 규모 a 대 b의 효과는 어떠한가?”를 정의한다. 연속 처치인지 사전 구간 비교인지, 처치 범위와 공통 지지를 등록한다. 같은 규모 비율이라도 계약 내용이 다른 문제는 처치의 일관성 가정에 명시한다.
3. **인과 트리:** 처치 전 W로 효과 차이를 탐색한다. 규모 T 자체를 분기해 얻은 CAR 차이를 곧바로 규모의 인과 효과라고 부르지 않는다. 식별 근거가 부족하면 1의 반응 연구만 확증한다.
4. **미래 확인:** 동결된 규칙을 미래 사건에 적용하고 [공통 검증 묶음](../protocol.md)을 모두 보고한다.

실행 전 확정할 항목: 모집단·기간, 사건 그룹 규칙, 처치 대비, 인과도·통제·조절 변수, 주 결과 창·정상 모델, D/E/H 경계, 추정기·복잡도·검정력 기준, 다중검정군, 반증시험. 데이터 품질 수정은 별도 후속 작업이며 이 문서에는 실측 효과를 기입하지 않았다.
