# ETF 요청창 블록 출력 설계

## 목적

ETF 설명을 요청된 시간창 하나에 대해 고정된 블록 순서로 출력한다. 코드가 어떤 블록과 사실을 쓸지 결정하고, LLM은 허용된 자리표시자를 사용해 문장만 작성한다. 실제 숫자·시각·종목명·출처는 코드가 검증 후 치환한다.

## 범위

- 수치 표시가 기본이다.
- 요약 모드는 같은 계산값을 로그에 남기고 화면 숫자만 정성 문구로 바꾼다.
- 리포트 데이터와 리포트 인용 블록은 제외한다.
- 호출마다 독립된 새 설명을 만든다.
- 갱신·`supersedes`·철회·재발행·준법 정정은 만들지 않는다.
- 이전 시간창의 가격·방향·문장은 현재 설명의 입력이나 출력에 넣지 않는다.

## 시간 계약

요청은 `(instrument, trade_date, window_start, window_end)`로 식별한다.

- 헤더의 `HH:MM 기준`은 항상 `window_end`다.
- 헤더 ETF 수익률만 전일 종가부터 `window_end`까지의 누적값이다.
- 기여·구성종목 폭·NAV·시장·섹터와 가격 경로는 `window_start`부터 `window_end`까지 계산한다.
- 공시·뉴스는 `available_at <= window_end`인 자료만 쓴다.
- 일단위 통계는 구간 인과로 표현하지 않는다. 요청창과 직접 정렬된 검정만 통계·인과 블록에 들어간다.
- 호출 과정에서 당일 원천을 여러 창으로 계산할 수 있지만, LLM에는 요청창의 `WindowFacts`만 전달한다.

## 조립 구조

### `WindowFacts`

코드가 요청창에 대해 다음 사실을 계산한다.

- 헤더용 ETF 전일 종가 대비 누적 수익률과 방향
- 설명 블록용 요청창 ETF 수익률과 방향
- NAV 수익률과 괴리
- 구성종목별 수익률·기여도와 상승/하락 종목 수
- 창 내부 가격 경로 요약
- 같은 창의 섹터·시장 수익률과 상대 성과
- 최근 분포상 이례성
- PIT를 통과한 공시·뉴스·수급 사실
- 통계 검정 결과와 표본 수
- 실제 사용한 데이터셋·필드·엔티티·시간·`as_of` 계보

요청창 밖 가격변동은 `WindowFacts`의 설명 입력에 포함하지 않는다.

### `BlockPlan`

코드가 `WindowFacts`에서 블록의 발생 여부, 순서, 허용 자리표시자, 실제 값, 근거 ID를 결정한다. LLM은 블록을 추가·삭제·재정렬하지 못한다.

### LLM 문장 계약

LLM은 블록별 고정 지시와 허용 자리표시자 목록을 받는다.

예:

```text
하락은 {top1_name}({top1_return})와 {top2_name}({top2_return})에 집중됐습니다.
```

규칙:

1. 숫자·시각·종목명·출처를 직접 쓰지 않는다.
2. 허용된 `{placeholder}`만 사용한다.
3. 필수 자리표시자를 누락하거나 중복하지 않는다.
4. 코드가 선택하지 않은 블록이나 원인을 추가하지 않는다.
5. 통계 결과를 공시·뉴스 사실보다 강하게 인과로 표현하지 않는다.

코드는 문장을 검증한 뒤 자리표시자를 실제 값으로 치환한다. 숫자 직접 작성, 미허용 토큰, 필수 토큰 누락, 블록 수·순서 변경은 계약 위반으로 거부하고 제한 횟수만 재시도한다. 재시도 후에도 실패하면 해당 블록을 판정불가 문구로 대체하며 다른 블록은 유지한다.

## 출력 순서

1. 헤더
2. NAV 괴리
3. 기여
4. 구성종목 폭
5. 창 내부 구간
6. 섹터·시장 상대 움직임
7. 이례성
8. 공시
9. 수급
10. 뉴스
11. 통계
12. 인과
13. 부재 고지
14. 근거

### 헤더

```text
KODEX 반도체 -6.2%
13:20 기준 · 전일 종가 대비
```

시간은 요청창 종료 시각이고 수익률은 전일 종가 대비 누적값이다. 아래 설명 블록은 요청창 시작~종료만 다룬다. 독립 호출이므로 `갱신됨`·`정정됨`·`재발행` 표시는 없다.

### 필수 블록

기여·구성종목 폭·창 내부 구간·섹터·시장 상대 움직임은 항상 발생한다. 필요한 데이터가 없으면 0으로 쓰지 않고 해당 블록에 판정불가 사유를 출력한다.

### NAV 괴리

시장가와 NAV 차이가 기존 표기 임계를 초과할 때 헤더 직후 출력한다. 임계 이하면 블록 자체를 생략한다.

### 이례성

최근 분포에 대한 기존 계산 임계를 충족할 때만 출력한다. 같은 입력과 임계는 항상 같은 발생 여부를 만든다.

### 공시·수급·뉴스

PIT와 선행성 게이트를 통과한 사실만 출력한다. 리포트는 데이터가 없으므로 후보 목록에도 넣지 않는다.

공시와 뉴스 블록이 모두 비면 다음 부재 고지를 자동 출력한다.

```text
해당 구간에 확인된 공시·보도는 없습니다.
```

선행성 게이트에서 탈락한 자료는 감사 로그에는 남기지만 현재 설명의 원인이나 사실 블록으로 재사용하지 않는다.

### 통계와 인과

통계 검정의 전역 최소 표본은 `MIN_N=20`이다.

- `n >= 20`: 검정 게이트를 통과한 결과만 통계 블록에 넣는다.
- `n < 20`: 평균·효과·p값을 모두 숨기고 `표본이 부족해 판단하지 않았습니다`만 출력한다.
- 일단위 ATT를 요청창 인과로 표현하지 않는다.
- 외부 검증이 없는 결과는 통계 근거 이상으로 승격하지 않는다.

## 수치 표시 모드

기본 모드는 코드가 치환한 수치를 표시한다.

요약 모드는 같은 `WindowFacts`와 `BlockPlan`을 사용하되 표시 단계에서 숫자 슬롯을 정성 구간으로 바꾼다. 계산값과 근거 묶음은 그대로 저장한다. 요약 모드 때문에 블록 발생 여부나 순서가 바뀌지 않는다.

## 근거와 계보

화면의 근거 줄은 실제 사용한 출처만 나열한다.

```text
근거: DART · 구성종목 실시간 시세 · KRX 반도체 지수 · 코스피
```

각 블록의 근거 묶음에는 다음을 저장한다.

- 블록 종류와 요청창 시작·종료
- 실제 치환한 값
- 데이터셋·뷰·필드·엔티티
- `available_at` 및 `as_of`
- 공시·뉴스·사건·스레드 ID
- 통계 표본 수·효과·p값·검정 게이트
- LLM이 반환한 자리표시자 문장과 최종 치환 문장

## 지원 Case

이번 범위는 Case 1~4, 6~10, 14~15의 블록 조합을 지원한다.

- Case 5 리포트 인용: 데이터 부재로 제외
- Case 11 갱신: 독립 호출 계약으로 제외
- Case 12 철회 후 재발행: 제외
- Case 13 준법 정정: 제외

## 검증

최소 자동 검증은 다음 계약을 지킨다.

- 헤더 시각이 요청창 종료 시각과 같다.
- 요청창 밖 가격변동 문장이 출력되지 않는다.
- 기여·구간·상대 블록이 항상 하나씩 존재한다.
- NAV·이례성·공시·수급·뉴스·통계·인과 블록은 각 게이트와 정확히 일치한다.
- 공시·뉴스가 없으면 부재 고지가 정확히 하나 존재한다.
- LLM 숫자 직접 작성과 미허용 자리표시자를 거부한다.
- 치환 후 미해결 `{placeholder}`가 없다.
- `n=19`는 수치가 없고 `n=20`부터 검정 가능하다.
- 수치 모드와 요약 모드의 블록 집합·순서·근거 ID가 같다.
- 같은 입력은 같은 `BlockPlan`과 수치 치환 결과를 만든다.

## 운영 지표

기존 실행 로그에서 다음을 집계한다.

- 블록별 발생률
- 상승·하락 분리 매칭률
- 게이트별 기각률과 사유
- 통계 블록 표본 미달률
- 수치 모드·요약 모드 사용률
- 각 출력 블록과 근거 묶음의 자동 대조 실패율

갱신·정정·재발행과 인과 블록 활성 테넌트 수는 이번 범위에 포함하지 않는다.
