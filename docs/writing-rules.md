# 문서 작성 톤 규칙 (모든 산출물 공통)

- "AI 리포트 생성기" ✕ → "증권사가 통제 가능한 가격 변동 설명 운영 인프라" ○
- "가격 변동의 확정 원인" ✕ → "공개 정보 기반 변동 요인 후보" ○
- 고객 데이터 비반출을 핵심 원칙으로 서술
- 컴플라이언스와 감사 로그를 제품 핵심 가치로 서술
- Cloud-only / embed widget 구조는 "폐기된 방향"으로 명시
- MVP에서 제외된 기능은 명확히 제거 (모호하게 남기지 않음)
- 대외 산출물(발표·기획서·영업 문서)에서 배치 환경은 **"증권사 관리 환경"**을 기본 표현으로 쓰고 On-Prem(ise)은 보조 병기 — "물리 서버 한정"으로 오독되는 것을 방지. 내부 기술 문서·컴포넌트명은 On-Prem 유지 (용어 정의: [context.md](context.md))
