# 설명 정당화 표준 — 필요·충분조건과 언어 라이선스

## Summary

- 이 문서는 설명 산출물의 **정당화 조건**을 두 층으로 고정한다: **설명 객체**의 충분조건 S0~S8, **자연어 문장**의 필요조건 N1~N7과 라이선스 사다리.
- 관계식: `문장의 정당화 = 충분한 설명 객체(S0~S8) + 그 객체의 비과장 투영(N1~N7 + 라이선스)`. 문장은 인증서의 투영이며, 투영은 손실은 가져도 과장은 못 가진다.
- 단일 사건 가격 설명은 **미결정 역문제 + token 인과 귀속**이므로, 도달 가능한 상한은 확정적 인과 증명이 아니라 **명시된 가설공간에 대한 확률적 평결**이다. 이 상한을 넘는 주장은 어떤 방법론으로도 불가능하며, 본 표준의 충분조건은 이 상한에 상대적이다.
- 집행은 규범이 아니라 코드다: value_ref 린트, 동사 렉시콘 린트, 의무 조항 체크, 확신 부사–보정 확률 밴드 매핑. 위반 문장은 렌더 거부된다.

## Context

가설 어휘(레이어 경로, playbook)는 [메커니즘 탐색공간](../../research/explanation/mechanism-search-space.md)이, 게이트·창·분해 계약은 explanation-engine과 price-decomposition 스펙이 소유한다. 이 문서는 **그 산출물이 언제 정당화되고, 어떤 문장으로 발화될 수 있는가**의 계약만 소유한다.

## 1. 문제의 성질 — 왜 상한이 확률적 평결인가

자산 $i$의 창 $W$ 수익률 $r$, 정보 도착 과정 $\{e_k\}$, 시장 상태 $S$에 대해 설명은

$$E(r, W) = \{(h_1, \delta_1), \dots, (h_k, \delta_k), (\text{UNKNOWN}, \delta_0)\}$$

이고, 생성 모형은 $r = \sum_k f_k(e_k, S) + \varepsilon$ (관측 1회, $f_k$ 미지)이다. 두 성질이 근본 제약을 건다.

**미결정성**: 원인 후보 k개, 관측 1개 — 방정식보다 미지수가 많다. 식별의 유일한 경로는 관측 차원 확장이다:

| 분할 축 | 관측 수 | 대응 게이트 |
|---|---|---|
| 시간 분할 (발표 전/직후/소화/지속) | 1 → 4+ | timing |
| 단면 분할 (노출도 다른 N종목) | 1 → N | xsec |
| 자산군 분할 (주식·금리·환율·변동성) | 1 → M | cross-asset |
| 주체 분할 (투자자 유형별 수급) | 1 → J | microfoundation |

**token 인과**: 통계가 식별하는 것은 type 수준 규칙성($\mathbb{E}[r\,|\,\text{surprise}]$의 기울기)뿐이다. "**이번** 움직임이 **이** 사건 때문"이라는 token 주장의 정당화 형식은 기후 사건귀속·감별진단·사고조사가 공유하는 삼단 결합이다:

$$\text{token 정당화} = \underbrace{\text{type 규칙성}}_{\text{반복표본}} \times \underbrace{\text{이번 사례의 지문 적합}}_{\text{fingerprint fit}} \times \underbrace{\text{경쟁가설 배제}}_{\text{differential}}$$

결론 형식은 항상 확률적 평결이다. 하위 문제별 해결 가능성:

| 하위 문제 | 해결 가능성 |
|---|---|
| Q1 측정 (비정상수익률 확정) | 완전 해결 가능 — 통계 |
| Q2 후보 생성 (가설공간) | 열린 세계 — 증명 불가, **recall 계측만 가능** |
| Q3 판별 (어느 후보인가) | 부분 식별 — 우도비 |
| Q4 정량화 (각각 얼마나) | 점추정 불가 — 구간만 |
| Q5 메커니즘 (왜 경제적으로) | 사건 단위 검증 불가 — type 수준만 |

이 표를 숨기지 않는 것 자체가 과학적 수용가능성의 전제다.

## 2. 설명 객체의 충분조건 — S0~S8

선언된 임계 $(\rho, \tau, \alpha, \dots)$ 하에서 S0~S8이 모두 성립하면, 그 설명은 "가설공간 $\mathcal{H}$와 오류율 프로파일 하에서의 확률적 귀속"으로서 정당화된다. 이것이 단일 사건에 대해 도달 가능한 최대 강도다.

| # | 조건 | 위반 시 무너지는 것 |
|---|---|---|
| S0 | **절차 무결성** — PIT(가설부는 $t_0$ 이전 데이터만), 전수 원장(다중비교의 정직한 분모), 리플레이 가능성 | 이하 전부 무효 |
| S1 | **측정 타당성** — $AR = r - \mathbb{E}[r\,|\,\mathcal{F}_{pre}]$ 확정, 반사실 모형 비이벤트일 OOS 검증, CI 부착 | 정상 변동을 설명하는 허구 |
| S2 | **가설공간의 상대적 폐쇄** — 후보 생성기의 골든케이스 recall ≥ ρ 계측, UNKNOWN 상시 포함 | "잘못된 메뉴에서의 최선" 오류 |
| S3 | **type 근거** — 후보 메커니즘마다 반복표본 효과 분포(n≥임계, 부호 안정), 이번 사례가 support 내(외삽 금지) | 일화적 서사 |
| S4 | **지문 판별** — $LR_{k,j} = P(\text{지문}\,\vert\,h_k)/P(\text{지문}\,\vert\,h_j) > \tau$, UNKNOWN 포함 전 경쟁자 대비. 마진 미달 시 동률 선언 의무 | 임의 선택 |
| S5 | **엄격성(severity)** — 통과한 검정이 "가설이 거짓이면 높은 확률로 실패했을" 검정. 음성 통제로 측정된 오탐율을 인증서에 부착 | 통과가 정보가 아님 |
| S6 | **강건성** — 창·모형·peer set 스펙 곡선에서 판정 불변 | 연구자 자유도의 산물 |
| S7 | **보정(calibration)** — 확신 등급별 사후 적중률을 원장 재검증으로 유지 | 확률 표기가 장식 |
| S8 | **잔여 정직성** — $\sum_k \delta_k \leq 1$, UNKNOWN 몫 $\delta_0$ 명시 | 과잉 귀속 |

게이트 의미론과의 접속: 자격(admissibility) 게이트는 S2·S3의 후보 자격을, 지지(signature) 게이트는 S4의 우도를, 반증(falsifier) 게이트는 S5의 거부권을 구현한다 (탐색공간 문서 §6.3).

## 3. 문장의 필요조건 — N1~N7

아래 중 하나라도 결여되면 어떤 문장도 발행 불가:

| # | 조건 | 위반 예 |
|---|---|---|
| N1 | 모든 정량 토큰은 `value_ref` — 수치는 등록 함수 출력의 참조로만 존재 | "6.2% 올랐다" (ref 없음) |
| N2 | **인과 동사 강도 ≤ 인증 등급의 라이선스** | 수준 2 인증에 "때문에 올랐다" |
| N3 | **반증 조건 내장** — 무엇이 발견되면 이 판정이 기각되는지 문장이 싣고 다님 | 킬 조건 없는 단언 |
| N4 | 수준 3 이상은 경쟁 가설 배제 조항 의무 — 조항 자체가 인증된 게이트 결과 인용 | "다른 요인은 없어 보인다" (근거 없는 배제) |
| N5 | 주장 범위 한정 — 이 창, 이 자산, 이 asof | "시장이 정책에 반응했다" (무한정 일반화) |
| N6 | 미귀속 잔여 몫 명시 | 잔차 100%를 한 원인에 귀속 |
| N7 | 재현 참조 — 인증서 id (리플레이 가능성) | 추적 불가 문장 |

## 4. 언어 라이선스 사다리 — 등급이 동사를 정한다

선례: IPCC 보정 언어(고정 어휘 ↔ 정량 확신도), 의학 GRADE, NTSB "probable cause". 언어 합의의 방식은 항상 **통제 어휘를 정량 근거에 고정**하는 것이다.

| 등급 | 허용 동사 클래스 | 허용 확신 부사 | 의무 조항 |
|---|---|---|---|
| 1 동시발생 | 관측되었다 · 동반했다 | 없음 (확신 표현 금지) | "인과 방향 판별 불가" 명시 |
| 2 시간 귀속 | 정합하다 · 관련 가능성이 있다 | 낮음 | 미배제 경쟁 후보 존재 명시 |
| 3 강한 귀속 | **주요 동인으로 판단된다** | 중간/높음 (보정 밴드) | 경쟁 배제 인용(N4) + 반증 조건(N3) + 잔여 몫(N6) |
| 4 준인과 | **유발했다는 강한 증거와 일치한다** | 높음 | type 표본 통계 + 단면 패턴 + 보정 이력 인용 |
| 5 인과 식별 | 인과 효과로 추정된다 | 식별 전략 명시 | 식별 가정의 명시 |
| 전 등급 금지 | 증명되었다 · 확실하다 · 명백하다 | 단정 무한정 | — |

수준 4에서도 맨몸의 "유발했다"는 없다 — "유발했다는 강한 증거와 일치한다"가 이 시스템의 최강 문장이다. 겸손이 아니라 관측 연구 식별력의 정확한 표기다.

### 등급별 예문

**수준 1** — "D일 KOSPI 상승({v1})과 정책 발표가 같은 날 관측되었다. 이 데이터로는 인과 방향을 판별할 수 없다."

**수준 2** — "10:00 발표 직후 5분 창에서 {v1}의 점프가 발생했고, 발표 전 30분간 유의한 드리프트는 없었다[cert]. 시간 선후는 발표 원인 가설과 정합하나, 동일 창의 경쟁 사건 2건[ref]을 배제하지 못했다."

**수준 3** — "발표가 이 창 상승의 **주요 동인으로 판단된다** (확신: 중간[cal]). 근거: 반응이 발표 직후 집중[ref], 금리·환율이 채널 예측 방향으로 동행[ref], 타임라인상 경쟁 사건 부재[cert]. 잔차의 {v4}는 미귀속으로 남는다. **이 판정은 발표 전 드리프트 발견 또는 동시각 미관측 사건 발견 시 기각된다.**"

**수준 4** — "이 유형의 surprise에 시장은 5년 40건에서 체계적으로 반응해왔고(β={v5}, placebo p={v6}), 노출도 상위 종목일수록 크게 반응했다[ref]. 이번 반응은 그 분포의 {v7} 분위로, 발표가 상승을 **유발했다는 강한 증거와 일치한다** (확신: 높음[cal])."

## 5. 문장의 충분조건 — 충실한 투영

문장을 의미 성분으로 분해하면 — 주어(자산·창), 동사(인과 강도), 목적어(원인 사건), 부사(확신도), 조항(경쟁·잔여·반증) — 충분조건은:

> N1~N7을 만족하고, **모든 의미 성분이 인증된 아티팩트에 1:1 대응**하며, 동사 강도가 등급 라이선스와 일치하고, 확신 부사가 보정된 확률 밴드와 일치할 때 — 그 문장은 정당화된다.

즉 문장의 충분조건 = 충분한 객체(S0~S8)의 **비과장 투영**. 문장 층에 새로운 인식적 노동은 없다 — 문장은 인증서가 이미 획득한 것 이상을 절대 말하지 않는다.

## 6. 왜 이 기준에서 합의가 가능한가

**기둥 1 — 방법론 대응.** 각 문장 형식이 인정된 방법의 식별력에 대응한다: 동시발생→서술통계, 시간귀속→이벤트스터디, 주요동인→고빈도 식별+교란배제, 강한증거→반복표본 회귀+placebo+단면. 자기 방법의 보증 범위를 넘지 않는 주장은 공격 표면이 없다.

**기둥 2 — 보정 이력.** "확신: 중간"이 추적되는 수치다 — 등급별 사후 유지율 공개. 업계는 트랙 레코드에, 학계는 보정에 합의하며, 둘 다 이 하나로 충족된다.

**기둥 3 — 반증가능성 보존.** N3 덕분에 모든 문장이 자기 기각 조건을 싣고 다닌다. 이견이 수사가 아니라 경험적 문제가 된다 — "그 킬 조건을 충족하는 증거를 가져오라."

정직한 한 가지: **합의되는 것은 진리가 아니라 정당화다.** 학계가 서명하는 것은 "이 문장이 참"이 아니라 "이 문장은 제시된 증거가 허용하는 최대치를 초과하지 않았다"이다. 그 이상을 약속하면 마케팅이고, 그 이하로 말하면 정보를 버리는 것이다. 목표 지점은 그 사이의 유일한 선 — 증거가 허용하는 정확히 그만큼만 말하는 문장이다.

## 7. 집행 계약 — 렌더러 린트

이 표준은 규범 문서가 아니라 렌더러의 거부 규칙으로 구현된다:

| 린트 | 규칙 | 위반 시 |
|---|---|---|
| value_ref 린트 (N1) | ref 없는 수치 리터럴 탐지 | 렌더 거부 |
| 동사 렉시콘 린트 (N2) | 인과 동사 사전(클래스별 허용 등급) 대조 — 인증 등급 초과 동사 | 렌더 거부 |
| 조항 체크 (N3·N4·N6) | 등급별 의무 조항 부재 | 렌더 거부 |
| 부사–확률 밴드 (S7) | 확신 부사 ↔ 보정 확률 구간 고정, `cal:` ref 없는 확신 표현 | 렌더 거부 |
| 등급 기원 (N7) | 인증서 id 참조 없는 등급 문자열 | 렌더 거부 |

네 린트가 모두 걸리는 순간부터 시스템은 **구조적으로 과장할 수 없다** — LLM의 수사가 아니라 렌더러의 거부 능력이 정직성을 보증한다.
