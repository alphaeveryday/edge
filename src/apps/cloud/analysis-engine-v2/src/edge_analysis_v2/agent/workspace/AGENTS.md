# 분석 결과 작성 원칙

**결론 먼저. 한 불릿은 한 주장. 소제목 하나에 최대 5불릿.** 더 필요하면 내용을 뭉치지 말고 논점을 다른 소제목으로 나눈다. 원인·반론·기간·가정·근거는 보존한다.

## 제목과 본문

- 제목만 읽어도 구체적인 대상과 변화·대비가 보여야 한다. 자연스러운 명사형으로 끝낸다. 예: '수주 증가에도 정체된 장비 매출'. 분류명·추상어·숫자 목록·미완성 문장으로 대신하지 않는다. 예시 사실은 복사하지 않는다.
- 주장을 먼저 쓰고 필요한 근거를 짧게 연결한다. 여러 기업·계약·비중·수급을 한 문장에 몰지 않는다. 원인→관측→기대→가격 연결은 필요한 여러 불릿에 나눠 쓴다. 반복 수치와 일반론을 덜고 핵심 한계는 대상·조건과 함께 남긴다.
- 사실·가정·판단을 자연어로 구분한다. 간결하게 고쳐도 예정·가능성·비교 기간을 지우거나 주장 강도를 높이지 않는다. 내부 구현·조사 일지·일반적인 주의 문구로 자리를 채우지 않는다.
- 금액은 자연스러우면 소수 한 자리, %는 소수 한 자리로 쓰고 불필요한 .0·-0.0을 없앤다. 본문은 자연스러운 해요체·합니다체를 쓴다.

## 요약·결론

- summary_card.title·detail.title·conclusion.title은 짧은 분석 제목이다. 장문 결론을 제목에 복사하지 않는다.
- 요약은 핵심 결론·이유·가장 중요한 반론을 짧은 문장으로 전달한다. 수치·기업별 근거는 상세에 둔다. 쉼표나 접속어로 여러 주장을 묶어 형식상 두 문장으로 만들지 않는다.
- supports·burdens의 label은 하나의 요인을 나타내는 짧은 키워드다. 예: '수주 증가', '기관 매도 지속'. 금액·날짜·비중·지표값·미확보 자료 목록을 넣지 않는다.
- conclusion.sentence는 현재 가격의 판단과 핵심 이유, change_condition은 이를 실제로 바꿀 관측을 담는다. 근거 목록을 반복하지 않는다. 확인된 사실을 미래 확인 과제로 되돌리지 않는다.

## 편집·오늘의 설명

- 기존 글도 그대로 복사하지 말고 긴 문장을 나눠 새로 편집한다. 전망의 유지 논점 ID·근거를 보존하고 표현 수정만으로 새 사실처럼 강조하지 않는다. 움직임의 기존 불변 기록은 소급 편집하지 않는다.
- 오늘의 설명은 사건의 날짜·기업·핵심 내용 다음에 사업 영향을 짧게 쓴다. 해요체로 작성하며 두 문장을 채우려 세부를 나열하지 않는다. 전망의 결론 필드나 가격 판단을 추가하지 않는다.
- 제출 전 제목만 읽어 핵심 전달을 확인하고, 상세와 요약의 원인·반론·시점·가정이 같은지 대조한다. 소제목별 불릿을 세어 5개를 넘으면 분리한다.
