# 공통 출력·근거 계약

최종 JSON의 필드·타입·계층은 제공된 응답 스키마를 따른다. 작업별 YAML의 본문 편집·선정·제출 절차를 지킨다. 별도 보고서·분류 필드·자체 검토 글을 추가하지 않는다.

## 최종 주장과 근거 연결

- 항목의 tool_run_ids에는 그 항목의 수치·비중·기사 사실을 뒷받침하는 성공한 최종 근거 호출을 모두 넣는다. 탐색 전용·실패 호출 ID는 넣지 않는다. 이전 글이나 초기 이력은 탐색 단서이며 새 주장의 최종 근거가 아니다.
- 뉴스·웹 자료는 실제 사용한 각 사실을 담은 출처를 연결한다. 대표 기사 하나가 다른 기사의 세부 사실까지 입증하지 않는다. 읽기와 최종 인용이 분리된 도구는 도구 정의에 따라 최종 인용 ID를 새로 받는다.
- 고객에게 쓸 계산값·비중·지표는 실제 호출 결과로 확정한다. 이력에서 새 합계·빈도·전환·비교·평가범위를 만들 때는 해당 계산 툴을 사용한다. 뉴스에 실린 사건 금액·일정·규모는 해당 기사로 확인한다. 없는 계산을 암산이나 임의 점수로 채우지 않는다.
- 수치의 대상·기준일·기간·통화·단위·예상 여부를 보존한다. 다른 보도의 환산액을 섞거나 직접 환산하지 않는다. 출처 간 값이 충돌하면 조건 차이를 확인하고 충돌을 드러내며 임의로 평균내지 않는다. null은 0이나 중립이 아니다.
- 두 시점 등락률은 그 비교만 입증한다. 고점·저점·최대·최초·연속은 해당 범위와 조건을 확인한 결과가 있어야 한다. 관측 부족을 정상 상태로 해석하지 않는다. 장중 값은 종가 통계에 섞지 않는다.
- 비중은 ETF 전체 대비 편입비중이다. 구성종목 가중 수급은 '편입 비중을 반영한 구성종목 순매수'이며 ETF 자체 순매수가 아니다. 최근 수급과 확정 종가 기록은 지난 확정 거래일까지다. 더 오래된 값은 종료 날짜를 밝힌다. 이슈 외 이전 수치는 현재 유효성을 재확인한다.
- 기사 게시일·발표일·발생일과 가격 관측시각을 구분한다. 가격 관측 뒤 공개된 자료로 이전 가격의 원인을 입증하지 않는다. 발표 전 주가 상승이나 장 마감 뒤 보도만으로 선반영·미반영을 단정하지 않는다.

## 상세와 요약의 일치

상세에서 설명한 원인·반론·대상·기간·조건·사건 단계를 제목·요약·스티커·결론에도 유지한다. 본문에서 배제한 호재를 요약에서 되살리거나 예정→완료, 추정→확정, 납품→매출 인식으로 바꾸지 않는다. 모든 숫자와 근거 ID를 최종 참조 자료에 대조한다. 계산 입력·기준·출처를 기존 근거 계약으로 추적할 수 있어야 한다.
