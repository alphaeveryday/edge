ETF Orca 계정 삭제

  1. 앱에서 삭제: 프로필 화면의 탈퇴에서 바로 삭제할 수 있습니다.
  2. 앱 없이 삭제 요청: 가입한 이메일 주소에서 asm.alphaeveryday@gmail.com 으로 "계정 삭제 요청"을 보내 주세요. 본인 확인 후 삭제합니다.

삭제되는 데이터

  • 이메일과 비밀번호
  • 관심 목록, 전망 투표, 좋아요, 알림

남는 데이터

  • 쓴 글과 답글은 "탈퇴한 사용자"로 표시되어 남습니다. 지우고 싶은 게시물은 삭제 전에 직접 지워 주세요.
  • 신고·차단 기록은 부적절한 게시물 대응을 위해 계정 식별 정보 없이 남습니다.

비회원으로 쓰던 관심 목록도 위 메일로 요청하면 삭제합니다.

자주 묻는 질문

비밀번호를 잊었어요.
로그인 화면의 "비밀번호 찾기"에서 가입 이메일로 받은 코드를 입력하면 새 비밀번호를 정할 수 있습니다.

부적절한 글을 봤어요.
글이나 답글의 ⋯ 메뉴에서 신고하거나 작성자를 차단할 수 있습니다. 신고는 24시간 안에 검토합니다.

분석은 언제 갱신되나요?
전망은 매일 장 시작 전에, 가격 변동 설명은 가격이 움직일 때 갱신됩니다. 시세는 전일 종가 기준입니다.

ETF Orca는 정보 제공 앱이며 투자 권유가 아닙니다. 주식 거래나 계좌 연결 기능은 없습니다.
