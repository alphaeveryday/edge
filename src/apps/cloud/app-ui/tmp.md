## 스크린샷에서 고칠 것

- 제품명 통일 (ETF Orca)
  - ETF 상세·AI 분석 / ETF 상세·요약 / 그룹 담기 배경: 바이라인 "Edge AI · 9월 5일 금요일 08:30" → "ETF Orca AI · …"
  - 테마 분석 본문: "EDGE는 이 테마를 …" → "ETF Orca는 …"
  - 계정 하단: "MarketBrew v2.4.1" → "ETF Orca v2.4.1"
  - 홈 "기본 관심 그룹 엣지 강도": 지표명 유지 여부 결정 필요 (제품명 잔재면 "전망 강도" 류로)
- 실시간 이슈: 본문이 "에 관한 발표와 …" 로 주어 없이 시작, 이슈 제목 비어 있음 (템플릿 미채움)
- 수치 정합: TIGER 반도체TOP10 가격 12,806 / 12,819 / 12,845, 등락 +2.9 / +3.0 / +3.2% 로 화면마다 다름. 투표 참여 480명(ETF 상세) vs 584명(커뮤니티)
- 로그인 상태: 전체 메뉴는 비로그인, 계정은 김지수 로그인
- 요인 지표 "국고채 10년 3.20%" 글자 겹침 의심

## 빠진 화면

### 흐름이 끊기는 것 (우선)

- 이메일 로그인 폼 · 회원가입 · 비밀번호 재설정 ("이메일로 로그인" 다음)
- 게스트 로그인 유도 시트 (관심·투표·글쓰기 진입 시)
- ETF 상세 "종목정보" 탭
- 요인 상세: 차트 · 밸류 · 수급 (이슈·매크로만 있음)
- 출처 보기 (뉴스·공시 원문 목록)
- 그룹 생성·이름 입력, 그룹 여러 개일 때 관심 탭 전환
- 투표 결과 분포 · 투표 철회
- 타인 프로필 · 프로필 수정
- 댓글 작성 상태 · 게시물 더보기(신고·삭제·수정)
- 글쓰기 종목 태그 검색 시트

### 상태 화면

- 빈 상태: 관심 0개 홈, 검색 결과 없음·최근 검색어, 알림 없음
- 로딩·오류: 네트워크 오류, 분석 미발행(08:30 이전)
- 스플래시 · 온보딩 재방문
- 확인 다이얼로그: 관심 삭제, 로그아웃, 글 삭제

### 금융 앱 필수

- 투자 유의·면책 고지 (AI 분석 첫 진입 동의 또는 분석 하단)
- 약관 · 개인정보 처리방침 · 회원 탈퇴 · 알림 설정 상세
