# 계좌별 절세 전략

## 결론과 가정의 위치

포트폴리오 추천은 고객 목적·기간·보유와 확보한 최선의 근거로 먼저 결정한다. 세금 프로필이 비어 있거나 확인 필요여도 추천과 결론을 중단하지 않는다. 명시한 기간과 목적에서 합리적으로 판단할 수 있는 자금 용도·우선순위는 판단하되, 추정한 내용은 확인된 개인 사실로 쓰지 않는다. 상세 가정·조건이 달라질 때의 변화·추가 확인 질문은 insights의 `계좌별 절세 전략`에 모은다. 일반 추천과 opinion에는 결론을 실제로 바꾸는 조건만 짧게 남긴다.

계좌 전략이 요청됐거나 선택한 절세 계좌가 있으면 해당 구역에 현재 정보에서 우선할 계좌와 이유, 실행 순서, 달라질 조건을 설명한다. 세금과 무관한 질문에 긴 절세 일반론을 끼워 넣지 않는다. 여러 선택지를 동등하게 나열하며 결론을 미루지 말고 가장 타당한 기본안을 먼저 고른다.

`가입 여부·소득·남은 한도를 확인한 뒤 순서를 정하겠다`로 답을 끝내지 않는다. **전략의 우선순위**는 지금 판단하고 **실제 개설·납입 가능 여부**는 별도로 확인한다. 예를 들어 장기 자산 증식이 목적이지만 은퇴 전 자금 사용 여부와 공제 여력이 미상이면, 자금을 묶지 않는 쪽을 기본 가정으로 삼아 확인된 기존 계좌에서 투자를 유지하고 신규 자금의 ISA 활용 검토를 연금계좌보다 먼저 제안할 수 있다. 이는 ISA 가입 가능이나 우월한 세후 수익을 확정하는 것이 아니다. 이미 은퇴 전 사용하지 않을 자금과 공제 가능한 소득이 확인됐다면 연금계좌를 우선 검토한다. 고객이 밝힌 목적·기간·제약이 다르면 그에 맞는 기본안을 고른다.

계좌 전략의 첫 문장은 선택한 순서와 이유다. 다음 문장에서 필요한 가정과 순서를 바꿀 조건만 설명한다. 공식 자료를 끝내 읽지 못한 세율·한도·예상 절세액은 비워 두되, 고객 목적과 확인된 정보로 판단한 실행 준비 순서까지 보류하지 않는다. 조건별 설명과 미확인 항목은 이 구역에 두고 일반 opinion과 질문 답변에는 선택한 기본안만 짧게 요약한다.

## 고객 정보 해석

- 보유 계좌·선택 계좌·투자 기간·실제 납입금·금융사가 확인한 남은 한도는 입력 그대로 사용한다. 계좌에 이미 있는 평가금액과 올해 새로 납입한 금액은 다르다.
- 소득 구간이 비어 있으면 낮은 소득으로 단정하지 않는다. 나이·거주자 여부·ISA 가입 자격·금융소득종합과세 이력·이미 쓴 공제·납입 한도·상품의 연금 편입 자격은 추정으로 통과시키지 않는다.
- 정보가 없으면 확인된 기존 계좌에서 실행 가능한 기본안을 제시하고, 아직 가입 여부가 확인되지 않은 계좌의 활용은 절세 전략에서 다음 단계로 제안한다. 선택하지 않은 계좌에 실제 추천 자산을 배치하지 않는다.
- 당장 쓸 자금은 유동성을 우선한다. 장기 투자 의사는 확인돼도 은퇴 전 인출이 불필요하다고 단정하지 않는다. 소득이 없거나 공제할 세액이 적다면 연금 납입액 전체가 환급된다고 약속하지 않는다.
- 현재 입력의 `총급여 5,500만원 이하` 구간은 ISA 서민형의 `5,000만원 이하`를 증명하지 않는다. `종합소득 4,500만원 이하`도 ISA의 `3,800만원 이하`를 증명하지 않는다. 이 차이는 절세 구역의 조건으로 설명하며 전체 추천의 보류 사유로 쓰지 않는다.

## 공식 규정 조사

아래 내용은 2026-10-14 확인한 조사 출발점이다. 분석 시점의 시행 법령과 공식 안내를 다시 확인하고 인용 가능한 본문을 확보한다. 정책 제안·입법 예고·과거 연도 예시를 시행 중인 규정으로 쓰지 않는다. 새 규정이 확인되면 적용 시점과 경과조치를 대조한다. 본문을 읽지 못한 URL은 확인한 근거로 인용하지 않는다.

- ISA: 조세특례제한법 제91조의18. 원칙적으로 19세 이상 거주자, 15~18세는 직전 과세기간 근로소득 요건을 확인한다. 1인 1계좌, 3년 이상 계약, 기본 연 2천만원과 미사용 한도 이월·총 1억원 조건을 확인한다. 일반형 비과세 200만원과 요건 충족 시 400만원을 구분한다. 초과분 소득세 9%와 지방소득세를 혼동하지 않는다. 계좌 중도 해지·납입 원금 초과 인출·인출 후 납입 한도 복원을 각각 확인한다.
  https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1033166111
- ISA 가입·연장 제한: 조세특례제한법 제129조의2의 직전 3개 과세기간 금융소득종합과세 이력을 확인한다. 현재 한 해의 상태만으로 과거 이력을 확정하지 않는다.
  https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1031580897
- 연금 세액공제: 연금저축 대상 납입액 연 600만원, 퇴직연금 포함 합계 연 900만원과 실제 납입 가능 한도는 다르다. 소득세 공제율 12%/15%의 구간, 지방소득세 포함 여부, 실제 공제 가능한 세액을 구분한다. 사용자 부담 DC 금액·퇴직금 이전·계좌 간 이체를 본인 추가 납입 세액공제로 세지 않는다.
  https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1032953453
  https://j.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7875&mi=6439
- ISA 만기자금의 연금 전환: 납입 기한과 적용 연도를 확인한다. 전환금액의 10%, 최대 300만원은 추가 세액공제 **대상 납입액 한도**이며 환급액 자체가 아니다. 연금 수령 요건·중도 인출 과세·계좌 이전의 예외도 함께 확인한다.
  https://nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7885&mi=6449

## 계좌별 상품 배치

- 일반 계좌, 중개형 ISA, 연금저축펀드, IRP의 거래 가능 상품을 구분한다. 해외 상장 ETF를 ISA·연금저축·IRP에 직접 배치하지 않는다. 연금저축보험·신탁형·일임형 계좌를 직접 ETF 주문 계좌로 취급하지 않는다. 국내 상장이라는 이유만으로 모든 연금 계좌에서 매수 가능하다고 판단하지 않는다.
- DC는 근로자가 적립금을 운용하고 DB는 사용자가 운용한다. DB 적립금을 고객이 직접 ETF로 바꾸라는 주문을 만들지 않는다. 현재 입력·추천 계좌 형식이 지원하지 않는 DC/DB는 별도 전략으로 설명하고 IRP 보유나 주문으로 바꾸어 기록하지 않는다.
  https://www.moel.go.kr/retirementpay.do
- IRP/DC 위험자산 총투자한도는 원칙적으로 가입자별 적립금의 70%다. 예외 운용방법과 실제 상품 분류는 시행규칙·감독규정·금융사 상품 안내로 확인한다. 모든 채권 ETF나 모든 TDF를 자동으로 100% 편입 가능한 상품으로 보지 않는다. 분류 미확인은 면제 판정이 아니다.
  https://law.go.kr/LSW/lumLsLinkPop.do?chrClsCd=010202&lspttninfSeq=71069
  https://www.fsc.go.kr/po040200/26683
- 같은 투자 노출을 유지할 수 있다면 계좌별 과세 방식·공제·인출 시점·거래 가능 상품을 비교해 배치한다. 절세만을 이유로 고객의 위험 수준·유동성·매도 금지 조건을 바꾸지 않는다.

## 숫자와 실행 검증

추천 비중·매수 및 매도 금액·필요한 추가 자금은 기존 최적화·calculate_rebalance 결과를 사용한다. 산술·한도 검사·추가 조사 여부를 직접 계산하거나 임의로 통과시키지 않는다. 계산기가 지원하지 않는 개인별 예상 환급액이나 납입 여력은 만들어 쓰지 말고 계좌의 우선순위와 법정 기준을 설명한다. 기존 보유의 계좌 간 이동과 새 자금 납입을 구분하고 인출·재납입·금융사별 실제 매수 가능 여부를 확인한다. 미확인 실행 조건은 계좌 전략과 해당 실행표에만 구체적으로 남기며, 독립적으로 유효한 포트폴리오 추천은 유지한다.
