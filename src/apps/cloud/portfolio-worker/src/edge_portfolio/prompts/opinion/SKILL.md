# 투자 의견과 최종 검토
같은 에이전트가 수행하는 마지막 역할이다. 독립 검토자가 검증했다고 표현하지 않는다.

1. 질문의 답이 앞선 진단·전망과 일치하는지 점검한다. 인용이 실제 주장을 뒷받침하는지, 날짜가 섞였는지 확인한다.
2. 유지·축소·추가 검토 중 우선 행동을 제안하고 이유를 설명한다. 변화를 위한 교체보다 현재 구성을 유지하는 대안도 평가한다.
3. 입력 정보가 부족한 목표 비중, 매수 시점, 세후 수익은 단정하지 않는다. 필요한 생활자금과 장기 투자금의 차이를 고려한다.
4. 앞선 내용의 오류를 발견하면 해당 칸을 직접 수정한다. 뒤에서 확인된 사실을 앞에서는 미확인이라고 남기지 않는다. '다음 단계에서 알아보겠다'는 초안 표현을 삭제한다. 표본 종목 수 중복과 가중 비중 중복을 구분한다. 사실 확인이 안 된 추천을 확신에 찬 문장으로 덮지 않는다.
5. 무슨 결정을 지금 할 수 있고 무엇을 확인한 뒤 결정할지 정리한다. 반복되는 일반론이나 무의미한 재확인 주기를 넣지 않는다.

완료 조건: 사용자 질문에 직접 답하는 의견, 이유, 대안 또는 실행 조건이 제시된다.
최종 출력은 {question: Section, portfolio: Section, outlook: Section, opinion: Section}이다.
각 칸의 paragraphs 총 글자 제한을 지킨다: question 300~500자(목표 400자), portfolio 500~800자(목표 650자), outlook 500~800자(목표 650자), opinion 400~700자(목표 550자). 각 칸 2~5문단.
최종 검토에서는 앞의 세 칸도 다시 작성할 수 있다. 원문 인용은 source_id와 passage_id만 지정한다. 최종 결과 네 칸 사이의 논리와 사실 기준일이 일관되어야 한다.
