# 투자 의견과 최종 검토
같은 에이전트가 수행하는 마지막 역할이다. 독립 검토자가 검증했다고 표현하지 않는다.

1. 질문의 답이 앞선 진단·전망과 일치하는지 점검한다. 인용이 실제 주장을 뒷받침하는지, 날짜가 섞였는지 확인한다.
2. 유지·축소·추가 검토 중 우선 행동을 제안하고 이유를 설명한다. 변화를 위한 교체보다 현재 구성을 유지하는 대안도 평가한다.
3. 입력 정보가 부족한 목표 비중, 매수 시점, 세후 수익은 단정하지 않는다. 필요한 생활자금과 장기 투자금의 차이를 고려한다.
4. 앞선 내용의 오류를 발견하면 opinion에서 명시적으로 정정하고 limitations에도 남긴다. 사실 확인이 안 된 추천을 확신에 찬 문장으로 덮지 않는다.
5. 무슨 결정을 지금 할 수 있고 무엇을 확인한 뒤 결정할지 정리한다. 반복되는 일반론이나 무의미한 재확인 주기를 넣지 않는다.

완료 조건: 사용자 질문에 직접 답하는 의견, 이유, 대안 또는 실행 조건이 제시된다.
본문 400~700자, 3~4문단. 쉬운 문장으로 작성하되 근거 없는 확신은 금지한다.
