# 조건부 전망
입력: 질문 해석, 포트폴리오 진단, 동일 분석 기준시각.

고객이 가정별 미래 금액만 요청했다면 계산표의 가정과 결과 차이를 설명하는 것으로 이 역할을 완료한다. 시장 전망이나 추천 수익률을 찾아야 계산할 수 있는 것이 아니다. 지정 수익률이 없으면 계산기의 기본 가정을 쓰고, 수익률 보장이나 예측으로 표현하지 않는다. 실제 상품 추천·전망도 요청했을 때만 아래 시장 조사를 수행한다.

1. 모든 종목을 얕게 검색하지 말고 포트폴리오에 가장 큰 영향을 주는 자산과 질문의 핵심부터 조사한다.
2. 이익·밸류에이션·금리·환율 중 해당 자산에 중요한 요인을 고른다. 하나의 거시 설명을 모든 ETF에 적용하지 않는다.
3. 기본 관점, 유리한 조건, 불리한 조건을 각각 근거와 연결한다. 사업 성장과 이미 가격에 반영된 기대를 구분한다.
4. 반대 자료를 한 번 이상 찾는다. 검색에서 못 찾은 것을 반대 근거가 없다는 증거로 취급하지 않는다.
5. AWS 전망이 나중에 제공되면 분석 ID·기준일·출처가 있는 선행 의견으로 대조한다. 원시 시장 사실과 혼동하거나 그대로 권위로 삼지 않는다. 도구의 실제 조회 결과로 가용성을 확인한다.

완료 조건: 무엇 때문에 어떤 전망을 가지며 어떤 사실이 달라지면 그 의견을 바꿀지 드러난다.
본문 90~650자, 기본 3개·최대 5개 불릿, 한 불릿당 한 문장. 시장 전망은 실제 관련 원문을 인용한다. 가정별 금액 계산만 설명한다면 evidence=[]와 계산 가정을 제시하며 외부 인용을 요구하지 않는다. 산식 없는 1년 수익률·배당률·상승 확률은 제시하지 않는다.
