## 현재 자동 검증

- 패키지 pytest: 30개, 모두 통과, skip 없음.
- JavaScript 구문 검사 통과.
- Python 소스 배포물과 wheel 빌드 성공.
- 모델 도구 경계: 기본 도구 없음, 등록된 search/read만 허용, 외부 설정 미사용,
  키 비저장. 실제 SDK 하위 프로세스의 OS 격리는 검증하지 않았다.
- 회계: HOLD/target 차이, 비용 포함 현금 제약, 분배금, 최초 자산 기준 낙폭,
  turnover, 상수 수익률 샤프 N/A, 실패 롤백, 재개 중복 방지.
- 가격: 실행 tape가 관측 데이터로 유입되는 결함을 회귀 테스트로 재현 후 수정.
  모델 가격은 별도 판본 증명으로 승인하며 search/read 가격 원문 조회도 차단.
- 대시보드: 빈 상태, 출처 구분, 로컬 origin·CSRF 검증. 실행 안 한 실험의
  성과는 null. 합성 투자 결과는 실제 성과와 구분한다.
