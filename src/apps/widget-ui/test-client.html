S015 기본 설치 예시

단일 <script> 태그 하나로 widget.js가 로드되고, script 위치 바로 뒤에 위젯 container가 생성됩니다.

<script
  src="./widget.js"
  data-embed-key="pub_demo_1234"
  data-client-id="demo-sec"
  data-widget-id="asset-event-impact"
  data-symbol="005930"
  data-theme="default">
</script>

S016 data attribute 계약 요약

  • 필수: data-embed-key, data-widget-id, data-symbol
  • 선택: data-client-id, data-theme
  • 테스트 전용: data-mock-status — PoC 상태 강제용이며 실제 Gateway request나 설치 코드에는 포함하지 않습니다.
  • 멀티테넌시 신뢰 기준은 data-client-id가 아니라 data-embed-key 검증 결과입니다.

mock 상태 확인 · success / empty / error / fallback

data-mock-status로 상태별 렌더링을 확인합니다. success는 위 AI분석 탭 본문 위젯에서 확인하고, 아래에서 empty / error / fallback을 확인합니다.

empty · 분석 결과 없음
error · 오류 메시지
fallback · 대체 응답

S046 / S049 local API mode · PoC/dev 전용

아래 위젯은 data-gateway-mode="local-api"로 동작하며 Vite dev 서버의 POST /mock-gateway/widget-analysis endpoint를 호출합니다. (S046) 이 endpoint는 내부적으로 request → mock tenantContext → analysisApiClient.getLatestAnalysis() → S049 adapter(mapAnalysisToWidgetResponse()) 순서로 위젯 응답을 만듭니다. pnpm --filter widget-ui dev로 띄운 dev 서버에서만 동작합니다.

POST /mock-gateway/widget-analysis는 PoC/dev 전용 endpoint입니다. 실제 Gateway 서버, Public Embed Key 검증, tenant DB/분석 API 호출은 아직 없습니다.

<script
  src="./widget.js"
  data-embed-key="pub_demo_1234"
  data-client-id="demo-sec"
  data-widget-id="asset-event-impact"
  data-symbol="005930"
  data-theme="default"
  data-gateway-mode="local-api"
  data-gateway-url="/mock-gateway/widget-analysis">
</script>

data-gateway-mode, data-gateway-url은 S049 PoC/dev 전용 속성이며 실제 고객사 설치 코드 계약이 아닙니다.
