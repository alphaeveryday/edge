# 수정 분석의 현재 조사 상태

사용자 승인: 이전 발행물과 현재 유효한 조사 원문을 첫 입력에 제공한다. 생략은 삭제가 아니며 명시적 제외만 반영한다. 전망은 주말에도 이어가고 가격변동은 한국시간 같은 날짜만 이어간다. 확정 표현의 의미 품질 문제는 보고하되 단독 배포 차단 사유로 삼지 않는다.

## 작업 단위와 검증

1. 현재 자료 상태와 실제 열람 자료 수집: 원문 유지, 같은 자료 중복 제거, 제외 상태 유지, 잘못된 변경의 원자적 거부를 단위 테스트한다.
2. 저장 및 인계: 기존 tool_runs에 내부 상태 스냅샷을 저장하고 완료된 부모만 읽는다. 발행 실패, 재시도, 기존 분석의 자료 누락, 같은 날짜 경계를 DB 통합 테스트한다. 스키마 변경 없이 기존 감사 저장 경로를 재사용한다.
3. 초기 입력과 조사 스킬: 이전 본문·자료를 직접 제공하고 최초/수정 조사 범위를 분리한다. 가설 스킬은 모두 기본 제공한다. 실제 첫 메시지와 경로 선택을 테스트한다.
4. 변경분 발행: 미변경 본문 유지, 명시적 변경만 적용, 이전 근거 재사용을 검증한다. 변경 개수에 따른 전체 재작성 지시는 제거한다.
5. 실증 및 PR: 같은 모델·effort·자료로 기존/후보를 비교한다. 무변경, 단일 변경, 정정, 수급 반전, 시점 경과, 주말, 연속 수정, 대용량을 다룬다. 복구 호출을 포함한 비용과 본문 보존을 보고한다. 실제 입력 초과는 임의 절단 없이 보고 후 해결안을 제시한다.

기존 tasks/plan.md와 todo.md는 다른 작업 문서이므로 덮어쓰지 않는다. 기존 미배포 writer/reviewer 실험은 포함하지 않는다. ALPHA-1336 후속 작업이며 현재 Jira 도구가 없어 이슈 상태 재확인은 미실행이다.
