## 목적과 계약

툴이 계산한 숫자를 나중에 확인하려면 호출 인수·반환값·수식·출처를 DB에서 찾을 수 있어야 합니다. 이번 변경은 기존 로컬 v2 전체를 옮기지 않고, 그 저장·조회 모듈과 최소 패키지만 추가합니다.

- `register_definition`: 함수명·버전·관리자용 설명·수식·출처 등록. 같은 ID의 내용을 덮어쓰지 않음.
- `save_run`: 이미 생성한 실행 ID와 실제 인수·반환 객체·소속 분석·실행시각 저장. 실패도 저장.
- `get_run`: 실행 ID로 저장된 값과 툴 정의를 함께 조회.
- 반환 객체는 `{tool_run_id, result}` 전체를 저장. 실행 ID가 다르거나 JSON으로 정확히 표현할 수 없는 값을 거부.
- 전용 autocommit 연결 사용. 감사 저장은 자체 트랜잭션으로 완료하여 이후 분석 실패에 휩쓸리지 않음.
- DB 접속값·SSM·권한 발급은 호출자가 담당. 원천 조회·계산·에이전트 실행은 이번 변경에 포함하지 않음.

## 선행과 검증

- 테이블은 #960 필요. 이 PR은 테이블을 중복 정의하지 않음.
- v2 패키지 검사 등록은 #962. 최소 패키지에는 저장에 필요한 psycopg만 의존.
- 자동 단위 검사는 잘못된 인수·트랜잭션 사용을 DB 접속 없이 검증.
- 실제 PostgreSQL 검사는 별도 integration_tests에서 수행. 로컬 테스트 DB만 허용하고 테스트가 만든 행만 정리.
- 클라우드 적용·실제 런타임 연결·대시보드 표시는 후속 작업. 여기까지 완료로 표시하지 않음.

## 검증 결과

- 단위 검사 17개 + 실제 로컬 PostgreSQL 검사 7개 통과. 건너뛴 테스트 없음.
- 호출 연결 모듈은 DB 커밋 후 동일 결과만 반환. 계산 실패 기록·저장 실패 시 결과 차단 포함. [연결 계약과 수동 검증](execution.md).
- 큰 정수·한글 반환값 보존, 전망·움직임 소속, 실패 기록, 정의 변경·실행 덮어쓰기 거부, 부모 없는 기록 거부 확인.
- 별도 연결로 다시 조회하여 분석 트랜잭션 롤백 뒤에도 감사 기록이 남는지 확인.
- `uv sync --locked --package analysis-engine-v2`로 독립 설치 확인. 기존 의존성 버전 변경 없음.
- 로컬 리뷰: SQL 인수 바인딩, 테이블명 고정, 비밀값 미저장, 기존 런타임·원천 테이블 변경 없음 확인.
- 자동 기본 테스트에는 단위 검사만 포함. DB 통합 검사는 아래 명령으로 별도 실행하며, 접속 설정이 없으면 실패함.

실행 위치: `src`. `V2_TEST_DSN`은 로컬 `127.0.0.1:55439/analysis_v2` 접속 문자열로 설정.

```powershell
uv run --locked --package analysis-engine-v2 pytest -c apps/cloud/analysis-engine-v2/pyproject.toml apps/cloud/analysis-engine-v2/tests apps/cloud/analysis-engine-v2/integration_tests -q
```
