목표: 목 원천 → 실제 툴/에이전트 → 클라우드 PostgreSQL → 기능별 화면 계약을 대시보드에서 확인. 폴더명의 local은 기존 작업 기록명이며, 결과 DB를 로컬로 제한하지 않는다.

구현 범위·순서: [계약](../../docs/analysis-engine-v2/local-storage-contract.md).

- 로컬 리뷰 후 선택 파일만 커밋·push하고 dev 대상으로 실제 PR 생성. 병합·DB 적용은 변경 영향 확인 후 별도로 수행.
- 기존 개발 트리의 미커밋 파일은 원본 보존. 필요한 부분을 PR별로 선별.
- DB 구조 변경은 `src/libs/schema` 관례를 따르고 개발 DB에서 선행 검증한 후 클라우드에 적용·확인.
- PR 설명은 문제 → 변경 후 동작 → 포함 파일 → 검증 → 미완료/의존성 순서.
