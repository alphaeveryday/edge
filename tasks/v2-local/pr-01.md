## docs(analysis-engine): 목데이터 분석의 DB 저장·화면 조립 계약 명시

ETF 분석은 에이전트가 문장을 반환하는 것으로 끝나지 않습니다. 문장과 근거를 DB에 저장하고, 그 저장값으로 앱에 전달할 응답을 만들어야 합니다. 이번 변경은 각 결과가 어느 테이블에 들어가고 어떤 화면 응답이 되는지 정리합니다.

원천은 목데이터를 사용하지만 계산·DB 저장·응답 조립은 실제 구현으로 검증합니다. 결과는 클라우드 PostgreSQL에 저장하고, 개발자는 대시보드에서 입력, 툴 결과, 실제 저장 행, 기능별 최종 JSON을 순서대로 확인하게 됩니다. 로컬 DB는 사전 검증용입니다.

### 포함 파일

- `docs/analysis-engine-v2/local-storage-contract.md`: 저장 매핑·갱신 규칙·대시보드 확인 항목.
- `tasks/v2-local/plan.md`, `todo.md`: 로컬 개발 순서와 진행 상태.
- 이 파일: 변경 목적과 로컬 리뷰 기록.

### 검증과 리뷰

- Obsidian ERD의 8개 테이블과 오늘 움직임·전망·요인 상세 계약을 대조.
- 수치 카드와 이슈 상세의 저장 위치 누락을 발견해 미완료 사항으로 명시.
- 기능별 응답을 독립 처리하면서 서로 다른 발행본을 섞지 않도록 저장 완료 경계를 명시.
- 문서 변경만 포함. 실행 코드 테스트는 대상 없음. DB 저장·대시보드 구현 완료를 의미하지 않음.

### 다음 변경

개발용 PostgreSQL에 Flyway로 테이블을 만들고 실제 제약조건을 검사합니다. 기존 미커밋 에이전트·대시보드 패키지는 이번 변경에 포함하지 않습니다.
