## 요약

분석 결과가 파일에만 남으면 서버를 다시 켠 뒤 이전 전망을 수정하거나, 화면에 나온 숫자의 근거를 DB에서 확인할 수 없습니다. 이번 변경은 오늘 움직임과 전망을 따로 저장하고, 각 문장의 계산 근거를 조회할 수 있는 8개 테이블을 추가합니다.

예를 들어 전망의 논점을 삭제하면 새 본문에는 그 논점이 없지만, 오늘 업데이트에는 삭제 기록을 저장할 수 있습니다. 툴 결과는 해당 분석과 연결되어 나중에 인수·결과·수식을 조회할 수 있습니다.

최종 목표는 목데이터 분석 결과를 클라우드 DB에 저장하고 대시보드에서 확인하는 것입니다. 이 PR은 그 첫 단계인 저장 테이블을 추가하며, 로컬 PostgreSQL로 먼저 검증했습니다.

### 변경 파일

| 파일 | 필요한 이유 |
|---|---|
| `docker-compose.v2-local.yml` | 다른 개발 DB와 분리된 PostgreSQL, Flyway 실행. 로컬 55439 포트만 공개 |
| `src/libs/schema/migrations-cloud/V202609281600__create_v2_analysis_storage.sql` | 기존 ERD의 8개 테이블·외래키·조회 인덱스 |
| `src/libs/schema/tests/analysis_v2_storage.sql` | 실제 PostgreSQL에서 잘못된 저장 거부와 정상 저장 확인 |
| `src/libs/schema/generated/physical-erd.dbml` | 저장소 필수 산출물. 새 8개 테이블이 반영된 물리 ERD |
| 이 파일 | 완료 범위·적용 영향·재현 명령 기록 |

### 검증 결과

- 테스트를 먼저 실행해 `movement_analyses`가 없어 실패함을 확인한 뒤 마이그레이션 작성.
- 최신 dev(ba3daa1) 기준의 빈 전용 DB에 기존 68개 + 신규 1개, 총 69개 Flyway 마이그레이션 적용 성공.
- 재실행 시 추가 적용 없음. Flyway validate 통과.
- Windows 커밋 훅의 ERD 생성은 UHC/UTF-8 인코딩 오류로 실패. 동일 생성 스크립트를 PostgreSQL 18 Docker에서 실행해 복구. cloud ERD만 변경되고 on-prem ERD는 동일.
- 툴의 소속 없음·이중 소속·없는 분석 참조, 허용하지 않은 스티커, 중복 본문 순서, 6개 설명 선정을 모두 거부: 6개 검사 통과.
- 정상 툴 결과·본문·논점 삭제 기록 저장과 조회 통과. 테스트 자료는 rollback.
- 로컬 리뷰: 기존 테이블 ALTER/DROP 없음. 외부 DB 연결 없음. 새 DB는 localhost 전용이며 비밀번호는 개발 전용 고정값.

### 실행 방법

저장소 루트 PowerShell에서 실행합니다.

```powershell
docker compose -p edge-v2-local -f docker-compose.v2-local.yml up -d --wait postgres
docker compose -p edge-v2-local -f docker-compose.v2-local.yml run --rm flyway migrate
docker compose -p edge-v2-local -f docker-compose.v2-local.yml run --rm flyway validate
docker compose -p edge-v2-local -f docker-compose.v2-local.yml cp src/libs/schema/tests/analysis_v2_storage.sql postgres:/tmp/analysis_v2_storage.sql
docker compose -p edge-v2-local -f docker-compose.v2-local.yml exec -T postgres psql -U v2_local -d analysis_v2 -v ON_ERROR_STOP=1 -f /tmp/analysis_v2_storage.sql
```

### 아직 포함하지 않은 동작

- 에이전트 호출 결과를 저장하는 코드와 대시보드는 후속 PR. 이번 변경만으로 분석이 자동 저장되지는 않습니다.
- 완료 발행본 불변성, 배열 근거 ID의 존재·소속, 필수 기능의 완성 여부는 저장 코드에서 검증할 예정입니다. DB 제약만으로 전체 업무 규칙을 보장하지 않습니다.
- 수치 카드와 이슈 상세 저장 보완은 PR 10. 이 마이그레이션은 기존 ERD 8개 테이블 범위입니다.
- 이번 검증은 전용 Docker DB에서 수행했습니다. 클라우드 DB에는 아직 적용하지 않았습니다.
- 설계 배경: #959. 이 PR은 dev에서 별도로 분리했으므로 문서 PR이나 과거 뉴스 구현 파일이 섞이지 않습니다.

### 병합 시 영향

- dev 병합 시 기존 `schema-migrate`가 ECS 일회성 작업으로 개발용 클라우드 RDS에 테이블을 생성합니다. PR 생성 자체는 해당 배포를 실행하지 않습니다.
- 기존 테이블 변경·데이터 삭제는 없습니다. 분석 실행기·대시보드 배포도 포함하지 않습니다.
- 자동 병합은 설정하지 않습니다. 병합 전에 대상 DB의 동명 테이블 유무, 적용 권한, 최신 Flyway 버전을 확인해야 합니다.
- 앱의 v2 전용 쓰기 권한과 클라우드 저장·재조회 확인은 후속 작업입니다. 이 PR만으로 클라우드 저장 기능이 완성되지 않습니다.
